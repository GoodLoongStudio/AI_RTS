# RTS_Map_Tool Skills 目录

本目录保存 `RTS_Map_Tool` 项目的项目级开发约束。开始修改地图生成、Kit、美术材质或 Godot 预览前，先阅读对应 skill。

## Skill 文件

- [RTS_MAP_TOOL_VISUAL_KIT.md](./RTS_MAP_TOOL_VISUAL_KIT.md)：台地、坡道、河流、湖泊和平面 Kit 的材质基线、连续几何规则、渲染检查和交付验收。

## 使用顺序

1. 先读取本目录和相关 skill 文件。
2. 再检查 `review/G4/kit_samples/modular_plateau_final/` 的正式基线。
3. 修改后执行 Godot headless 渲染并检查输出图。
