# RTS Map Tool Visual Kit Skill

## 美术基线不可绕过

台地、坡道、河流、湖泊和平面 Kit 必须共享已经验收的正式美术管线。新 Kit 的第一版也必须沿用台地/坡道正式样例使用的材质、纹理、法线、粗糙度、光照和镜头设置。

禁止用临时纯色 Shader、临时平面材质或仅靠颜色渐变的程序网格，冒充正式视觉结果。程序化几何只能负责形状和连接关系，不能替代正式地表材质。

## 河流与湖泊

- 河床、水面、浅水带和湿岸必须使用连续共享顶点或等效连续高度场，避免条带接缝和错误法线。
- 水体视觉部件只包裹既有 G2 水域边界，不修改 water footprint、blocking、passable、桥位或导航语义。
- 河心默认保持干净。除非需求明确要求，不能添加岛屿、沙洲、石块、桥或装饰物。
- 岸线细节应优先使用真实砂地/岩石纹理、法线和粗糙度；泡沫、浅滩和湿岸必须是材质层次，不得只靠宽色带表达。
- 岸边岩石和植被只能稀疏放置在岸线附近，不能散落到河心或遮挡水面连续性。

## 实施顺序

1. 先读取并复用 `modular_plateau_final` 的正式材质和渲染设置。
2. 再建立最小视觉原型：单一连续水体、无中间装饰、自然岸线。
3. 只有基础材质通过参考图对照后，才增加桥、连接件、碎石或植被。
4. 每次修改后必须用 Godot headless 重新渲染 `overview` 和 `bank_detail`，检查水面连续、岸线无条带接缝、材质没有异常深色块。
5. 若材质测试产生上下色差、棕黑色带或错误法线，立即回退到上一个稳定版本，不得继续叠加结构掩盖问题。

## 交付验收

- 必须展示最终渲染图，而不是只报告脚本已运行。
- 必须说明参考图与输出在水色、湿岸、砂砾纹理、岩石分布和镜头上的对应关系。
- `component.json` 记录 Kit ID、几何类型、材质资源路径、实例和生成参数。
- 视觉验收通过前，不得把该 Kit 接入 G4 总地图或 AI_RTS。
