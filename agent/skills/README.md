# Agent Skills

项目级技能目前统一放在根目录 `skills/`，不要在这里复制第二份规则。

当前最重要的技能是 [`skills/闭环验证工作法.md`](../../skills/闭环验证工作法.md)。以后可以在根目录 `skills/` 增加领域技能，例如：

- `world-scale-audit.md`：视觉、碰撞、导航、速度、射程、视野和特效的米制联动审计；
- `godot-screenshot-qa.md`：启动可见实例、截图、打开图片并做视觉验收；
- `rts-combat-balance.md`：速度/射程/视野/弹道/命中反馈的统一调参流程。

新增技能必须在 `skills/目录.md` 登记，并包含适用范围、输入证据、执行步骤、验证命令和失败处理。
