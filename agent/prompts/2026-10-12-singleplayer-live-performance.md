# 可重复的诊断入口

读取 AGENTS.md 和 airts-performance-optimization。运行 tools/dev/singleplayer_live_perf.py --out agent/runs/<唯一运行目录>，仅在用户授权开独立局且不存在另一个玩家游戏时执行。该工具走正常 Play 页的单人开局方法，设置真人和一个中等电脑、PlainAndSimple 地图；采集真实帧间隔、渲染服务器计时和现有系统计时桶，外部线程/全机 GPU 遥测。不得把不同采样器数据相加成互斥帧成本，也不得把后台样本称为前台成绩。

先看 identity、raw-phase 和 cleanup，核对运行身份和错误，再给用户热点与未归因项。单次状态 FPS 不是 p95；主视口 GPU 时间不能代表全部视口。禁止自动优化、改产品配置、控制其他对局、清理其他 Agent 的进程或工作区。

已知工具限制：r02 启动和采样保持后台；r03 引擎忽略了非激活启动请求，曾成为前台。工具现检测到此条件即停止，不能宣称已彻底解决启动抢焦点。修复和重新资格验证非激活启动前，不把该入口当作可靠的全自动后台测试标准。工具最后加入的 QueryPerfStats 导出及前台拒绝分支只经过 Python 静态校验，尚未重新运行 Godot 验证。
