# 副官循环分支诊断提示词

用户要可追溯的循环分支图：本轮读到什么事实、目标是否仍有效、能走哪些支路、为什么选择、输出任务、合法性与资源门禁、命令接受、实际进展、成功/正常等待/失败/超时、恢复后返回何处。

先从既有真实 600 秒观察和相同 hash 的源码还原现有调度图。分开呈现源码定义的预期路径、日志明确记录的分支事件，以及建议新增的目标反馈循环。日志无节点进入/退出时间、父任务ID或因果ID时写缺口，不能据 tick 或最近时间编造调用因果，不能把 dispatch accepted 当任务完成。

用 Mermaid 保存源图与 Markdown 并渲染查看。提供离线时间滑块选择已有轮次，展示原始事件、真实路由、实际余额、最新已完成调用、已记录候选路线与不可选原因。重点核验 D2 经济恢复入口与当前 M01/工人数/交货的关系，检查 success/failure/exit 是否只是文本，而非执行分支。

独立核对全部轮次、事件计数、来源 hash、图代码一致、筛选与回放；保存闭环报告。工具只读原件，不改产品、不重跑游戏、不声称运行时防停滞门禁已安装。将运行时追踪和分支合同作为明确待实现要求记录。
