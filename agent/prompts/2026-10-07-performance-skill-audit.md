# 可交给下一个 Agent 的任务

读取 `AGENTS.md`、`agent/manifest.json` 和 `skills/airts-performance-optimization/SKILL.md`。在 AI_RTS 中做保画质性能优化：先复现和测量，再选当前最贵的一项，完成小补丁、新旧行为对照、真实 Match 性能对照、截图、相关/全量回归与报告。按 skill 的按需参考定位现有代码，不重复创建已存在的空间索引。

每轮必须明确 CPU/GPU/同步/分配的实际瓶颈，记录单位/建筑/战斗数量、相机/画质、physics tick、引擎/提交/文件 hash、平均 FPS 与帧时间 p50/p95/p99。不要凭一次高 FPS、成功标记或 headless 测试宣称图形性能达标。

优先消除重复遍历、过期缓存、重复路线预览、全图重绘/上传和分配；模型 LOD、阴影代理、特效预算仅在 GPU 证据支持时按屏幕空间误差实施，保留剪影、阴影接地感、命中/死亡/移动/采矿反馈和战争迷雾信息安全。不改变单位游戏尺寸、射程、速度、视野或碰撞来冒充优化。

使用当前可用的 Godot 工具/MCP 或 CLI；先检查实际能力和运行状态，插件安装列表不代表可用。启动本地 Match 用 `tools/dev/match_instance.py` 的所有权/端口/租约与 finally 清理。不杀其他 Agent/玩家进程，不污染正常启动配置，不额外调用收费模型服务。

候选失败就记录并撤销本轮自己的补丁，保留最后已验证版本。测试仍有失败时列出可复现项及旧版对照，不改断言让它绿、不宣称全局完成。把真正实测成立的新经验追加到 skill 的参考证据区；未测方案保持候选身份。
