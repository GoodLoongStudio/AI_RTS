# RTS 保画质性能审计与 skill

状态：已完成文档交付与独立前向评估。范围：代码/已有性能证据审计，项目级 skill 和路由；本任务没有改产品算法或画质。

## 目标

识别当前 AI_RTS 中减少重复计算、平滑尖峰和降低渲染浪费的机会，让后续 Agent 按测量和正确性门禁实施，而不是把碰撞、战争迷雾或画质关掉换 FPS。

## 计划

1. Explorer：检查共享工作区、现有 skill/运行器及上一轮原始证据；定位 CPU、GPU、特效、UI、AI 快照入口。
2. Controller：按代码证据和测量状态排序；区分零画质影响与需要视觉审批的候选，不承诺未测收益。
3. Editor：创建 `skills/airts-performance-optimization/SKILL.md` 和按需参考文档；更新 AGENTS、skills 目录和 manifest 路由。
4. Verifier：校验 skill/JSON/链接；独立前向评估真实性、低画质风险和验证流程；记录闭环报告。

## 门禁与边界

- 不回滚现有大量 staged/unstaged/untracked 工作；动笔前复查目标文件。
- 新 skill 必须保留物理 tick、碰撞/净空、速度/射程/视野、出生/建造、单位可读性。
- 保留已有空间网格，不能推荐再次建设同类索引；索引复用先验证快照时序和不漏候选。
- 文档交付不等于性能优化已实施；复用历史运行数据标明时间/负载，未测项标候选。
- 本任务仅文档/路由变更，无需为了文档重跑全量游戏；运行时及画质改动将由后续实现任务单独测量。

## 基线

- 2026-10-07 小部队报告：53 实体，原算法约 4.4 FPS；窄范围等价补丁后移动约 91.5 FPS 无上限，正常 30 FPS 上限约 29.8 FPS，p95 仍约 54 ms。
- 全局回归未全绿；该报告 needs-review，不能包装成全项目 champion。
- 当前代码/引用/修改边界在最终闭环报告中列出。
