# Grok 4.7 游戏修复安全闭环计划

日期：2026-10-10（北京时间）  
状态：待新会话执行；本文件只定义计划和门禁，未声称游戏问题已经修好。

## 1. 目标

让 Grok 4.7 能够修复 AI_RTS 的尺寸、碰撞、出生、建造、导航、经济和性能问题，同时避免“修好 A、破坏 B”。核心方法是：**一个小补丁 → 立即重新开一局无头真实对局 → 验证新旧链路 → 阶段性回归 → 才能继续下一项**。

性能、视觉和玩法都必须保留真实合同：正常画质、单位尺寸、碰撞形状、速度、射程、视野、physics tick、攻击、采矿、生产、副官命令、建造和退局重开。不得靠关闭避障/碰撞、缩碰撞盒、停模拟、降低 tick、减少视野或降画质制造假修复。

## 2. 为什么要收紧

当前项目已有 RSI、真实 Match、回归和 champion 概念，但规则容易被模型解释成“先改很多文件，最后统一跑测试”。这会掩盖跨系统回归，尤其是共享 `Movement`、`Unit`、场景、配置和线程/缓存改动。新规则把真实对局闸门前移到每个关键补丁之后。

## 3. 四级阶段

### S0：锁定基线

- 读取仓库规则、技能、计划、当前报告；检查 Git 状态、目标 mtime/hash、Godot 版本和活动实例。
- 从当前 champion 开新局，记录实际实体数、出生位置、单位移动/到达、碰撞/建造、攻击或资源链、退局重开、错误日志和 `cleanup_ok`。
- 建立 `agent/runs/<run-id>/baseline.md`、`checklist.md`、`champion.json`。

### S1：单补丁真实对局闸门

- 每轮只选一个可证伪假设和一组紧密耦合改动。
- 编辑后立即解析/编译；通过后重新启动独立 Godot headless 进程，使用真实 Match 入口，不复用上一局进程。
- 至少验证受影响链路的新行为、一个正向断言、一个反向断言和一条旧功能回放。记录命令、实际位移/到达、伤害或产出、physics tick、模拟秒/墙钟秒、退出码、PID、实例端口和 `cleanup_ok`。
- S1 失败立即拒绝候选，禁止在失败候选上继续改第二个系统；从 champion 开始下一轮。

### S2：阶段复验

- 每完成一个阶段（例如尺寸同步、碰撞/导航、经济/生产、性能线程）运行受影响套件、边界/异常场景和同一命令回放。
- 必须覆盖“新功能通过 + 旧功能未退化”的成对证据；性能改动还要看模拟速度、长帧和命令延迟。
- 视觉变化开可见实例截图并实际打开；headless 只证明逻辑，不证明画面。

### S3：晋级与交付

- 独立会话/探针复核，运行全量回归，比较 candidate 与 champion 的质量向量。
- 任何解析错误、真实对局失败、僵尸房、旧功能退化、错误日志、截图不新鲜或清理失败都拒绝晋级。
- 连续三轮无 champion 提升换诊断方向；连续两轮“新行为通过但旧行为退化”暂停编辑并重画调用链/不变量。

## 4. 证据合同

每轮目录：

```text
agent/runs/<run-id>/
  baseline.md
  checklist.md
  champion.json
  round-01/direction.md
  round-01/patch.md
  round-01/headless_match.json
  round-01/verification.md
  round-01/*.log
  round-01/*.png
```

`headless_match.json` 不能只写 `scene_started`；至少包含真实 Match 入口、实体数、命令数、位移/到达、攻击伤害或资源产出、模拟秒/墙钟秒、physics tick、退出码、错误摘要、PID/实例、产物 mtime 和 `cleanup_ok`。

## 5. 失败处理

- 探针不能复现：修复启动/测试链路，不改产品代码，记录 `blocked: reproduction`。
- 新行为通过但旧链路退化：候选 `reject`，从 champion 重来，不加补丁掩盖。
- 测试红但可能是假红：单跑/串行复核并检查并发、端口、旧进程和证据 mtime，不改断言阈值。
- 性能提升伴随模拟变慢、碰撞变宽、攻击/采矿/生产丢失：候选拒绝。
- 无法获得线程归属或完整截图：如实标 `needs-review`，不能写完成。

## 6. 交付标准

最终报告必须列修改文件、candidate/champion hash、每轮无头真实对局命令与 rc、旧/新行为、截图、回归套件、清理结果、未验证项和回滚方式。未通过 S3 只能交付 `needs-review`/`blocked`。
