## 1. 为什么必须换指标

round-21 我用"平均排名跨度"度量公平性，结果**加轮转之后跨度反而变大**（16.7 → 21.5）。
我在那份报告里写了"疑为指标缺陷"，但**没有验证**。本轮就验它。

那个指标的缺陷是明确的：它量的是"**出现在第几位**"。而一轮里被截断的单位
本来就还排在后面 —— **排名靠后 ≠ 等待久**。真正该量的是"**服务周期**"：
一个单位两次"进入前 `PARALLEL_FILL_CAP`"之间隔了多少轮。

工具 [service_interval.py](agent/runs/2026-10-07-adjutant-continuity-fix/round-22/service_interval.py)。

## 2. 实测：轮转**没有**改善服务周期

| 档案 | 轮数 | 单位数 | **从未被服务** | **最坏间隔** | 间隔 p50 | 间隔 p95 |
|---|---|---|---|---|---|---|
| `9e5627fe`（round-20，**无**轮转） | 167 | 31 | 0 | **73 轮** | 2 | 8 |
| `8c6f5071`（round-21，**有**轮转） | 169 | 29 | 0 | **109 轮** | 2 | 8 |

- **p50 = 2、p95 = 8，两局完全一样** ⇒ 分布的主体没有任何变化；
- **最坏间隔反而从 73 涨到 109 轮**（但这只是单个极值，见下）；
- "从未被服务"两局都是 **0** ⇒ 不存在永久饥饿。

⇒ **轮转在它本该改善的指标上没有可测的收益。**

## 3. 因此必须收回 round-21 的归因

round-21 我写的是"加轮转后 p95 8.20 → 4.95 秒"，并把它当作轮转有效的证据。
**这个归因站不住**，因为：

1. 轮转本该压缩"服务周期"，而服务周期的 p50/p95 **纹丝不动**（2 / 8）；
2. 最坏间隔**变差**（73 → 109）；
3. p95 的 8.20 → 4.95 是**单局对单局**的读数，而这一路我用的都是
   "每轮一个对局"的比较法 —— 我在每份报告里都标注了"不是严格 A/B"，
   但**仍然把连续下降当成了因果链**。这是本轮要纠正的推理错误。

**结论：那 3.25 秒的差别更可能是局间波动（run-to-run variance），不是轮转造成的。**
我此前那条"五轮单调下降"的叙述因此**被削弱**：它至少有一部分是
"每轮换一局 + 恰好一路往好的方向走"。

## 4. 那这一路的下降（32.15 → 4.95）到底是真是假？

需要分开看，不能一竿子打翻：

| 修复 | 证据强度 | 说明 |
|---|---|---|
| 意图 id 跟着目标走（r13） | **强** | 机制侧独立证据：不同 id 数 33.0 → 50.8（同口径代码行为） |
| 到达即释放占用（r15） | **强** | 机制侧独立证据：`busy` 出口归因 1232 次，且 `arrival_marker_kept=60` 实测生效 |
| 资源字段名 + 换矿（r18/19） | **强** | 代码级字段名逐字对照 + 运行时回包证据；接受率 14/154 → 53/163 |
| **轮转服务顺序（r21）** | **弱 → 本轮被推翻** | 目标指标无变化 |

所以：前三项有**机制侧证据**支撑，仍然站得住；第四项（轮转）
**只有单局 p95 读数**支撑，本轮用更合适的指标把它否掉了。

**这也给出一条方法论教训**（值得写进下一轮的检查清单）：
**每次改动都必须配一个"它本该改善的指标"，并在改后立刻量那个指标。**
不能拿一个总指标（p95）的波动去证明一个针对性改动有效 —— 这正是本轮之前的做法。

## 5. 下一轮（round-23）

1. **保留还是回退轮转？** 它现在**没有可测收益**，但也**没有可测危害**
   （p50/p95 间隔不变、"从未服务"= 0 两局相同）。我倾向**保留**（改动只有顺序、
   行为面很小），但**明确标注"未证明有效"**，并把它从"改善清单"移出。
   —— 这属于"拿不准就问用户"的范畴：是否要把一个未证明的改动留在树里，
   我会在报告里提出，但**不擅自**把它算成成绩。
2. **给 p95 做一个真正的多局对照**：同一配置跑 3 局取中位，
   再和"回退轮转"或"回退资源修复"的 3 局比。单局比较这条老问题必须在这里解决 ——
   否则后面每一轮都会重复"我改了、数变好了、但是不是它改的说不清"。
3. 剩余 p95 ≈ 4.95 秒的**真实**成因仍然没查到。在拿到多局基线之前，
   我不应再基于单局读数做归因。

## 6. 未验证 / 边界
