# AI 副官地图解析与主动提案审计报告

日期：2026-10-06
状态：**needs-review**

本报告针对用户最新截图和要求，审计“地图事实 → 小模型 → 战前建议”的真实链路。本轮只做读代码、独立探针和直接模型请求，没有修改产品代码。

## 结论

当前问题不是单一的“模型没启动”：

1. 本地小模型端点可达，模型列表包含 minicpm5-adj-16k:latest，直接给固定地图事实时能返回具体建议。
2. 地图情报解析器存在确定性 bug：地图源文件有 16 个 Resources 节点，但 StrategicMapIntel 解析结果为 0 个资源。
3. 资源解析为 0 后，发送给模型的上下文只有资源数量，没有资源坐标、数量、到出生点距离和敌方槽位位置；模型不可能凭空补出这些事实。
4. 当前页面只有玩家输入后才调用 AdjutantChatService.send()，没有“地图解析完成后副官自动给出初始方案”的请求。
5. 当前请求默认 max_tokens=512，小模型会把预算消耗在 reasoning，出现 finish_reason=length 且 message.content 为空；这被页面当成空/失败，不能作为主动提案协议。
6. 当前 UI 仍然把“未知”放在主要事实位置，且玩家必须输入多轮问题；这与“副官主动提案，玩家只同意或改变”的产品目标不符。

## 证据

### 1. 用户截图

截图中页面已经显示地图和四个出生点，但四张出生点卡片均显示“附近资源：未知”。聊天内容是：

- 玩家先输入“你好”；
- 副官回复“摘要中未提供敌方单位/资源/实时情报”；
- 玩家继续追问资源点和战术；
- 副官仍然只能重复“需要补充战情摘要”。

这说明当前页面没有完成“主动分析”，也没有把静态地图情报喂给模型。

### 2. 独立地图解析审计

探针：agent/runs/2026-10-06-adjutant-map-audit/intel_audit.tscn

结果：agent/runs/2026-10-06-adjutant-map-audit/intel_result.json

| 项目 | 结果 |
|---|---:|
| 原始 PlainAndSimple.tscn 的 Resources 节点 | 16 |
| StrategicMapIntel 解析出的资源 | 0 |
| 原始出生点 | 4 |
| StrategicMapIntel 解析出的出生点 | 4 |

根因在 _parse_resources()：节点头部和 transform 位于不同的场景文件行，旧代码却要求同一行同时包含节点名和 transform，因此所有资源被跳过。

原始地图中已经存在出生点 1 附近的资源事实，例如：

- (26.9272, 57.2079)，距出生点 1 (40, 28) 约 32m；
- (5.01005, 28.8388)，距出生点 1 约 35m；
- (35.573, 65.7412)，距出生点 1 约 38m；
- (61.5127, 55.608)，距出生点 1 约 35m。

所以截图里的“附近资源：未知”是产品读取错误，不是地图真的没有资源。

### 3. 小模型直接链路审计

探针：agent/runs/2026-10-06-adjutant-map-audit/source_and_model_audit.py

结果：agent/runs/2026-10-06-adjutant-map-audit/source_and_model_result.json

- GET http://127.0.0.1:11436/v1/models 成功；模型包括 minicpm5-adj-16k:latest。
- 直接发送包含出生点、资源坐标和敌方出生点的固定事实，模型在较大输出预算下返回了“先前往资源点”一类的具体建议。
- 一次默认 512 token 请求的 finish_reason 为 length，正文为空但 reasoning 有内容；这说明当前请求预算/思考协议不适合直接作为 UI 正文协议。

## 当前候选的处理决定

- 当前“地图 UI 已完成、战略层已完成”的候选拒绝提升为 champion；事实层和主动提案层仍是硬门禁失败。
- 当前 champion 暂保留为上一轮可返回的 UI 基线，不把现有截图中的“资源未知 + 玩家主动提问”当作产品完成状态。
- 连续未提升轮数：0；需要换成“确定性地图分析包 + 主动提案状态机”的新方向。

## 下一阶段硬门禁

1. 地图源节点数与解析结果一致，至少验证两张真实地图。
2. 选择出生点后，副官自动完成一次地图简报，不要求玩家先输入问题。
3. 简报必须包含玩家附近资源的坐标/距离/有效数量或明确未知、敌方/其他占用出生点及来源、地形/桥/水域事实或明确未知。
4. 小模型正文为空、只返回 reasoning、超时或非法格式时，页面不能显示“已回复”；必须重试或进入可见失败状态。
5. 玩家流程主要只有“同意方案”“调整方案”“换一个方案”；自由输入作为可选补充，不是主流程。
6. 没有创建 Match、没有执行命令、没有把模型建议当成已执行动作。
