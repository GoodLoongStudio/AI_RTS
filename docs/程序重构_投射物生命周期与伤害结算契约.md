# 投射物生命周期与伤害结算契约

对应进度：`CMD-028`

## 1. 已确认规则

任何已经完成“发射”的攻击都获得独立生命周期：

- Stop、切换命令、切换交战姿态或开火策略，不删除已经发射的投射物；
- 发射单位阵亡或退出 SceneTree，不删除在途炮弹、导弹或其他攻击；
- 发射时快照本次攻击所需的伤害、阵营/来源 ID、目标或落点等数据，命中时不再依赖发射单位 Node；
- 伤害在视觉命中或约定的命中时刻结算，避免“先扣血、炮弹后到”的表现分裂；
- 已经发射的攻击不因来源失效而取消，允许单位阵亡前留下最后一发有效攻击；
- 目标先行死亡或失效时，投射物继续按剩余制导能力飞向最后有效位置并正常引爆；爆炸仍可伤害爆点范围内的其他单位，但不得访问已失效 Node 或对同一对象重复结算；
- 后续 AoE、友伤比例、护甲等规则只改变命中结算，不改变投射物的独立生命周期。

## 2. 目标、爆点与受伤对象必须分离

投射物不得把命令指定目标直接当成唯一受伤对象。一次攻击至少包含四个不同概念：

| 概念 | 含义 |
|---|---|
| 指定目标 | 玩家或 AI 下令攻击的实体，只是初始制导参考 |
| 当前瞄准点 | Guidance 根据目标运动、情报和自身跟踪能力计算的期望位置 |
| 实际爆点 | 投射物受速度、转向上限、障碍碰撞和引信影响后真正引爆的位置 |
| 受伤对象集合 | Warhead 在实际爆点附近查询得到的全部合法伤害对象 |

因此，导弹即使没有直接碰撞指定目标，也可以通过 AoE 命中附近单位或建筑；混战中的意外爆炸同样必须影响爆点范围内的敌军、友军和其他可伤害对象。指定目标身份不能成为伤害过滤条件。

建筑和大型单位的范围命中应按其 footprint 与爆炸范围的相交关系判断，不能只比较对象中心点。直接命中可以在未来配置额外奖励，但本质上仍是“距爆点最近”的一种 Warhead 结算情况。

## 3. Guidance、Fuse 与 Warhead 边界

- `Guidance` 只更新投射物的运动方向或当前瞄准点。最大转向速率、跟踪刷新率、目标信息丢失和预测能力属于制导参数；较弱制导允许对移动目标脱靶。
- `Fuse` 只决定何时以及在哪里引爆，可支持接触、近炸、定时或到达地面落点等模式。
- `Warhead` 只在实际爆点执行一次空间查询和伤害计算，不关心最初由谁被指定为目标。
- 三者均使用发射快照，不依赖发射单位继续存活；同一投射物必须通过稳定 ID 或一次性标志保证只引爆一次。
- 范围内候选对象应按稳定 UnitId 排序后结算，为回放、多人同步和测试提供确定性。

友军默认承受完整基础伤害；`CMD-024` 后续把 `FriendlyFireDamageMultiplier`、距离衰减、弹头半径和可能的直接命中奖励纳入版本化数值管理。当前接口先预留这些参数，不在投射物脚本中散落硬编码平衡值。

## 4. 当前代码审计

当前 Legacy 实现不满足上述契约：

| 实现 | 当前行为 | 风险 |
|---|---|---|
| `CannonShell` | 作为发射单位子节点；在 `_ready()` 立即扣除实体目标 HP | 发射者死亡会删除视觉；伤害早于视觉命中 |
| `Rocket` | 作为发射单位子节点；命中动画回调读取父单位 `attack_damage` | 发射者死亡会删除导弹并失去结算来源 |
| `Rocket` 目标退出 | 直接 `queue_free()` | 在途导弹瞬间消失，缺少末端视觉 |
| 地面 ForceAttack | Action 先直接结算落点伤害，再创建发射者子节点视觉 | Stop/阵亡后视觉可能消失，伤害与视觉生命周期分离 |

因此，“Stop 后允许在途弹继续命中”目前只在部分即时伤害路径上表现为伤害已经发生，并不代表独立投射物契约已经实现。

## 5. 重构边界

`CMD-028` 应建立独立的投射物生成/结算入口，由 Match 级容器或专用服务持有投射物，而不是把投射物挂在发射单位下。发射事件至少应携带不可变快照：

- 来源稳定 ID 与阵营；
- 基础伤害及必要的伤害类型；
- 发射世界坐标和视觉朝向；
- 实体目标稳定 ID 或地面落点；
- 发射时模拟 Tick；
- 后续友伤、AoE 和护甲计算所需的版本化数值引用。

本切片不与 Stop 提交混合，避免在修订命令语义时同时改变全项目伤害时机。实施时必须覆盖 CannonShell、Rocket、地面 ForceAttack，以及以下自动测试：

- 发射后来源阵亡，投射物仍完成飞行和命中；
- 飞行中指定目标先失效，投射物在最后有效轨迹上引爆；
- 移动目标超过低制导性能后发生脱靶；
- 未直接碰撞指定目标但 AoE 仍命中附近敌军；
- AoE 同时覆盖非指定敌军、建筑和友军，并分别产生正确伤害；
- footprint 与爆炸范围相交但对象中心在范围外时仍能命中；
- 同一爆炸对每个对象最多结算一次。
