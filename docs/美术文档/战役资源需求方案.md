# AI_RTS 战役资源需求方案

> 状态：Canonical  
> 用途：主策评审 / 美术任务拆分 / 外包拆分  
> 适用阶段：首个战役《回声撤离》  
> 说明：本文件只定义当前战役需要准备的美术资源，不做制作排期；音频不作为本文件重点。

---

## 1. 优先级定义

- **P0：首发必需**。缺失会直接影响首个战役可玩性、辨识度或核心体验验证。
- **P1：完整战役必需**。不阻塞最早期切片，但进入完整战役必须补齐。
- **P2：品质补充**。主要提升氛围、叙事和完成度，可在核心内容稳定后继续补充。

资源拆分原则：每项必须能直接成为一条内部制作任务或一份外包任务单，不使用“做一些场景”“补一些特效”这类不可验收描述。

|---|---:|---|---|---|

| 人类阵营视觉规则 | 1 套 | 阵营颜色、识别符号、材料、工业设计语言、灯光规则 | P0 | 玩家单位、建筑、UI 必须统一 |

# 13. 每项资源交付字段

所有正式制作任务或外包单必须至少带以下字段：

- 资源名称；
- 数量；
- 类型（模型 / 材质 / VFX / UI / 概念）；
- 使用位置；
- 规格 / 用途；
- P0 / P1 / P2；
- 优先级理由；
- 是否可复用；
- 主要状态；
- 尺寸基准；
- 授权 / 来源；
- Godot 导入状态；
- 战役场景验收状态。

最终验收必须放回 RTS 正常镜头、战争迷雾、任务标记和实际战斗中检查，不能只看单独模型截图。
