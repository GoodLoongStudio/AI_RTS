### U1-a F05 真因：**空域导航地图未激活** → 无人机所有路径查询失败（已定位到具体机制）

**现象回放（档案）**：`archive_5d6cdb0e` 里 `rule-fill-scout-Unit_1-*`（无人机 Unit_1）被
`movement_gated:no_path` 拒，无人机全部采样位置不变，`scout_first_coverage=0.0`，
末尾 `no_path` / `wait` 各 608 次 —— 而档案把原因**折叠成一个 `no_path`**，无法归因。

**实验（`tmp_logs/campaign_accept/probe_u1_path.py`，同刻对照）**：

```
空中 Unit_1(drone)  near/far/edge  ok=False reason=navmesh_unavailable  waypoints=0
地面 Unit_0         near/far/edge  ok=True  domain=terrain  waypoints=2/2/2
域级 terrain ok=True ／ 域级 air ok=False navmesh_unavailable
```

**进一步到游戏侧（新增 `NAVDBG air` 诊断，`u1air` 局日志）**：

```
NAVDBG air polygons=2 vertices=4 region_map_valid=true map_active=false   ← 网格烘出来了，但**地图没激活**
NAVDBG bake map=/root/Match/Map ... polygons=114 vertices=100            ← 地面正常
```

即：**不是"这张图没有空域网格"，也不是"两点不连通"**，而是空域 `NavigationMap` 处于
`active=false` → `NavigationServer3D.map_get_closest_point_owner()` 对空域恒非法 →
`op=adjutant_nav_path` 对空中单位恒 `navmesh_unavailable` → 副官把无人机判成"没路"。

### U1-a2 ⭐根因已闭环：空域 map RID 曾被 free → 已修，真机验证通过

**机制（比"激活不生效"更准确）**：`Navigation._release_server_owned_navigation_resources()`
会在加载流程里调用 `air.release_navigation_map()`，它 **free 掉本节点直接创建的 map RID**；
同一场景节点被复用时（`_ready` 早已跑过、`@onready` 不会重跑），随后 `bake()` 里
`region_set_map(region, 失效RID)` 会把 region 挂到**默认世界地图**上
（所以 `region_get_map().is_valid()` 仍为 true，极具迷惑性），而真正的空域地图已是失效 RID →
`map_set_active(true)` 静默无效 → 空域查路恒 `navmesh_unavailable`。

**修法**：新增 `AirNavigation._ensure_navigation_map()`（失效即**重建** + 参数 + 挂 region + 激活），
在 `_ready()` 与**每次 `bake()` 开头**都调用；诊断行升级为
`NAVDBG air polygons=… rid_valid=… region_on_our_map=… map_active=…`。

**真机验证（`u1fix4` 局）**

```
NAVDBG air polygons=2 vertices=4 rid_valid=true region_on_our_map=true map_active=true
空中 Unit_1 near/far/edge 全部 ok=True waypoints=3
```

### U1-b `F01` 已实现：探索前沿 + 访问记忆（函数级已复验，真机 T01 待补）

**实现**（`graph/rules_fallback.py`，唯一口径）：地图按可用区切成 `EXPLORE_CELL_M=24m` 的格，
格中心为候选前沿；`explore_frontier()` 负责选择与记账：

- **到达 → 换前沿**：用**既有路线事实**结算（`routes[unit].invalidated_reason == "arrived"`），
  不新增埋点；`covered` 计数即 T01 要的"不同可达前沿数"；
- **受阻 → 退避**：同一前沿连续 `EXPLORE_MAX_FAILURES=3` 次失败 → 标 `unreachable` 并换目标；
- **记忆有界**（`EXPLORE_MEMORY_LIMIT=128`，超限丢最早）、**确定性**、**情报偏置**
  （有情报时按"离情报点最近"排序，理由是 `toward_intel`）；
- **网格建在可用区内**（不是整图再逐点夹取）——后者会让贴边多格夹到同一坐标，
  "换了前沿"在坐标上看不出来（实测踩到 `[40,12]` 重复）。

**接线**：`military_waypoint(..., state=, unit=, ring=)`（并行填充侦察/前压 + 行为树前压共用同一份记忆；
树通过黑板的 `state_ref` 传**引用**，否则记忆每轮被拷贝、永远停在初始状态）；状态字段 `explore`
（`AdjutantGraphState` + `GraphStateDict` + `to_dict/from_dict` + `summary()` + runner 的 rounds）。
