# 程序重构：公共查询与观察权限纵向样例记录

## 1. 完成范围

本纵向样例建立了不依赖 Godot 的查询契约与权限服务，并接入 Match 级 Godot 只读快照：

- `GetOwnForces`：返回观察者自己的单位与建筑；
- `ScanCircle`：只返回范围内当前获准观察的实体；
- `InspectOwnEntity`：只允许按稳定 ID 查询己方单位或建筑；
- `GetOwnEconomy`：返回自己的权威整数资源余额和账户版本；
- `IBudgetedWorldQueryService`：固定未来大模型强制操作点装饰层的类型边界，本轮不实现扣费规则。

## 2. 安全与权限实现

- `WorldQueryService` 构造时接收组合根预先生成的 `QuerySessionGrant`，查询请求本身不含观察者玩家 ID 或全知开关。
- 非 `OmniscientDebug` 来源无法创建全知 Grant，非法配置在服务构造阶段拒绝。
- 未知会话在读取世界仓库之前拒绝。
- 普通和调试会话使用不同随机 ID；正式 Agent Gateway 不得暴露测试会话取得入口。
- 当前 Godot Runtime 的 `GetStandardSessionForTests` 与 `GetDebugSessionForTests` 只服务重构期测试，不属于未来外部 Agent API。
- `IBudgetedWorldQueryService` 未来必须先原子扣费，再调用底层 `IWorldQueryService`；Agent 组合根只注入前者。

## 3. 数据边界

- Domain/Application 不包含 Godot 类型。
- 查询结果只包含不可变稳定 ID、位置、类型、关系、可空生命值和实际返回字段掩码。
- Godot Adapter 每次查询复制同一物理帧的单位、建筑、资源和经济账户数据，不返回 Node 或节点路径。
- 合法空范围稳定返回 `Accepted`、空错误码和非空 `entities=[]`。
- 己方实体不依赖画面 `Node.visible`；敌方和中立实体按观察者自己的单位视野计算。
- 当前 Demo 没有联盟规则，除自己和中立外暂解析为敌人；`Ally` 已预留。

## 4. 自动验证

纯 C# 新增 8 项测试：

1. 己方信息不受视野集合影响且位置、HP 准确；
2. 合法空范围显式成功；
3. 普通与全知调试会话的视野结果不同；
4. 未授权敌军 HP 不通过零值或字段掩码泄漏；
5. 敌军与未知 ID 的直接查询错误不可区分；
6. 己方经济余额和版本准确；
7. 非法会话不会触达世界仓库；
8. 非有限坐标或非正半径在读取世界前拒绝。

Godot `WorldQueryRuntimeSmokeTest` 验证：

- Match 为 Human 签发标准和独立调试会话；
- 己方 Tank 数量、HP 和 ID 查询正确；
- 不能从己方引用入口取得敌军引用；
- 空范围保留 `entities` 空数组；
- 敌方建筑移出视野后普通会话不可见、全知调试会话仍可见；
- 己方经济结果显式包含余额字典。

## 5. 已知限制与后续工作

- 敌军建筑 `LastKnown`、重新侦察清除和观察版本已在后续 QUERY-002 纵向样例实现，详见《程序重构_敌方建筑LastKnown观察纵向样例记录》。
- 当前视野按圆形距离和现有 sight range 计算，不处理高低差、遮挡、隐形、伪装、间谍和共享盟友视野。
- 传统规则 AI 仍有直接遍历 SceneTree 的 Legacy 读取；迁移至查询接口归入 RAI-001。
- 操作点余额、计价、空查询扣费、内部错误退款和跨进程 Gateway 尚未实现。
- 测试会话取得方法不得复用为正式外部 API。
