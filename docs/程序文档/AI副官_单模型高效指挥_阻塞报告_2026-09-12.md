## 二、剩余阻塞（需要用户/GPT 决策或额外信息）

### 阻塞 A：**已查清 = 游戏侧缺 "续建（construct）" 路由**（Rejected/Occupied ×32）

- 现象：`rule-build-finish-Unit_6|build` 被权威端连续 `Rejected / reason=Occupied`。
- **根因（已定位到代码）**：游戏侧 `build` 走 `placement_runtime.Place(...)`（= **新建一座建筑**，
  `DebugControlServer.gd` 约 474 行），而车厂**已经放置过**（`constructed=False` 是
  "已放置未完工"）→ 在同一位置再 `Place` 必然 `Occupied`。
- **游戏本身已有正确的续建通道**（人类 UI 走的就是它）：
  - `source/match/units/actions/Constructing.gd`：
    `is_applicable(source_unit, target_unit)` = `Worker` + `Structure` + `not is_constructed()` + 同玩家；
    `_ready()` 即 `_construct_or_move_closer()`（自动走近并施工）。
  - `source/match/players/human/UnitActionsController.gd:625`：
    `Constructing.is_applicable(unit, target)` → `gateway.ConstructUnits([unit], target)`。
  - `source/net/NetSync.gd:609`：命令 `"construct"` → `gateway.ConstructUnits(units, target, issuer)`。
- **缺口**：副官意图通道的动作集是
  `["move","attack_move","attack","gather","stop","produce","build"]`
  （`DebugControlServer.gd:1528`），**没有 `construct`**，也没有"build 目标是未完工己方建筑 →
  改走 ConstructUnits"的分支。
- **两侧改法**（协调改动，本次会话只完成了副官侧）：
  - ✅ 副官侧（已改）：阶梯的续建意图 target 现在**同时带 `entity_id` = 工地实体名**
    （`rule-finish-site-<site>-<tick>`，`rules_fallback.development_intents`），
    游戏侧据此就能解析到目标实体。
  - ⛔ **待游戏侧补（唯一阻塞）**：在副官意图翻译/执行处加一条——
    当 `action=build`（或新增 `construct`）且 target 指向**己方未完工建筑实体**时，
    调用 `gateway.ConstructUnits(units, target_structure, player)`，而不是 `PlaceStructure`；
    并把 `construct` 加进 `available_actions`。
    （新建筑仍走 `PlaceStructure`；两者用"目标是否为未完工己方建筑"区分。）

### 阻塞 B：旧 checkpoint 里的在途意图被继续下发（"旧结果复活"）

- 现象：阶梯已不再生成 `rule-produce-tank-Unit_6`，但权威端**最新**几条仍是
  `produce Tank / ProducerNotConstructed` → 说明**恢复的对局状态里仍有旧意图**在每轮下发。
- 计划要求："旧结果不得复活 / 请求绑定快照与代际"。**建议修法**：下发前按**当前观测**
  做预校验——生产设施 `constructed=False` 直接丢弃并留痕（`producer_not_constructed`）；
  同样规则也应加在模型侧（`squads.py` 给 facility actor 带 `constructed`，
  `task_patch._check_actor_capability` 拒绝未完工设施）。

### 阻塞 C：2B 不保证按「发展候选」菜单发展

- 已按计划补上候选菜单（`发展候选: W1造V1(aircraft_factory) | F1产U5(worker) Q2 |
  F2产U3(soldier) Q2 | 维持现有任务`，输入 434 字符），但同一轮模型只回
