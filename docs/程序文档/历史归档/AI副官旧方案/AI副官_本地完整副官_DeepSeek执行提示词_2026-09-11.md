## 必须保留的设计

- 一个真人玩家，本机 Godot 权威端、本机 Python runner、本机 Ollama。
- 默认模型 `maternion/minicpm5:2b`。LangGraph 通过 PydanticAI 调用这个模型，不是两层各配一个模型，不强制串行两次推理。
- LangGraph 管理异步状态与事件；PydanticAI 负责结构化调用；模型给出阶段目标和小队任务；游戏任务执行器、行为树或现有状态机持续执行。
- 云端 API、服务器转发、隧道和 Hermes 不在实时链路。Hermes 的对局外职责本轮不扩展。
- 一局最多一个在途模型请求，观测、玩家控制和回执不能等待模型；有界重试，拒绝过时结果，不堆积推理线程。
- 运行时身份、快照、期限、控制代际和任务版本由程序绑定。代际以游戏权威端为准，不能提交时换成最新代际，也不能用多个单位的最大代际代替逐对象校验。
- 玩家手动命令立即生效，即便单位尚无 AI 租约也必须记录控制权。玩家未确认时，完成玩家命令后保持位置和正常自卫，不自动交回。

## 模型接入与验证

优先实测 PydanticAI NativeOutput 的 JSON Schema 支持，不兼容再使用 PromptedOutput，不默认采用 tool calling。不依赖旧自制代理。原生 Ollama 与兼容接口参数不同，确认关闭思考、上下文窗口和输出上限真实生效。

初始参数为上下文 4096、输出上限 512 token、温度 0、总期限 4 秒，自动纠错最多一次并包含在总期限内。参数可按证据调整，说明原因。

此前几个短合成请求约 0.25～1.06 秒，但出现过攻击目标类型错误，而且多数测试直接告诉模型应该采取什么动作。不要把这个结果当作自主判断能力或真实 P95 已达标。

至少进行 100 次真实模型请求，采用真实观测或明确标注的回放，包含经济取舍、基地受袭、未知区域、撤退、玩家介入与多小队冲突。分别统计首次结构合法率、语义合法率、修复次数、超时率和 P50/P95；不要用提示词泄露答案，也不要把规则选择冒充模型判断。

在游戏同时运行、真实输入规模下，热态目标 P50 ≤ 1.5 秒、P95 ≤ 4 秒。未达到时先检查配置、上下文和异步实现，再与已安装模型做同条件对比；不要静默更换默认模型。
