# 地图 ×2 与单位放大 · 联动核查清单（2026-09-27）

> 写给正在做「单位尺寸审计 + 地图扩大 2 倍（台地/山高度不变）」的会话。
> 来源：并行会话（负责炮口/弹道/重坦数值/随机地图生成链路修复）对全仓尺寸耦合点的核对结果。
> **地图 ×2 落地前请逐项打勾。** 带 ⛔ 的是会静默失败、玩家侧直接可见的。

## 一、已经自适应、不用动的（已核对代码）

- 相机高度：`IsometricCamera3D.gd` 已是"30m 锚点"制，任何地图尺寸开局都精确 30m；拉远上限 0.24×边长自动缩放。
- 战争迷雾 / 小地图：`px_per_m` 按地图尺寸自适应 + 上限钳制（`Minimap.gd` MAX_MINIMAP_VIEWPORT_EDGE）。
- 相机 far 面：按 size 公式自适应（`_align_camera_far_to_size`）。
- 大图性能路径：G4 逻辑地形寻路、建筑淡出关闭（≥256）、性能治理——512 自动命中既有分支。

## 二、⛔ 地图 ×2（G4 256→512）会静默失败的

1. **mapgen 台地半径不随地图缩放**：`rtsmap/gates/g2_strategy.py` 的
   `make_plateau(c, radius * params['neutral_plateau_scale'], …)` 只乘 1.7，
   没有 extent 因子。512 图上台地相对尺寸减半 → `plateau_top_fraction ≥ 12%`
   结构性失败 → pipeline 退保底烘焙 → **玩家拿到的是固定布局图**（job.json 里
   `baked: true` 是唯一线索，界面上看不出）。
2. **并行会话 2026-09-24 调过的全套参数只在 256 验证过**：山体净空 `clearance > 3.`、
   国道核心带 `+1.5m`、桥口净空 9m、`plateau_radius (9,11)`、摆件稀疏密度。
   512 时 `_extent_scale()` 0.5→1.0（回到原始 512 标定），**必须重跑扫参 + e2e**
   （40% 阻碍 / 台地 12% / 公平三项 / 双河六桥全过检才算数）。
3. **G1 出生布局库是 256 画布上的绝对坐标**（`layout_catalog`）：不重建布局或整体 ×2，
   512 图上四家挤在一个象限。
4. 检查手段：`tools/mapgen` 下用 `apply_map_extent(512)` 跑 sweep + e2e，
   看 job.json 的 `baked` 是否为 false、`stages.engine` 是否走完整验收。

## 三、单位/建筑放大 ×2 必须同步的（不改就穿模/挤死）

1. **单位碰撞半径写死在每个单位场景**（不是 balance）：
   `Movement` / `MovementObstacle` 节点的 `radius` 属性
   （Tank 0.8、HeavyTank 0.8、CommandCenter 1.8/2.0，`Unit._get_radius` 直读场景）。
   模型放大 radius 不放大 → 视觉重叠、寻路钻缝、RVO 互挤。
2. **建筑占位半径在 balance**：`constructions[].footprintRadiusMeters`
   （指挥中心 6.0 / 工厂 4.5 / 塔 1.2）。建筑放大必须同步。
3. **矿场自动指派距离**：`OreRefinery.gd` 服务半径 30m、矿边站位偏移——建筑/矿放大后跟调。
4. **桥面容量减半**：RVO 避让半径 = 单位半径；单位翻倍后 10.7m 桥面净宽从并行
   6~7 个单位降到 3~4 个（"桥上卡单位"会加重）。桥宽参数在
   `rtsmap/contract.py bridge_width: 12.0`，视放大倍率同步加宽。
5. **建造放置**：`FindAutoSpot` 螺旋起步半径 5~8m（`StructurePlacementRuntime.cs`）、
   建造间距判定——建筑放大后同调。

## 四、需要用户拍板的设计决策（不要默认不动）

- **射程/移速是否随地图 ×2**：不放大则 20m 射程、2.2m/s 移速的战术意义减半，
  跨图行军时间翻倍；放大则全 balance 数值联动。
- PlainAndSimple 已改 200×200，但 diff 只有 1 行（Map.size 属性）——
  **进游戏确认**地面视觉网格/装饰/出兵点真到了 200（菜单注释自己写着不同步就对不上）。
