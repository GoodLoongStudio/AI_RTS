## 3. 已确认根因与排除的错误判断

### D5 侦察指令双源翻涌 —— 已修
- **现象**：`explore.cells` 300 秒只覆盖 2~4 格；无人机在两套航点源之间反复改目标。
- **根因**：规则并行填充的侦察轨走 `military_waypoint`（有情报时是"0.6×敌距"
  standoff 渐近线），行为树侦察分支走"扩张定向点/定环方位"——两套源、两套判据。
- **修复**：行为树 `_scout_waypoint` 改为直接调 `explore_frontier`（与侦察轨同一份
  记忆、同一个判据）；侦察轨也不再经 `military_waypoint`，直取 `explore_frontier`。
- **排除**：探索算法本身没问题（连续调用模拟可正常遍历网格，16 格全覆盖）。

### D6 情报点形状不兼容导致整条规则层当拍崩掉 —— 已修（重大）
- **现象**：无可见敌人且有情报时，`development_intents` 直接 AttributeError，
  被协调层"阶梯异常绝不允许拖垮微操"整块吞掉 → **生产/建造/采集/军事/侦察轨
  当拍全灭**，只剩行为树零散分支。
- **根因**：`enemy_intel_points` 真实形状是 `[[x, z], ...]`，而
  `military_waypoint` 的情情环用 `observation_view.pos2d`（要 `{"pos": [x,y,z]}`）。
- **修复**：新增 `_intel_point()` 入口一次性兼容两种形状（dict / 原始列表 /
  二维 / 三维），调用方不用各自转换。
- **这条是"大军不压上、生产时断时续"的真因之一**，第 1 轮完全没找到。

### D7 网格格距 > 侦察视野，"敌家在缝里" —— 已修
- **现象**：三局都有单位摸到离敌家 11~12m 却看不见。
- **根因**：探索网格 20m 格距（`EXPLORE_CELL_M=24` → 80m 可用区 4×4 格），
  而 demo 平衡表的视野是**步兵 6m / 坦克 8m / 无人机 10m**——格心圆之间有缝，
  敌家 (69,15) 恰好落在 (60,20) 与 (80,20) 两格的缝里（各差 10.3m / 12m）。
- **修复（两块）**：
  ① **情报点扫描格**：情报点周围按视野步长（10m）铺 5×5 局部网格；
  ② **来袭走廊**：敌情点几乎都在家门口（敌人来打我们的路上被看到），绕它扫
     够不到 50m 外的敌家；沿"基地→情报点"走向从情报点继续往纵深铺点
     （步长=视野、3 条车道、12 步），"敌人从哪边来，家就在那个方向"。
- **验证（模拟）**：det_2 的情报局面下，走廊第 9 跳到达 (67.2,14.5)——
  距敌家 **1.9m**，必然发现。

### D8 前沿结算与发令耦合 → 侦察单位泊车 —— 已修
- **现象**：det_5 无人机飞到 (90,90) 后**泊了 195 秒**；365 个前沿格只有
  1 个 covered。
- **根因**：`explore_frontier`（含位置事实结算）只在单位**空闲**时被调用；
  在途单位不结算 → 它的格永远不记 covered → `hold_assigned` 原样返回同一航点。
- **修复**：侦察轨把"结算/推进前沿"与"发令"解耦——所有侦察类型单位每拍都结算
  （含在途的），只对空闲且不在途的发令。

### D9 无人机被击落即全程失明 —— **未修**
- **现象**：det_9 无人机 t=40 前就没了，之后 0 个建筑可见（全军最近也只到
  离敌家 18~37m，没有单位进过 10m 视野）。
- **判断**：需要"侦察备份"（多造一架无人机 / 专职阵亡后由`pick_scout_executor`
  转交机动单位——该机制存在但本轮没触发，因为转交条件仍只认"专职不在编制"）。
  列入下一轮。

## 4. 实际修改与职责变化

| 文件 | 修改 | 职责变化 |
|---|---|---|
| `graph/behavior_tree.py` | `_scout_waypoint` 直取 `explore_frontier`（有扩张定向点时仍用它，已受军队门槛保护）；无 state 时保留原定环兜底 | 行为树侦察与规则侦察轨**同一航点源** |

`EXPLORE_CELL_M`（全局网格保持 24m，只在情报点周围加密）。

   机制没覆盖"专职阵亡后由谁补位"的执行链（本轮没触发）。

5. **无随机种子集合**（第 1 轮已记录，本轮未实现）——逐局方差大是判据只达成
