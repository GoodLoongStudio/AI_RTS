## 1. 矿场运营参数改为配置驱动

阶段 0 断点 C2 记录：`SERVICE_RADIUS_M=30.0` / `CAPACITY=4` / `CLAIM_INTERVAL_S=2.0` 是
`OreRefinery.gd` 里的裸常量，balance 目录无对应字段。现在走与
`construction_work_per_tick` / `resources_max` **同一套**注入链路：

```json
"unitTypes": [{ "id": "ore_refinery", ...,
  "oreRefinery": { "serviceRadiusMeters": 30.0, "workerCapacity": 4, "claimIntervalSeconds": 2.0 } }]
```

贯通：`OreRefineryDefinitionDto` → `BalanceConfigLoader.ValidateUnitTypes`（半径与间隔必须有限正数、
容量必须正整数）→ `OreRefineryDefinition` → `BalanceConfigRuntime.ConfigureUnit()` 写入
`service_radius_m` / `worker_capacity` / `claim_interval_s` → `OreRefinery.gd` 的三个 `@export`。
`claim_interval_s` 带 setter，配置在 `_ready` 之后到达时也会重建定时器 `wait_time`。
默认数值与旧常量逐位相同，**本次不借配置化偷偷改经济节奏**。

## 2. 修掉阶段 0 定位的两个矿场运营真缺陷

| 缺陷 | 旧行为（file:line） | 现在 |
|---|---|---|
| 半径内无矿仍占名额 | `_nearest_ore_stand` 返回 null（`OreRefinery.gd:163-164`），但 `_assign` 照样写 meta 并计入 `_assigned`（`:131-141`）⇒ 4 个槽位被空占，且这些工人的交货点被改指到远处矿场 | `_claim_tick` 先 `has_serviceable_ore()`，没有矿就 `_release_all()` 直接返回；`_assign` 只有真的拿到矿点才占名额 |
| 指派 meta 只增不清 | 只有 `_exit_tree → _release_all`（`:55-64`）会清；被显式命令调走的工人后续仍把货交给这坐矿场（注释承诺的契约④只对动作成立，对 meta 不成立） | `_supervise_assigned` 每轮复核：meta 已不属于本矿场 → 丢名额；工人转入施工/显式采集/交战等**其它**动作 → 立刻 `remove_meta` 并腾出名额 |

同时新增 `has_serviceable_ore()` 与 `_nearest_ore()`（矿点搜索与站位解耦，供判空与测试复用）。

## 3. 玩家与权威入口不再把 Worker 当开工前置

阶段 0 只记了规则中台的 `if not builders: continue`，实际链路上还有**两道**同样的门：

1. **玩家 HUD**：`Ra3Sidebar._begin_structure_placement()` 先调 `_select_builder_if_needed()`，
   一个工人都没有时直接 `return false` 并提示「所有工人都在建造中」⇒ 玩家明明有 10600 资金却
   连蓝图都进不去。现在按 `_requires_builder_selection()` 判定，只有 `worker` 进度源才要求先选人。
2. **权威命令端**：`DebugControlServer._op_build()` 在 `builders.is_empty()` 时返回
   `UnitsNotFound` ⇒ 副官/脚本在无空闲工人时永远建不了任何东西。现在同样按进度源放行。

两处都新增 `BalanceConfigRuntime.GetConstructionProgressSource(scene)`（C# 侧唯一事实来源），
**查不到配置时一律按 `worker` 处理**——宁可保守地继续要求建造者，也不悄悄放开一条未配置的路径。

另外，`automatic` 工地重复收到 build 意图时不再走 `_construct_on_existing_site`（也不需要），
直接返回 `Accepted / AlreadyUnderConstruction`：阶段 0 记的「同一意图被连续 Rejected×32」
在 automatic 口径下从源头消失。
