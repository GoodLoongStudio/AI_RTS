## 0. 决策地图接入 Laya（2026-09-21 第二轮迭代）

提示词 §2 的"选择用 Laya"从战术四列**扩展到战略分支层**：

| 环节 | 改动 |
|---|---|
| 分支问题 | `frame_to_questions` 新增 `branch` 问（choice：可用路线 + KEEP维持）；候选 = `decision_map.retrieve` 每 tick 筛出的可用节点（恒 ≤20）+ "维持当前主线" |
| 落地链 | Laya 分支答案 → `DecodeResult.goal_ref` + `branch_source="laya"` → `summarize_decode` 透传 → 既有 `note_model_branch`（前置条件复核）→ campaign 主线。**复用既有校验链，不新增旁路** |
| 决策地图 | `retrieve` 把**主线前沿绑定的节点**补进可用列表（实测 D9/D12 常被前置条件筛掉，而主线正沿它推进——菜单里没有主线当前节点，分支就永远学不到主线在做什么） |
| 战略层 | `note_model_branch` 增加 `source` 参数（model/laya 可分辨）；`context_view` 暴露 `mainline_node`（主线实际走向）作为**分支教师标签**（不是模型自述） |
| 训练 | `train_laya.py` 默认监督 `branch` 问；标签取 `mainline_node`（前沿里程碑绑定节点 → 最近已完成里程碑节点 → 首个可用路线 的回退链） |
| 守门 | `DecisionMapBranchTest` 5 个用例（问题结构/goal_ref/KEEP/异步透传/无路线）；全套件 896 测试零新增失败 |
| 标签闭环 | 晋升与标签同源（都在 campaign.py 经 `_mainline_node_id`）后：v9 采集 165 条分支标签**全部在菜单内**（修复前 v8 仅 28/197）；训练样本 branch 从 4 → 169 |

## 1. 循环总览

```
┌──────────────────────────────────────────────────────────────┐
│  ① 自对局（selfplay_match.py，with_ai=True）                  │

│     val 一致率 + 真机胜率/发育对比                              │
├──────────────────────────────────────────────────────────────┘
```

## 3. 数据格式（JSONL，每行一次决策）

| 字段 | 含义 |
|---|---|
| `state` | 当时给 Laya 的紧凑状态文本（含少样本前缀） |
| `questions` / `fine_questions` | 问题集（**完整 criteria**：选项键→描述；含 `branch` 分支问） |
| `laya_answers` | Laya 当次的选择与置信度（教师局为空） |
| `label` | **教师标签** = 该拍实际下发的四列行 + `branch`（主线实际沿用的节点；Laya 被拒时行取自 2B 回退） |
| `laya_accepted` / `fallback_reason` | 该拍 Laya 是否成功、失败原因（含熔断断开） |

每个教师行拆成四个监督样本（task/actor/target/params），标签不在候选项内的跳过
（与推理同源，不教模型选不存在的选项）。

## 4.8 v10 验证局：Laya 分支选择行为（2026-09-21）

`AIRTS_LAYA_MODEL=ft_v2` 跑 240s 学生局（backend=laya, difficulty=0）：

- 186 条记录全部 `laya_accepted=True`、零回退；65 次 `laya_decided` 全 ok；
- **Laya 自选分支 vs 教师标签一致率 94.1%**（175/186）：教师 D12×101/D9×73，
  Laya 自选 D12×101/D9×73/D10×11/D11×1 —— 训练确实把"沿主线"学进去了；
- 新数据落盘 `laya_dataset_v10.jsonl`（186 条）。

**但暴露一个真 bug**：分支教师标签 101/186 条指向**已完成里程碑**绑定的节点
（D12←M06 已完成），Laya 采纳后全被 `note_model_branch` 以 `branch_done` 驳回
（10 次）——等于教模型做一个必然无效的选择。根因两处叠加：
① `_mainline_node_id` 读的前沿 key 写错（战役状态里叫 `next_frontier`，
   `frontier` 只存在于派生视图）→ 每次都走进回退分支；
② 回退取"最近已完成"里程碑的节点 = 陈旧标签。
已修为：前沿取 `next_frontier`；回退改为**优先级最高且未完成**的里程碑绑定节点；
全完成则不给标签（该拍不产生分支监督）。守门测试 `MainlineLabelTest` 4 例
（含"标签必须真的能被 note_model_branch 采纳"的闭环断言）。

## 4.9 双 runner 事故：大军不压上的真根因（2026-09-21，本轮最重要的发现）

v10 局终局 88:31 仍超时，且**敌方建筑一根毛都没掉**。逐层排查后的根因：

1. `ai_controlled_units` 只剩 **9 个建筑**，112 个机动单位全在
   `player_controlled_units` 里 → 军事/侦察轨**没有执行者**，整局 0 条
   `rule-attack`/`rule-advance`（只有 589 条生产）；
2. override 事件来自局服 `_rpc_command` 的 `_notify_adjutant_player_override`
   —— 它对**副官自己的命令**也会发（DCS 侧 `notify_player_override` 有
   `_adjutant_executing` 守卫，NetSync 这条没有）；
3. 客户端日志显示 271 条 `[CMD] 客户端提交 source=adjutant`：**游戏加载页按
   `auto_takeover` 预热了第二个 runner**（连客户端 DCS 24610），它的命令经
   客户端转发链触发 override，把两边 runner 的机动单位托管全部收回。

修复（两处，都不改默认行为）：

- harness：`selfplay_match.py` 显式 `AIRTS_ADJ_AUTO_TAKEOVER=0`
  （游戏侧本就是给隔离测试准备的覆盖开关）；
- 游戏侧 `NetSync.gd`：副官来源标记 `ADJUTANT_SOURCE_MARKER` 随转发命令
  的 `extra` 前缀带到局服，`_rpc_command` 摘前缀后**跳过** override 通知
  （produce/build 的 `scene|cmd_id` 协议原样保留）；DCS `_adjutant_execute`
  期间给 NetSync 打标记。手动玩家命令的 override 语义**完全不变**。

修复后复跑（sp_fix1）：客户端转发命令 271 → **0**，`rule-fill-attack` 0 → **492**，
终局 92:31（战斗真的打起来了，敌人兵力开始掉）。

## 4.10 集结修复：威胁闸门把大军逐个拦散（2026-09-21）

sp_fix1 仍超时，敌人建筑依旧无损。闸门账本：413 次推进只放行 56 次，
`threat_too_high` 拦 222 次。根因：`local_force` 只数**已经进接触圈**的单位，
60 个兵被逐个评估——每个单位只看得到先到的战友，永远凑不齐
`ENGAGE_ADVANTAGE_RATIO`，整支部队卡在威胁圈外缘（这不是"保守"，是**集结动作
从未完成**）。

修复 `movement.committed_support`：战区 = 接触圈内的敌人；路线台账里 `target`
落在任一战区敌人接触圈内的己方作战单位**算即时战力**（"正在赶来打这一仗"的部队）。
"200m 外看戏的友军不算支援"这条纪律不变（他们没有路线，计入为 0）。
第二道判据：已拦下的单位若援军已在赶来 → 降级动作从 `retreat` 改 `hold`
（后撤会把正在集结的大军逐个抽走，v11 实测 114 次 retreat）。

效果（sp_fix2）：推进放行率 13.6% → **85%**（824 次放行 699 次），
`threat_too_high` 222 → 44，`attack_move` 167 → **602** 条且全部 Accepted。
守门测试：`test_local_engagement` +2（赶来算支援/开往别处不算）、
`test_safe_movement` +3（闸门放行/孤立仍撤/降级守卫），全套 905 测试零新增失败。

**仍未闭环**：敌人建筑（3 指挥中心 + 4 炮塔）全程零损伤。当前判断是
"两线作战 + 兵种射程"：分基地开在敌家附近（扩张点 (80,83) 挨着敌情 (83,77)），
一半兵力在家防守；且 demo 口径下步兵步枪 0.5 伤/6m 射程，
敌方防空/反地炮塔 2.0 伤/16m 射程——纯步兵海冲不动机炮要塞。
下一轮方向：优先产坦克（3.5 伤/7.5m）并集中全军打一边，别再两线分兵。
