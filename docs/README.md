## 文档状态建议

新增长期文档建议在开头标记：

- `Canonical`：当前权威规则；
- `Draft`：待评审草案；
- `Implementation Record`：实施/迁移历史记录；
- `Deprecated`：已被新方案替代但保留用于追溯。

原则上不要删除有追溯价值的历史文档，但必须避免让历史记录看起来像当前权威规范。
