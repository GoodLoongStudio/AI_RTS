## 文档状态约定

- **Canonical**：当前规则或架构权威入口；
- **Implementation Audit / Implementation Record**：有时间边界的代码审计、实现与测试证据，不自动代表当前全绿；
- **Draft**：待评审计划；
- **Deprecated / Historical**：已被当前方案覆盖的旧稿，保留追溯，不作为新功能验收依据。

若规则与代码/配置/CI 冲突，先明确日期和生效范围并同步上述权威文件；不通过删除测试、扩大审计豁免等方式假装验收通过。
