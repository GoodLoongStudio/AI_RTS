## 1. 使用方法

1. 在 Godot Project Manager 中导入 `AI_RTS-refactor/project.godot`，不要误开另一个工作树。
2. 等待首次资源导入结束；`.godot/` 是本地缓存，不提交。
3. 首轮按“主项目流程”体验，再对 `tests/manual` 中五个场景逐个使用“运行当前场景（F6）”。

5. 崩溃、卡死、文本异常、行为不同但仍可玩，都不能直接写“通过”，应写明差异。

## 2. 已知基线注意事项

- 现有 AICommandHUD 是关键词 Mock，不会连接大模型。
- 自动化 `CampaignSmokeTest` 当前存在假阳性：设置按钮节点名断言失败后仍打印成功并退出 0。
- 首次运行需完成模型和翻译等资源导入；不要提交 `.godot/imported`。
- 战斗中攻击者与目标水平位置重合会在通用攻击朝向逻辑持续触发 `looking_at` 错误，可能表现为直升机或整局卡住；重构后出现同一现象不能直接记为迁移回归。
- 初始建筑靠近地图角落、部分模型越界、边缘滚屏范围过大，以及建造/生产交互时仍触发边缘滚屏，均已作为旧版本问题登记。
- 详细缺陷归因和素材来源见《程序重构_素材来源审计与既有问题登记.md》。
