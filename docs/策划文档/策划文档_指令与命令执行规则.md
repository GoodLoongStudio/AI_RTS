# 策划文档_指令与命令执行规则

> 状态：已完成  
> 本文定义当前 RTS Demo 中指令如何转化为单位命令，以及命令的接受、执行、覆盖、暂停、完成和失效规则。  
> 前置规则：《策划文档_基础交互逻辑文档》。

---

# 1. 术语

- **指令**：玩家、AI 副官或系统提交的一次控制请求，对应程序中的 `Command`。
- **命令**：单位接受指令后实际进入执行状态的行为，对应程序中的 `Order`。
- **当前活动命令**：单位当前仍可继续变化的唯一活动命令。

当前 Demo 不为 AI 单独建立另一套单位命令。AI 副官最终使用与玩家相同的正式指令入口。

---

# 2. 核心规则

> **同一单位同一时间只保留一个当前活动命令。新的有效命令创建后，旧活动命令被取消，新命令成为当前活动命令。**

统一流程：

```text
指令产生
↓
合法性检查
↓
执行端接受 / 拒绝
↓
创建单位命令
↓
进入执行中
↓
状态继续变化
↓
到达 / 完成 / 暂停 / 不可达 / 目标丢失 / 取消 / 单位失效
```

无效指令不会覆盖当前合法命令。

---

# 3. 当前正式单位命令

当前程序正式存在的单位命令如下：

| 策划名称 | 程序命令 | 含义 |
|---|---|---|
| 移动 | `Move` | 移动到指定世界位置 |
| 靠近目标 | `ApproachEntity` | 靠近指定战场实体，到达要求距离后完成 |
| 跟随目标 | `FollowEntity` | 持续跟随指定单位或建筑 |
| 强制移动 | `ForceMove` | 以强制移动语义前往指定位置 |
| 地面攻击移动 | `GroundAttackMove` | 向指定位置推进，并按当前交战策略处理中途敌人 |
| 目标攻击移动 | `EntityAttackMove` | 以敌方实体为最终目标推进，并处理中途敌人 |
| 战术撤退 | `TacticalWithdraw` | 向指定撤退位置移动，具备倒车能力时使用倒车撤退 |
| 普通攻击 | `Attack` | 攻击指定敌方实体，并受当前开火策略约束 |
| 强制攻击 | `ForceAttack` | 明确强制攻击指定实体 |
| 地面强制攻击 | `GroundForceAttack` | 持续强制攻击指定地面位置 |
| 采集 | `Gather` | 持续执行采集、返程与交付循环 |
| 施工 | `Construct` | 前往施工现场并持续贡献施工工作量 |

当前正式命令中不包含巡逻、保持位置、通用交互、技能命令或独立 AI 命令。

---

# 4. 不创建单位命令的控制操作

以下操作会改变单位执行状态或持续策略，但本身不建立新的 `UnitOrderKind`：

| 操作 | 作用 |
|---|---|
| 停止移动 | 停止当前位移，并暂停当前移动类活动命令 |
| 停止 | 统一停止当前主要行为 |
| 设置交战姿态 | 设置侵略 / 警戒 / 固守等持续交战规则 |
| 设置开火策略 | 设置自由开火 / 停止开火 |
| 取消强制攻击 | 取消当前显式强制攻击，不影响普通自动攻击规则 |

交战姿态与开火策略是持续状态，不属于一次性单位命令。

---

# 5. 命令状态

当前程序中的命令状态统一为：

| 状态 | 含义 |
|---|---|
| 已接受 | 命令已经通过校验并创建 |
| 执行中 | 单位正在执行命令 |
| 暂停 | 命令仍被保留，但不会自动继续执行 |
| 已到达 | 单位已经到达目标位置 |
| 已完成 | 持续任务正常完成 |
| 不可达 | 重新处理后仍无法抵达目标 |
| 目标丢失 | 命令依赖的目标实体已经失效 |
| 已取消 | 被新命令或明确取消操作终止 |
| 单位失效 | 执行命令的单位已经死亡、销毁或离场 |

其中“已到达、已完成、不可达、目标丢失、已取消、单位失效”为终态。

---

# 6. 命令覆盖

创建新的有效命令时：

```text
存在旧活动命令
→ 旧命令进入已取消
→ 记录新的指令为替代来源
→ 创建新命令
→ 新命令成为当前活动命令
```

连续下达：

```text
移动 A
→ 移动 B
→ 移动 C
```

最终只有“移动 C”是当前活动命令。

当前 Demo 不支持 `Shift + 命令` 的多命令队列，该功能继续保持待定。

---

# 7. 停止移动

“停止移动”只处理移动执行，不等同于“停止”。

适用当前命令：

- 移动；
- 靠近目标；
- 跟随目标；
- 强制移动；
- 地面攻击移动；
- 目标攻击移动；
- 战术撤退。

执行结果：

```text
停止当前位移
→ 当前移动类命令进入暂停
```

其他命令不存在时，停止移动作为合法无操作处理。

---

# 8. 停止

“停止”用于统一停止当前主要行为。

## 8.1 可暂停任务

以下当前命令进入暂停：

- 移动；
- 靠近目标；
- 跟随目标；
- 强制移动；
- 地面攻击移动；
- 目标攻击移动；
- 战术撤退；
- 采集；
- 施工。

## 8.2 攻击命令

以下当前命令进入已取消：

- 普通攻击；
- 强制攻击；
- 地面强制攻击。

## 8.3 持续战斗策略

停止不会清除：

- 当前交战姿态；
- 当前开火策略。

因此“停止”结束的是当前主要行为，不是重置单位全部战斗配置。

---

# 9. 命令目标

当前命令目标分为两种基础结构：

## 世界位置

用于：

- 移动；
- 强制移动；
- 地面攻击移动；
- 战术撤退；
- 地面强制攻击。

## 稳定战场实体

用于：

- 靠近目标；
- 跟随目标；
- 目标攻击移动；
- 普通攻击；
- 强制攻击；
- 采集；
- 施工。

命令记录的是稳定目标身份，不直接持有场景节点作为策划语义。

---

# 10. 目标失效与单位失效

依赖目标实体的命令在目标失效后进入“目标丢失”或由对应执行规则结束。

执行单位死亡、被摧毁或离场时：

```text
当前活动命令
→ 单位失效
→ 不再作为当前活动命令
```

UI、选择系统、编队系统和 AI 查询随后使用新的合法世界状态。

---

# 11. 批量指令

玩家一次控制多个单位时，统一指令可以包含多个单位，但每个单位独立完成：

```text
所有权校验
能力校验
执行端接受
命令创建
状态变化
```

因此同一次批量指令可以出现部分单位接受、部分单位拒绝。

每个单位仍然只维护自己的一个当前活动命令。

---

# 12. AI 副官与单位命令

AI 副官不会产生独立的“AI 命令类型”。

AI 理解玩家意图后，转换为当前正式指令，例如：

```text
“1队撤退到基地”
→ 战术撤退指令
→ 各单位创建 TacticalWithdraw 命令
```

```text
“这队固守”
→ 设置交战姿态
→ 不创建新的单位命令
```

```text
“停止开火”
→ 设置开火策略
→ 不创建新的单位命令
```

因此玩家和 AI 副官共享同一套 RTS 执行规则。

---

# 13. 当前范围

当前 Demo 的命令层以程序已经存在的正式能力为准。

当前不扩展：

- 巡逻命令；
- 多命令队列；
- 通用交互命令；
- 技能命令；
- 独立 Unit AI 命令；
- 独立 System AI 单位命令类型；
- 复杂命令优先级队列。

后续新增能力时，在现有“指令 → 命令 → 状态”的结构中扩展。
