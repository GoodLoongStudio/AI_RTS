# 策划文档_技能基础规则

> 状态：待评审  
> 本文定义技能的统一组成方式，使后续大部分技能可以通过基础效果组合与配置完成。

# 1. 技能总体结构

所有技能统一抽象为：

**技能 = 触发规则 + 目标规则 + 效果序列 + 时间规则 + 消耗与冷却**

| 结构 | 作用 |
|---|---|
| 触发规则 | 技能什么时候开始 |
| 目标规则 | 技能作用于谁、哪里或什么方向 |
| 效果序列 | 技能实际产生哪些结果 |
| 时间规则 | 各效果什么时候发生、持续多久 |
| 消耗与冷却 | 技能使用成本与再次使用限制 |

具体技能只需要配置这些结构，不单独建立新的执行体系。

# 2. 触发规则

技能触发统一支持：

- 主动触发；
- 被动触发；
- 事件触发；
- 条件触发。

主动技能由玩家或 AI 明确使用。

被动、事件与条件触发技能不需要玩家主动确认目标，但仍然使用相同的目标规则和效果序列。

# 3. 目标规则

技能目标统一使用以下基础结构：

- 自身；
- 单个单位；
- 多个单位；
- 地面位置；
- 区域；
- 方向；
- 已有游戏对象。

目标规则至少可以配置：

- 阵营关系；
- 单位类型；
- 单位标签；
- 最大目标数量；
- 距离；
- 范围；
- 方向；
- 是否必须存活；
- 是否允许作用于自身。

目标确认方式继续使用现有 Targeting 规则。

# 4. 效果序列

技能真正的内容统一由 **效果序列** 表达。

效果序列由一个或多个基础效果组成。

基础效果只保留以下类型：

| 效果 | 作用 |
|---|---|
| 造成伤害 | 对目标产生伤害 |
| 恢复生命 | 恢复目标生命值 |
| 修改护盾 | 增加、减少或恢复护盾 |
| 修改属性 | 修改已有单位属性 |
| 修改资源 | 修改能量、弹药、充能等资源 |
| 添加状态 | 给目标增加一个状态 |
| 移除状态 | 移除目标已有状态 |
| 位移 | 改变对象位置 |
| 强制移动 | 推、拉、击退等位置变化 |
| 创建对象 | 按对象模板创建一个游戏对象 |
| 移除对象 | 移除指定游戏对象 |
| 下达命令 | 让目标执行一个已有基础命令 |
| 触发事件 | 产生一个统一游戏事件 |

只要具体技能可以由这些效果组合得到，就不新增新的底层技能效果。

# 5. 效果组合

多个效果之间只使用以下关系：

- 顺序；
- 同时；
- 延迟；
- 持续；
- 周期；
- 条件；
- 重复。

例如一个技能可以表示为：

**效果 A → 延迟 → 效果 B**

或者：

**同时执行效果 A + 效果 B**

复杂技能也只通过这些关系继续组合。

# 6. 时间规则

时间规则只描述：

- 施放前等待时间；
- 效果触发时点；
- 延迟时间；
- 持续时间；
- 周期间隔；
- 重复次数；
- 技能结束时点。

技能不为“蓄力、持续施法、延迟爆发”等玩法建立独立系统，这些都由时间规则与效果序列组合表达。

# 7. 状态

状态是可以持续附着在单位或对象上的规则。

统一结构：

**状态 = 持续时间 + 属性修改 + 触发效果 + 叠加规则**

状态可以：

- 修改属性；
- 周期触发效果；
- 在指定事件发生时触发效果；
- 被刷新、叠加或移除。

状态本身继续使用同一套基础效果，不建立独立效果系统。

# 8. 创建对象

技能如果需要在场上产生一个持续存在的东西，只使用：

**创建对象 + 对象模板**

技能层只需要提供：

- 对象模板；
- 创建位置；
- 创建方向；
- 所属施法者；
- 必要的初始参数。

对象创建以后，其：

- 生命周期；
- 空间表现；
- 移动；
- 碰撞；
- 接触规则；
- 自身触发逻辑；

全部由对应对象模板定义。

技能基础规则不展开对象模板内部结构。

# 9. 数值来源

效果中的数值可以来自：

- 固定数值；
- 技能等级；
- 施法者属性；
- 目标属性；
- 当前状态；
- 临时变量；
- 前一个效果的结果。

技能数值只负责读取这些结果，不为每一种数值关系建立新的技能类型。

伤害效果最终统一使用《策划文档_伤害计算规则》。

# 10. 消耗与冷却

主动技能可以配置：

- 消耗资源类型；
- 消耗数值；
- 冷却时间；
- 消耗时点；
- 冷却开始时点；
- 使用次数 / 充能数量；
- 充能恢复时间。

默认规则：

**技能正式生效时扣除消耗并开始冷却。**

# 11. 技能中断

技能可以配置：

- 哪些阶段允许中断；
- 哪些情况触发中断；
- 中断后哪些尚未发生的效果停止；
- 是否返还消耗；
- 是否保留冷却。

已经生效的效果不因为后续中断自动撤销。

# 12. 技能配置结构

每个技能最终统一配置为：

```text
技能名称：

触发规则：

目标规则：

效果序列：
1.
2.
3.

时间规则：

消耗：

冷却：

中断规则：
```

效果序列中的每一项只使用已有基础效果。

# 13. 核心原则

技能系统只负责：

**什么时候触发、作用于谁、按什么顺序产生什么效果。**

效果系统负责：

**如何改变当前游戏状态。**

对象模板负责：

**场上持续存在对象自己的生命周期与行为。**

新增具体技能时，优先通过：

**基础效果 + 时间规则 + 目标规则 + 对象模板**

进行组合。

只有当现有基础效果无法表达一种新的通用游戏行为时，才增加新的基础效果类型。
