# 策划文档_单位AI行为基础规则

> 状态：待评审  
> 本文定义单位级人工智能的控制结构、大模型人工智能与行为树人工智能的职责边界，以及单位自主执行任务的统一规则。

# 1. 核心结构

单位自主控制统一使用以下链路：

**玩家 / 大模型人工智能 → 任务参数 → 行为树人工智能 → 基础命令系统 → 单位实际行动**

其中：

- 玩家负责直接控制和明确下达任务；
- 大模型人工智能负责理解、规划和分配任务；
- 行为树人工智能负责持续执行任务；
- 基础命令系统负责移动、攻击、技能、跟随、交互等具体命令；
- 游戏基础规则负责最终合法性和实际结果。

核心原则：

**大模型人工智能决定做什么。**

**行为树人工智能决定具体怎么执行。**

**基础游戏系统决定动作是否合法以及最终如何发生。**

玩家直接命令始终拥有最高优先级。

# 2. 大模型人工智能职责

大模型人工智能负责高层、低频决策。

大模型人工智能负责：

- 理解玩家自然语言指令；
- 理解当前任务目标；
- 判断当前战场重点；
- 选择需要执行任务的合法单位或小队；
- 设置单位职责；
- 设置任务目标；
- 设置目标区域；
- 设置行为姿态；
- 设置任务优先级；
- 设置行动限制；
- 根据重要新情报调整任务；
- 在任务完成或失败后决定下一步任务。

大模型人工智能最终输出结构化任务参数。

大模型人工智能不直接控制单位连续动作。

# 3. 行为树人工智能职责

行为树人工智能负责高频、局部、确定性的任务执行。

行为树人工智能接收任务参数后，持续完成以下工作：

- 读取单位当前状态；
- 读取当前合法战场情报；
- 读取当前已知地图；
- 选择合法具体目标；
- 选择合法行动位置；
- 生成移动命令；
- 生成攻击命令；
- 生成跟随或接近命令；
- 生成巡逻命令；
- 生成交互命令；
- 使用允许自动使用的技能；
- 处理目标失效；
- 处理路径变化；
- 处理局部威胁；
- 处理生命、护盾和资源变化；
- 在任务边界内持续执行当前职责。

行为树人工智能最终只生成已有基础命令。

# 4. 两层明确边界

大模型人工智能不负责：

- 逐帧移动；
- 具体寻路；
- 局部避障；
- 具体转向；
- 单次攻击节奏；
- 连续追击；
- 每次攻击目标刷新；
- 每次技能释放时机；
- 局部战斗走位；
- 局部撤退路径；
- 碰撞处理；
- 单位之间的即时位置修正。

这些全部交给行为树人工智能和基础游戏系统。

行为树人工智能不负责：

- 理解玩家自然语言；
- 修改战略目标；
- 修改任务胜负条件；
- 自己建立新的高层任务；
- 自己改变单位主要职责；
- 自己扩大授权控制范围；
- 自己改变系统级战略；
- 自己决定长期资源、生产和科技方向；
- 自己读取隐藏战场真值。

这些全部属于玩家、大模型人工智能或其他高层系统。

# 5. 任务参数

大模型人工智能与行为树人工智能之间只通过任务参数连接。

统一任务参数包括：

| 参数 | 含义 |
|---|---|
| 执行对象 | 哪些单位或小队执行任务 |
| 单位职责 | 单位当前主要完成什么工作 |
| 任务类型 | 当前需要完成的任务 |
| 任务目标 | 当前需要达到的结果 |
| 目标对象 | 当前明确指定的合法对象 |
| 目标区域 | 当前主要行动区域 |
| 行为姿态 | 当前单位自主行动倾向 |
| 任务优先级 | 多个任务之间的先后顺序 |
| 行动限制 | 追击、范围、资源、风险等限制 |
| 结束条件 | 什么结果代表当前任务结束 |

行为树人工智能不读取自然语言指令。

行为树人工智能只读取最终任务参数。

# 6. 单位职责

单位职责决定：

**这个单位在当前任务中主要负责什么。**

单位职责直接决定：

- 优先处理的目标；
- 允许主动执行的行为；
- 允许自动使用的技能；
- 默认行动范围；
- 当前职责完成后的默认状态。

单位主要职责由玩家、大模型人工智能或任务规则设置。

行为树人工智能不自行修改主要职责。

# 7. 行为姿态

单位统一使用四种行为姿态：

| 行为姿态 | 最终行为 |
|---|---|
| 自主履职 | 围绕当前任务和职责自主处理局部情况 |
| 主动强化 | 主动扩大行动范围并寻找符合职责的目标 |
| 稳守维持 | 围绕当前任务位置或区域履职，不主动扩大行动范围 |
| 保全优先 | 停止高风险扩展行为，优先脱离危险并保存自身 |

行为姿态不改变单位职责。

行为姿态只改变：

- 主动搜索范围；
- 追击范围；
- 风险倾向；
- 资源投入程度；
- 撤离优先级。

# 8. 行动锚点

行为树人工智能始终围绕一个当前行动锚点执行任务。

行动锚点优先级固定为：

**明确任务位置 > 明确防守位置 > 当前跟随对象 > 当前巡逻区域 > 最近一次玩家直接命令结束位置 > 当前任务开始位置**

新的更高优先级行动锚点直接替换旧锚点。

行动锚点负责确定单位自主行动的中心位置。

# 9. 自主履职

自主履职的最终行为固定为：

- 围绕当前行动锚点执行职责；
- 处理局部范围内符合职责的合法目标；
- 正常使用允许自动使用的技能和资源；
- 当前没有职责目标时保持任务位置或待命；
- 不主动进入扩展行动范围。

# 10. 主动强化

主动强化的最终行为固定为：

- 搜索扩展行动范围内符合职责的合法目标；
- 主动接近并处理目标；
- 提高允许自动使用的技能和资源投入；
- 当前目标处理完成后继续寻找职责目标；
- 扩展范围内没有职责目标后回到行动锚点附近。

# 11. 稳守维持

稳守维持的最终行为固定为：

- 保持当前行动锚点；
- 处理稳守范围内符合职责的合法目标；
- 不主动追击超出稳守范围的目标；
- 目标离开稳守范围后停止追击；
- 局部处理完成后返回行动锚点附近；
- 优先保持位置与持续作战能力。

# 12. 保全优先

保全优先的最终行为固定为：

- 停止主动扩大任务成果；
- 停止主动追击；
- 中止非必要高风险交战；
- 向当前已知安全位置、后方锚点或友方安全区域移动；
- 只使用撤离与生存需要的攻击、技能和资源；
- 到达安全位置后保持保全状态。

保全路径只使用合法已知地图和合法战场情报。

# 13. 行为树判断顺序

行为树每次重新判断时，统一按照以下顺序处理：

**玩家直接命令 > 单位生存与控制状态 > 当前任务有效性 > 当前直接威胁 > 当前职责目标 > 当前行为姿态 > 默认待命行为**

行为树不得跳过更高优先级规则直接执行低优先级行为。

# 14. 目标选择

行为树人工智能只从当前合法目标中选择具体目标。

统一目标优先顺序：

**明确任务目标 > 当前直接威胁 > 职责优先目标 > 其他合法目标**

同一级目标继续按照：

**任务相关性 > 处理价值 > 距离与行动成本**

确定具体对象。

失去合法目标资格的对象立即退出当前目标。

战争迷雾中的隐藏单位不继续作为实时实体目标。

# 15. 技能自动使用

技能是否允许由行为树人工智能自动使用，由技能或单位配置明确决定。

允许自动使用的技能统一按照：

**当前职责 → 当前任务 → 当前目标 → 当前行为姿态 → 当前资源**

决定是否释放。

具体释放时机由行为树人工智能处理。

大模型人工智能不负责每一次技能释放。

# 16. 玩家直接命令

玩家直接命令开始后：

**行为树人工智能立即让权。**

玩家直接命令执行期间：

- 行为树人工智能不生成冲突命令；
- 当前任务继续保留；
- 当前单位职责继续保留；
- 当前行为姿态继续保留；
- 大模型人工智能不立即重新覆盖玩家命令。

玩家直接命令结束后：

**行为树人工智能重新读取当前任务和战场状态，并重新执行。**

恢复的是当前任务，不机械恢复玩家接管前的旧具体命令。

# 17. 行为树自行处理的变化

以下变化由行为树人工智能直接处理：

- 当前具体目标死亡；
- 当前具体目标失效；
- 当前目标暂时失去视野；
- 当前路径变化；
- 当前局部位置被阻挡；
- 当前附近出现合法敌人；
- 当前技能进入可用状态；
- 当前生命或护盾变化；
- 当前弹药、能量、充能变化；
- 当前局部交战结束。

这些变化不直接触发大模型人工智能重新规划。

# 18. 大模型重新规划的结果

以下结果交回大模型人工智能：

- 当前高层任务完成；
- 当前高层任务确认失败；
- 当前任务目标永久失效；
- 当前任务已经失去继续执行价值；
- 战场出现改变任务方向的重要新情报；
- 玩家修改当前战略意图；
- 更高优先级任务替换当前任务。

大模型人工智能重新输出新的任务参数。

行为树人工智能随后执行新的任务参数。

# 19. 多单位与小队

大模型人工智能负责把任务分配给单位或小队。

行为树人工智能负责每个单位的具体执行。

同一小队共享：

- 小队任务；
- 目标区域；
- 行为姿态；
- 行动限制；
- 小队行动锚点。

每个单位继续根据自己的：

- 单位职责；
- 当前状态；
- 当前能力；
- 当前合法目标；

生成具体基础命令。

因此同一个小队中的不同单位可以执行不同动作，但所有动作服务于同一个小队任务。

# 20. 情报边界

大模型人工智能和行为树人工智能使用同一套合法战场情报。

两者都不得读取：

- 未探索区域真实地形；
- 战争迷雾中的实时敌军位置；
- 未被发现的隐藏目标；
- 敌方内部命令；
- 敌方内部决策；
- 其他规则未公开的信息。

行为树人工智能只根据当前合法信息执行任务。

大模型人工智能只根据当前合法信息规划任务。

# 21. 大规模单位控制范围待定

> 本节为待讨论事项，当前不冻结最终方案。

当战场单位数量明显增加后，大模型人工智能的直接控制范围需要重新评估。

当前明确保留以下问题，后续根据实际游戏规模、性能和操作体验决定：

- 大模型人工智能是否继续直接向大量单个单位分配任务；
- 大模型人工智能是否只控制小队、编队或更高层级单位集合；
- 单个单位是否主要交由行为树人工智能自行执行；
- 大模型人工智能一次能够直接管理的单位或小队数量是否需要限制；
- 大规模战斗中是否需要进一步减少大模型人工智能参与局部决策的频率；
- 是否需要根据单位数量动态调整大模型人工智能的控制粒度。

当前原则：

**单位数量增加时，优先考虑缩小大模型人工智能的直接控制范围，把更细的执行继续下放给行为树人工智能。**

最终控制粒度不在当前阶段确定。

该规则在后续多人讨论、性能测试和实际战斗体验验证后再冻结。

# 22. 最终规则

单位自主控制最终固定为：

**玩家 / 大模型人工智能负责高层任务。**

**行为树人工智能负责局部持续执行。**

**基础命令系统负责具体单位动作。**

**基础游戏规则负责合法性和结果。**

统一遵守：

- 大模型人工智能决定做什么；
- 行为树人工智能决定具体怎么执行；
- 行为树只生成已有基础命令；
- 玩家直接命令始终最高优先；
- 行为树不自行改变高层任务；
- 大模型不参与单位逐帧微操；
- 两层人工智能都不能突破战争迷雾；
- 两层人工智能都不能绕过移动、攻击、技能和命令规则。
