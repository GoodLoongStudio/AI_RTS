# 策划文档_视野战争迷雾与情报规则

> 状态：待评审  
> 本文定义地图视野、战争迷雾、单位情报状态、探测与情报共享的基础规则。

# 1. 核心结构

战场信息统一拆成两部分：

**战场情报 = 地图可见状态 + 对象情报状态**

地图可见状态回答：

**这片区域现在能不能看见。**

对象情报状态回答：

**这个单位 / 建筑现在知道到什么程度。**

两者分开处理。

# 2. 地图可见状态

地图区域只存在三种基础状态：

| 状态 | 含义 |
|---|---|
| 未探索 | 从未获得过合法视野 |
| 已探索 | 曾经看见过，但当前没有视野 |
| 当前可见 | 当前处于己方合法视野范围内 |

状态转换：

**未探索 → 当前可见 → 已探索 → 当前可见**

第一次获得视野时，区域直接从未探索变成当前可见。

失去视野后，区域变成已探索。

重新获得视野后，再次变成当前可见。

# 3. 地图信息更新

## 当前可见

当前可见区域：

- 显示当前地图状态；
- 显示当前合法可见对象；
- 动态变化正常更新。

## 已探索

已探索但当前不可见区域：

- 保留已经确认过的基础地图信息；
- 不继续更新隐藏区域中的动态变化；
- 不提供隐藏单位的实时位置。

## 未探索

未探索区域不提供该区域当前战场信息。

任务明确公开的信息不受地图探索状态限制。

# 4. 视野来源

任何能够提供视野的对象统一称为 **视野来源**。

视野来源至少包含：

| 字段 | 含义 |
|---|---|
| 视野范围 | 可以获得正常视野的空间范围 |
| 探测能力 | 是否能够发现需要额外探测的目标 |
| 情报共享 | 产生的视野是否共享给所属控制方 |

视野来源可以来自单位、建筑或其他明确提供视野的游戏对象。

多个己方视野来源的结果直接合并。

只要一个合法视野来源能够观察某区域，该区域即属于当前可见。

# 5. 单位视野属性

单位基础属性中的 **视野能力**，在本规则中具体表现为单位能够提供的视野范围及相关观察能力。

其中最基础的数值是：

**视野范围**

视野范围以单位当前位置为中心，决定该单位当前能够为所属控制方提供多大的正常可见区域。

因此单位移动时：

**单位位置变化 → 视野覆盖区域变化 → 当前可见区域同步变化**

不同单位可以拥有不同的视野范围。

单位失效、死亡、离场或失去提供视野的资格后，不再继续产生视野。

探测能力属于视野能力的附加能力，不改变视野范围本身，而是决定视野范围内某些特殊目标是否能够被发现。

# 6. 开地图

**开地图**表示某个地图区域第一次被己方合法视野覆盖，从“未探索”进入已探索体系。

基础流程：

**未探索区域 → 被己方视野首次覆盖 → 当前可见 → 视野离开后变为已探索**

因此：

- 单位向未知区域移动，可以持续开地图；
- 多个单位可以同时从不同方向开地图；
- 已经开过的区域不会重新变成未探索；
- 开地图记录属于控制方共享的地图探索信息。

开地图与当前视野不是同一个概念：

| 概念 | 作用 |
|---|---|
| 视野 | 决定当前位置是否能够获得实时信息 |
| 开地图 | 决定该区域是否已经被探索过 |

已经开过地图但当前没有视野时，只能看到允许保留的已探索地图信息，不能获得该区域中的实时敌军信息。

特殊任务、剧情或地图规则可以直接将指定区域标记为已探索。

这种“直接开地图”只改变地图探索状态；如果规则没有同时明确给予视野，则不会因此获得该区域的实时单位情报。

# 7. 未探索区域移动与隐藏阻挡

玩家或人工智能可以向未探索区域下达移动命令。

未探索区域中的地形、墙体、建筑阻挡和通行关系，在被合法探索前不得提前参与寻路判断。

为了保证这一点，每个控制方只使用自己的 **已知通行地图**。

已知通行地图中的区域只有三种状态：

| 状态 | 含义 |
|---|---|
| 已确认可通行 | 已经探索，并确认单位可以经过 |
| 已确认阻挡 | 已经探索，并确认单位不能经过 |
| 未知 | 尚未探索，不知道是否可以经过 |

寻路只能读取这三种已知状态，不允许直接读取未探索区域的真实通行结果。

## 7.1 前往未探索区域

向未探索区域移动时：

**下达移动命令 → 按已知通行地图前进 → 接近未知边界 → 开出新的地图 → 更新通行信息 → 重新规划**

未知区域不直接判定为可通行，也不直接判定为阻挡。

它只表示：

**当前还不知道。**

单位会先向最接近目标方向、且当前能够到达的已知边界前进。

随着单位移动，新的区域不断被探索，已知通行地图也不断扩展。

## 7.2 什么时候算发现阻挡

阻挡只能通过合法观察或实际接触被确认。

满足以下任一条件，即认为该阻挡已经被发现：

- 阻挡进入单位的地图探索范围，并且从当前位置能够合法观察到该阻挡；
- 单位实际移动到该位置附近，并因为该阻挡无法继续前进；
- 其他己方视野来源已经合法发现该阻挡，并且该情报允许共享。

发现阻挡后：

**对应区域立即从未知变为已确认阻挡。**

如果该阻挡使当前移动路线失效，则立即重新规划。

单位不会在阻挡仍处于未探索状态时提前绕开它。

## 7.3 地图探索范围

地图探索范围决定单位能够确认周围地形与通行信息的范围。

默认情况下：

**地图探索范围 = 单位视野范围**

也就是说，单位能看见的正常地形，同时会被记入已知通行地图。

如果后续某些单位需要特殊侦察能力，可以单独配置更大的地图探索范围，但基础规则不依赖这种特殊能力。

阻挡本身可以挡住后方区域的探索。

单位看见一面墙，只会确认当前能够观察到的墙体与周围区域，不会因为看见墙的一部分就自动知道整面墙延伸多远。

## 7.4 发现阻挡后的绕行

发现当前路线被阻挡后，单位重新使用已知通行地图计算路线。

处理顺序：

**先寻找已经确认的可通行绕行路线 → 如果没有，则寻找可到达的未探索边界 → 继续探路**

如果已知地图中已经存在绕过阻挡的路线：

**直接沿该路线继续前往原目标。**

如果已知地图中没有完整绕行路线，但阻挡附近仍存在能够到达的未探索区域：

**不判定不可达。**

单位会选择一个可到达的未探索边界继续前进并开地图。

选择未探索边界时，只能依据当前已知信息判断，主要考虑：

- 与原目标方向的偏差；
- 到该边界的已知移动距离；
- 当前已经确认的阻挡形状；
- 单位自身通行能力。

不得依据隐藏地图中真正的出口位置选择方向。

因此如果阻挡两侧都还没有探索，单位只能根据当前已知距离和方向选择一侧尝试，而不能提前知道哪一侧实际存在出口。

## 7.5 如何逐步找到绕行路线

单位在阻挡附近继续探路时：

**移动到新的已知边界 → 获得新的地图信息 → 更新阻挡范围 → 再次计算路线**

这个过程可以重复。

当探索到一个新的可通行区域，使当前位置与目标之间出现合法路线时：

**绕行路线被发现 → 单位沿新路线继续执行原移动命令。**

因此“发现绕行路线”不是一次读取完整地图得出的结果，而是通过不断扩大已知通行地图得到的。

## 7.6 暂时没有路线

如果当前已知地图中没有到目标的路线，但仍然存在能够到达的未探索边界，则只能得到：

**当前尚未找到路线。**

不能得到：

**目标不可到达。**

此时移动命令可以继续进入探路过程。

## 7.7 什么时候才能确认不可到达

只有同时满足以下条件，才能确认目标不可到达：

- 当前已知通行地图中不存在到目标的合法路线；
- 所有能够从当前位置继续尝试绕行的边界都已经探索；
- 已确认阻挡、地图边界或其他已知不可通行区域已经切断所有可能连接；
- 不再存在能够到达、并且可能形成新路线的未探索区域。

满足这些条件后：

**目标确认不可到达 → 当前移动命令结束 → 单位停止 → 向玩家返回无法到达反馈。**

只要仍有一个合法可到达的未探索方向可能形成新路线，就不能把目标标记为确认不可到达。

## 7.8 探路范围限制

为了避免单位为了一个普通移动命令无限沿着巨大阻挡探索，移动命令可以配置一个 **最大探路范围**。

最大探路范围只限制单位为了寻找绕行路线愿意额外探索多远。

达到最大探路范围后仍未找到路线：

**停止自动探路，并返回“当前未找到可行路线”。**

这个结果不同于“确认不可到达”。

只有已经满足第 7.7 节条件时，才可以返回“确认不可到达”。

## 7.9 已知阻挡的后续使用

一旦阻挡被合法发现，其已经确认的部分可以继续参与后续寻路。

后续再次经过附近区域时：

- 已确认阻挡不需要重新探索；
- 已确认可通行区域可以正常参与寻路；
- 仍未探索的部分继续保持未知。

如果地图规则允许阻挡动态变化，则只有再次获得合法视野后才能刷新其新状态。

## 7.10 核心规则

**单位只能依据当前已知通行地图规划路线。**

**阻挡只能在被合法观察或实际接触后加入已知地图。**

**绕行路线只能通过已经确认的可通行区域，或继续探索未知边界逐步发现。**

**当前没有路线，不等于确认不可到达。**

**只有所有可能的可达探索边界都已经排除后，才可以确认目标不可到达。**

# 8. 可见判定

一个目标成为当前可见对象，需要同时满足：

**目标位于己方有效视野内 + 当前观察条件允许发现该目标**

正常单位只需要进入有效视野即可被发现。

如果目标具有额外隐藏条件，则还需要满足对应探测条件。

因此：

**视野决定“能不能看到这里”，探测决定“这里的特殊目标能不能被发现”。**

# 9. 对象情报状态

所有非本方对象统一使用以下情报状态：

| 状态 | 含义 |
|---|---|
| 当前可见 | 当前被合法观察，信息可以实时更新 |
| 已知记录 | 曾经可见，现在已经失去视野 |
| 推断 | 根据合法情报推断出的结论 |
| 未知 | 当前没有合法情报 |

本方对象使用：

**本方已知**

本方单位的合法状态由所属控制方持续掌握，不需要通过战争迷雾重新发现。

# 10. 当前可见情报

敌方对象处于“当前可见”状态时，可以更新当前合法公开信息。

基础包括：

- 对象存在；
- 对象类型；
- 当前可见位置；
- 当前可见状态；
- 游戏规则允许公开的生命、护盾等战斗信息。

“当前可见”不代表能够读取该对象所有内部数据。

例如隐藏的人工智能决策、内部命令队列、未公开技能状态等，不因为对象可见而自动公开。

# 11. 已知记录

敌方对象从 当前可见 离开视野后：

**当前可见 → 已知记录**

“已知记录”保存最后一次合法观察到的信息。

至少包含：

- 最后确认时间；
- 最后确认位置 / 区域；
- 最后确认类型；
- 当时已知的公开状态。

进入“已知记录”后：

**该对象的隐藏真值停止更新。**

例如敌人在战争迷雾中继续移动，已知记录仍然停留在最后一次确认的位置。

# 12. 已知记录的刷新与失效

“已知记录”不等于目标现在仍然在那里。

当目标重新进入合法视野：

**已知记录 → 当前可见**

如果最后已知位置重新变成当前可见，而目标已经不在那里：

**该位置记录被确认过时。**

系统可以清除该位置的当前存在性判断，但仍可保留“曾在此处发现过该目标”的历史信息。

已知记录可以保留“信息年龄”，用于玩家和人工智能判断该信息有多旧。

不使用隐藏真值自动修正已知记录。

# 13. 推断情报

“推断”表示：

**根据合法情报得到的推测，不是系统确认事实。**

推断情报至少需要保留：

- 推断内容；
- 推断依据；
- 生成时间；
- 可选的可信度。

后续获得直接视野后：

- 推断被证实，可以转化为当前确认信息；
- 推断被否定，则失效；
- 没有新证据时继续保持推断状态。

推断永远不能自动获得隐藏对象的精确实时数据。

# 14. 情报共享

同一控制方的共享情报统一合并。

例如多个己方单位分别发现不同区域：

**所有允许共享的视野 → 合并为当前控制方的战场情报**

基础共享内容包括：

- 当前可见区域；
- 当前可见对象；
- 已知记录；
- 已确认的公开战场事件。

如果某个单位或规则明确禁止共享，则其情报只属于对应观察者或指定控制范围。

# 15. 玩家与人工智能的情报关系

玩家和人工智能使用同一套基础战场情报状态。

人工智能可以读取：

- 本方已知；
- 当前可见；
- 已知记录；
- 合法产生的 推断。

人工智能不允许读取“未知”对应的隐藏真值。

核心原则：

**人工智能可以比玩家知道得更少，但不能因为是人工智能而知道得更多。**

人工智能的权限、细节等级和操作点还可以进一步限制它能读取多少合法情报，但这些限制不能反向突破战争迷雾。

# 16. 情报与目标选择

新的实体目标必须来自当前合法可引用情报。

基础规则：

- “当前可见”对象可以作为正常实体目标；
- “已知记录”只表示最后已知信息，不等同于当前可锁定实体；
- “推断”不能直接当成已确认实体；
- “未知”不可被直接引用。

如果某个命令允许攻击位置或区域，可以使用合法的最后已知位置作为地面目标。

但这仍然是：

**攻击一个位置，而不是直接锁定战争迷雾中的隐藏实体。**

# 17. 目标失去视野

已经存在的敌方目标失去当前视野后：

- 不再继续获得其实时位置；
- 不再继续更新其当前状态；
- 只保留最后确认信息。

当前攻击、追击或技能后续如何处理，由对应行为规则根据“目标已经失去当前可见性”继续判断。

普通规则不得继续使用隐藏真值追踪目标。

# 18. 战场事件

战场事件同样受情报规则限制。

玩家或人工智能可以获得：

- 当前可见范围内合法发生的战斗事件；
- 本方单位自身状态变化；
- 任务明确公开的系统事件；
- 规则明确共享的情报事件。

隐藏区域中的敌方行为不会因为系统内部已经发生，就自动成为玩家或人工智能的已知情报。

# 19. 基础配置

单位或视野来源至少需要：

| 字段 | 说明 |
|---|---|
| 视野范围 | 正常观察范围 |
| 探测能力 | 是否能发现需要特殊探测的目标 |
| 情报共享能力 | 是否向所属控制方共享观察结果 |

需要特殊隐藏规则的对象至少需要：

| 字段 | 说明 |
|---|---|
| 可见条件 | 正常视野是否足够 |
| 探测条件 | 被特殊发现需要什么探测能力 |

# 20. 基础验收

| 情况 | 结果 |
|---|---|
| 第一次进入区域 | 未探索 → 当前可见 |
| 单位向未知区域移动 | 视野覆盖到的新区域持续完成开地图 |
| 未探索区域存在隐藏阻挡 | 阻挡被观察或接触后才写入已知通行地图 |
| 已知地图已有绕行路线 | 直接重新规划并继续前往原目标 |
| 没有已知绕行路线但仍有未探索边界 | 继续探路，不得判定不可到达 |
| 探索后发现新的通路 | 形成绕行路线并继续执行原移动命令 |
| 所有可能绕行方向均已探索并被阻断 | 确认不可到达，结束移动命令 |
| 达到最大探路范围仍有未知区域 | 返回当前未找到路线，不得标记确认不可到达 |
| 单位离开区域 | 当前可见 → 已探索 |
| 敌人进入己方视野 | 未知 / 已知记录 → 当前可见 |
| 敌人离开视野 | 当前可见 → 已知记录 |
| 敌人在迷雾中移动 | 已知记录位置不跟随隐藏真值更新 |
| 再次发现敌人 | 已知记录 → 当前可见，并更新当前信息 |
