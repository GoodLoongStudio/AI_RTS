## 2026-10-13 — 建造与发布边界规则同步

**本次仅补写已有代码/用户需求形成的规则，不在文档中新增尚未实现的玩法。** 详情和证据见 [差异审计](../程序文档/文档与实现差异审计_2026-10-13.md)。

- **建筑施工**：9 月 27 日起 Demo 建筑配置为零工人可自动推进；旧决策手册“无建造者不能开工”的阻断条件不再适用于这些建筑。施工进度由服务与配置决定；同一玩家目前只能有一个 Active 工地。
- **多主基地速度**：有按已完工指挥中心数量计算速率的能力，但默认平衡配置没有加速系数（默认 0），当前 Demo 不应宣传为“多造主基地就默认加速”。
- **矿点再生**：当前 Demo 的矿点 A 已开启基础再生（90 秒等待、每次恢复 1500）；代码支持等待逐轮延长/封顶，但配置没有启用对应参数，不能写为默认机制。
- **建筑交互**：待放置时选择其他建筑会切换蓝图；重复选择原建筑不重置待放置方向/位置。
- **发布范围**：地图生成工作台保留为开发态功能，正式非编辑器包隐藏入口；单机随机地图按钮隐藏；在线匹配主菜单入口仍隐藏，但联机能力和自动化入口未删除。
- **验收限制**：10 月 13 日 PR #11 的 C# 构建通过但测试和 GDScript 审计未全绿。这些实现属于代码事实，不能等同于本版本整体玩法验收通过。

## 2026-09-25

### 当前策划基线改为“按已实现事实反向收敛”

新增 [AI_RTS 当前产品策划基线（2026-09-25）](AI_RTS_当前产品策划基线_2026-09-25.md)。

本次变更的主要原因：

1. `yyp_test` 已合入 `main`，当前实现与 2026-09-14 以前的单模型副官文档产生明显偏差；
2. Laya 已进入运行时，AI 副官已形成 **Laya + MiniCPM5-2B + 规则 baseline + 行为树** 的实际结构；
3. 玩家接管、generation、TTL、任务生命周期、本地 Ollama 自动拉起/预热、自对局训练等能力已经落地；
4. 当前最大风险从“有没有 AI 功能”变为“规则、模型和策划职责是否清晰，以及 AI 是否真正改善了对局”；
5. 战役胜负、成长、程序化地图和联机 Demo 均已有实装，但产品闭环优先级需要重新排序。

### 架构优化原则冻结为“渐进式优化，不推翻大结构”

新增 [AI_RTS 现有架构渐进式优化方案（2026-09-25）](../程序文档/AI_RTS_现有架构渐进式优化方案_2026-09-25.md)。

本次不是改变产品架构，而是给后续开发增加 Guardrail：

- Godot 4.7 Mono、C# Domain/Application/GodotAdapter、GDScript 场景表现、服务器权威联机、传统规则 AI、Laya + MiniCPM5-2B + 规则 baseline、现有 Intent/CommandRuntime 链路、程序化地图、战役和成长体系全部保持；
- 优化重点改为职责边界、单一事实源、配置收敛、订单追踪、日志、测试、运行时生命周期和性能；
- 禁止以“优化”为名换引擎、全量换语言、改 lockstep、删除规则 AI、模型直连游戏状态或建立第二套战役/成长/地图系统；
- 后续重大架构 PR 若新增权威状态源、命令旁路、网络协议或运行进程，必须脱离本方案单独评审。

### AI 副官定位调整

旧口径：

- 单一 MiniCPM5-2B 决策；
- 四列短输出作为主要表达接口；
- 规则层常驻生成大量 baseline；
- 评测重点偏结构合法率、模型延迟和聚合准确率。

新口径：

- MiniCPM5-2B：负责异步战略、多小队组合计划、复杂取舍和玩家意图；
- Laya：负责局部交战的快速离散选择；
- 规则/行为树：负责硬安全、寻路、射程、CD、动画和无有效订单时的 baseline；
- 四列接口保留为内部落地格式，策划目标升级到原子小队订单；
- 引入“订单租约”概念，避免规则每 tick 覆盖有效模型订单；
- 产品评测改为 R0/R1/R2/R3 对照，必须用真实对局结果证明模型增益。

### 产品优先级调整

上调：

1. 规则 AI 实战可赢 / 可稳定造成建筑伤害；
2. SquadOrder + 订单租约；
3. 通用战役 Objective Runtime；
4. 模型增益对照实验；
5. Laya 训练数据结果化；
6. 真实自然语言命令链。

下调：

- 继续扩张成长树节点；
- 在基线未稳定前继续堆模型训练轮数；
- 把 2B 放进高频同步关键路径；
- 让模型逐帧输出移动坐标；
- 在没有结果样本前做复杂离线强化学习。

### 交付规则调整

旧完整包文档中“Python 环境必须排除 torch”的结论只适用于 **不启用 Laya** 的 2B-only 方案。

从现在开始交付分为：

- **轻量包**：游戏 + 传统规则 AI；AI 副官可退化运行；
- **AI 完整包**：Ollama + MiniCPM5-2B + 副官协调器；若启用 Laya，则必须携带/安装其真实 ML 依赖。
