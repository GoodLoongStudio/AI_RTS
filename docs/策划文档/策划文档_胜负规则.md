# 策划文档_胜负规则

> 状态：待评审  
> 本文定义所有需要胜负结算的玩法共用的基础胜负规则。

# 1. 核心规则

胜负只由当前玩法明确指定的胜负目标决定。

统一结构：

**关键目标达到指定状态 → 产生胜利或失败结果**

# 2. 胜利

当前玩法指定的敌方胜负目标全部达到失败状态后：

**己方胜利。**

胜负目标包括但不限于：

- 关键基地；
- 核心建筑；
- 关键单位；
- 当前玩法明确指定的其他关键对象。

# 3. 失败

当前玩法指定的己方胜负目标全部达到失败状态后：

**己方失败。**

# 4. 默认规则

普通对战默认使用：

**敌方全部关键基地或核心建筑被摧毁 → 胜利。**

**己方全部关键基地或核心建筑被摧毁 → 失败。**

具体玩法可以替换胜负目标，但不改变基础判断方式。

# 5. 最终结算

胜利或失败一旦成立：

- 锁定最终结果；
- 停止继续进行胜负判断；
- 进入对应结算流程。

同一场游戏只产生一次最终胜负结果。
