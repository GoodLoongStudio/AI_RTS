# 策划文档_战役任务系统规则

> 状态：待评审  
> 本文只定义单人战役及其他剧情关卡使用的任务目标推进规则。

# 1. 核心结构

战役任务统一使用：

**前置依赖 → 任务进行 → 完成 / 失败 → 后续结果**

任务系统只负责推进战役流程，不负责定义基础胜负规则。

# 2. 任务目标

每个任务目标只配置：

- 目标名称；
- 前置依赖；
- 完成条件；
- 失败条件；
- 完成结果；
- 失败结果。

# 3. 前置依赖

任务目标的前置依赖包括：

- 无依赖；
- 某个任务目标完成；
- 某个任务目标失败；
- 某个游戏事件发生。

依赖满足后，目标进入进行中。

# 4. 完成与失败

完成条件满足：

**任务目标完成。**

失败条件满足：

**任务目标失败。**

任务目标的完成或失败只改变战役流程，不自动改变整场游戏胜负。

# 5. 后续结果

任务目标结束后可以：

- 开始下一个任务目标；
- 触发剧情事件；
- 改变关卡状态；
- 修改当前胜负目标；
- 触发战役关卡结算。

# 6. 与胜负规则的关系

战役可以直接使用基础胜负规则，也可以通过任务流程修改当前胜负目标。

战役任务系统负责：

**这一关要玩家做什么。**

基础胜负规则负责：

**什么时候真正结束这一关。**

两者独立。
