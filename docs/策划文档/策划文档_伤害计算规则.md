# 策划文档_伤害计算规则

> 状态：待评审  
> 本文定义一次伤害如何根据攻击数值、伤害类型、护甲类型与护甲数值得到最终伤害。

# 1. 核心伤害公式

**最终伤害 = 攻击力 × 克制倍率 × 100 ÷（100 + 护甲）**

其中：

| 字段 | 含义 |
|---|---|
| 攻击力 | 武器或单位本次攻击的基础伤害数值 |
| 克制倍率 | 根据伤害类型与目标护甲类型查表得到 |
| 护甲 | 目标单位已有的护甲属性 |
| 100 | 统一护甲基准值 |
| 最终伤害 | 实际进入护盾 / 生命值的伤害 |

公式中的 **100** 是统一护甲基准值。

当护甲为 0 时，承受 100% 伤害。  
当护甲为 100 时，承受 50% 伤害。  
当护甲为 200 时，承受约 33.3% 伤害。

因此护甲越高，减伤越明显，但不会因为护甲高于攻击力就直接变成 0 伤害。

# 2. 护甲曲线关系

当克制倍率为 100% 时：

**最终伤害 = 攻击力 × 100 ÷（100 + 护甲）**

固定护甲时，最终伤害与攻击力保持线性关系；攻击力翻倍，最终伤害也翻倍。

固定攻击力时，护甲提供平滑递减的伤害承受比例：

| 护甲 | 承受原伤害 | 攻击力 100 时的最终伤害 |
|---:|---:|---:|
| 0 | 100% | 100 |
| 25 | 80% | 80 |
| 50 | 66.7% | 约 66.7 |
| 100 | 50% | 50 |
| 200 | 33.3% | 约 33.3 |
| 300 | 25% | 25 |
| 900 | 10% | 10 |

护甲越高，伤害减免继续增加，但不会因为护甲高于攻击力就直接变成 0 伤害。

从生存能力来看，这条公式还有一个便于平衡的关系：

**有效生命值 = 生命值 ×（1 + 护甲 ÷ 100）**

例如单位生命值为 1000：

| 护甲 | 物理有效生命值 |
|---:|---:|
| 0 | 1000 |
| 100 | 2000 |
| 200 | 3000 |
| 300 | 4000 |

因此每增加 100 护甲，相当于增加一份基础生命值对应的有效生存能力。

# 3. 伤害类型与护甲类型

伤害类型：

**常规 / 穿甲 / 爆破**

护甲类型：

**轻型 / 重型 / 建筑**

克制倍率：

| 伤害类型 | 轻型 | 重型 | 建筑 |
|---|---:|---:|---:|
| 常规 | 100% | 100% | 100% |
| 穿甲 | 80% | 130% | 110% |
| 爆破 | 120% | 80% | 130% |

# 4. 计算示例

### 常规攻击

攻击力 100，目标护甲 50：

**最终伤害 = 100 × 100% × 100 ÷ 150 ≈ 66.7**

### 穿甲攻击重型单位

攻击力 100，穿甲对重型倍率 130%，目标护甲 50：

**最终伤害 = 100 × 130% × 100 ÷ 150 ≈ 86.7**

### 爆破攻击建筑

攻击力 120，爆破对建筑倍率 130%，目标护甲 100：

**最终伤害 = 120 × 130% × 100 ÷ 200 = 78**

# 5. 护盾与生命值

最终伤害计算完成后：

**最终伤害先扣护盾，护盾不足的部分再扣生命值。**

生命值降至 0 时，单位死亡或被摧毁。

# 6. 基础配置

伤害来源需要：

- 攻击力
- 伤害类型

目标单位需要：

- 护甲类型
- 护甲
- 护盾
- 生命值

# 7. 友军伤害规则

攻击、技能及其他伤害来源可以配置是否允许对友军造成伤害。

不允许对友军造成伤害时，友军不受到该伤害。

允许对友军造成伤害时：

**友军最终伤害 = 正常最终伤害 ×（1 - 友军伤害减免比例）**

其中：

- 友军伤害减免 0%：承受完整伤害；
- 友军伤害减免 50%：承受 50% 伤害；
- 友军伤害减免 100%：不受到伤害。

是否允许伤害友军，以及友军伤害减免比例，由具体攻击或技能配置。

具体程序字段和实现方式由开发确定。

# 8. 治疗规则

每个治疗效果首先计算原始治疗量：

**原始治疗量 = 基础治疗值 + 各项治疗加成**

各项治疗加成包括但不限于：

- 施放者属性加成；
- 目标最大生命值加成；
- 目标已损失生命值加成。

随后计算：

**最终治疗量 = 原始治疗量 ×（1 + 治疗效果增加比例）×（1 - 治疗效果降低比例）**

治疗后的生命值最高恢复至目标最大生命值。

超过最大生命值的治疗量直接舍弃，不自动转化为护盾。
