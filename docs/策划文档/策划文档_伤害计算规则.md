# 策划文档_伤害计算规则

> 状态：已完成  
> 本文定义当前 RTS 战役 Demo 必须具备的最小伤害、生命与死亡规则。  
> 当前只保留现有程序已经具备、且战役 Demo 必须使用的伤害闭环；复杂数值体系使用删除线保留。

---

# 1. 当前最小伤害闭环

当前 Demo 统一使用：

```text
攻击产生基础伤害
↓
根据当前友军伤害规则得到实际伤害
↓
扣减目标生命值
↓
生命值降至 0
→ 单位死亡 / 被摧毁
```

当前阶段优先保证伤害、生命和死亡完整闭环，不提前建立复杂克制系统。

---

# 2. 基础伤害

每个能够产生伤害的武器至少需要：

```text
基础伤害
```

当前程序伤害解析以武器基础伤害为核心。

不要求当前战役 Demo 同时具备伤害类型、护甲类型、护盾等额外数值层。

---

# 3. 生命值

可受伤单位至少具有：

- 当前生命值；
- 最大生命值。

受到有效伤害后：

```text
当前生命值 = 当前生命值 - 实际伤害
```

生命值最低为 0。

生命值降至 0 时：

```text
单位进入死亡 / 被摧毁处理
→ 退出正常战场生命周期
→ 当前命令失效
→ 不再作为合法攻击目标
```

---

# 4. 友军伤害

当前程序已经存在友军伤害倍率。

当前基础规则：

```text
实际伤害 = 基础伤害 × 当前友军伤害倍率
```

是否允许友军伤害以及对应倍率，由当前攻击配置决定。

当前阶段不额外引入第二套友军伤害公式。

---

# 5. 已发出攻击的伤害

攻击弹体已经正式发出后，按照弹体自身生命周期继续结算。

因此：

```text
攻击已经发出
+
攻击单位随后移动 / 停止 / 死亡
=
已经存在的弹体继续按照自身规则处理
```

如果弹体最终命中合法目标，则正常进入伤害结算。

---

# 6. 死亡后的系统结果

单位生命值降至 0 后，至少需要保证：

- 单位离开正常可控状态；
- 当前活动命令进入单位失效终态；
- 不再接受新的单位命令；
- 不再作为合法存活攻击目标；
- 选择系统不再返回该单位作为有效成员；
- 数字编队调用时清理该失效单位；
- AI 与战役任务读取新的合法世界状态；
- 胜负和任务系统可以依据单位死亡继续判断。

这些属于 RTS 战役 Demo 必须保证的基础闭环。

---

# 7. 当前 Demo 必须验收

必须保证：

1. 武器攻击能够产生基础伤害。
2. 伤害能够正确减少目标生命值。
3. 友军伤害按照当前配置处理。
4. 生命值不会降到 0 以下。
5. 生命值为 0 后单位正确死亡 / 被摧毁。
6. 死亡单位不会继续作为正常命令或攻击目标。
7. 单位死亡后选择、编队、AI 查询、任务和胜负可以读取正确的新状态。

---

# 8. 当前阶段不做的复杂伤害设计

以下内容不是当前几个战役 Demo 的 RTS 最小必备能力，保留历史设计但不作为当前程序目标：

- ~~最终伤害 = 攻击力 × 克制倍率 × 100 ÷（100 + 护甲）。~~
- ~~统一护甲曲线和有效生命值公式。~~
- ~~伤害类型：常规 / 穿甲 / 爆破。~~
- ~~护甲类型：轻型 / 重型 / 建筑。~~
- ~~常规 / 穿甲 / 爆破对不同护甲类型的完整克制倍率表。~~
- ~~目标单位配置护甲数值。~~
- ~~目标单位配置护甲类型。~~
- ~~护盾优先承受伤害，护盾不足后再扣生命值。~~
- ~~复杂友军伤害减免公式。~~
- ~~治疗基础值 + 属性加成 + 最大生命值加成 + 已损失生命值加成。~~
- ~~治疗效果增加比例 / 降低比例。~~
- ~~完整治疗系统。~~

这些内容以后需要做兵种克制、英雄、技能或完整数值平衡时再重新启用。

---

# 9. 当前原则

当前战役 Demo 的伤害系统只要求：

**基础伤害 → 生命值 → 死亡 → 世界状态正确更新。**

先保证这条链稳定，再扩展护甲、护盾、克制、治疗等高级数值系统。
