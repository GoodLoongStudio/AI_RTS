# 第一战役《回声撤离》地图与流程设计

> 类型：搜打撤式教学战役  
> 建议时长：完整深入路线 55～70 分钟；玩家可在约 20、40、60 分钟主动撤离  
> 核心体验：搜索未知区域、控制交战风险、带着成果活着撤离  
> 教学目标：让玩家在剧情压力中自然学会选择、移动、战斗、小队指挥、AI 协作、微操与撤离

## 1. 一句话故事

玩家带领三支小队进入失联战区，搜寻一支不断发送求救信号的友军侦察队；随着搜索深入，玩家发现信号只是受损 Agent 循环播放的“最后回声”，但真正的幸存者和一枚记录敌方新战术的黑匣子仍在战区深处，而敌军已经封锁撤离路线。

## 2. 为什么选择这个经典情节

《回声撤离》组合了几种经典、容易建立预期的战争故事结构：

1. **普通搜救变成高风险任务**：最初目标简单，进入后局势逐级升级。
2. **循环求救信号**：玩家以为目标就在前方，却发现信号来自过去。
3. **废墟中的幸存者**：最初希望落空后，仍留下一个值得冒险的真实目标。
4. **任务与人命的选择**：黑匣子、幸存者和部队安全无法毫无代价地全部获得。
5. **撤离点失效**：玩家完成搜索后不能原路轻松离开，必须临时重组计划。
6. **最后一班撤离艇**：最终用短时间防守制造清楚、经典的高潮。
7. **带回来的东西改变后续故事**：成功撤出的情报成为第二关的剧情钩子。

这些情节本身容易理解，不需要大量世界观说明；真正的新意来自 AI RTS 的表达方式：不同角色 Agent 对风险、救援和撤离提出不同意见，玩家既在指挥部队，也在判断信息是否可信。

## 3. 玩家身份与任务简报

玩家是一支快速反应部队的现场指挥官。战区中的“北辰通信站”在六小时前失联，侦察七队最后发送了一段求救信息：

> “通信站遭到袭击。我们携带重要情报，请求立即撤离。”

任务目标分三层：

- **最低目标**：至少一支小队抵达撤离点并成功撤出；
- **主要目标**：找到侦察七队或确认其状态；
- **高价值目标**：带回敌方战术黑匣子；
- **可选目标**：搜集补给、营救幸存者、关闭敌方干扰设备。

玩家不是必须清空地图。继续搜索可以获得更多资源和剧情，但会提高伤亡、时间和撤离风险。

## 4. 主要角色 Agent

### 4.1 副官 Agent“岚”

- 定位：系统教学、命令复述、风险汇总；
- 性格：冷静、克制、重视证据；
- 知识边界：只使用已侦察区域、传感器和友军报告；
- 剧情作用：最先发现求救信号的时间戳异常；
- 教学作用：解释信息可信度、AI 建议和托管状态。

### 4.2 侦察小队长“隼”

- 定位：侦察、路线判断、战场发现；
- 性格：果断、好奇、愿意冒险；
- 倾向：主张继续深入搜索；
- 教学作用：引导侦察命令、视野、隐蔽路线和情报标记。

### 4.3 突击小队长“磐石”

- 定位：正面战斗、防守和撤退保护；
- 性格：谨慎、重视部队生存；
- 倾向：伤亡升高时建议提前撤离；
- 教学作用：引导攻击、防守、追击边界和接管微操。

### 4.4 幸存者“白鸦”

- 定位：侦察七队仅存成员，携带部分战术数据；
- 性格：疲惫、警惕，对己方指挥系统存在怀疑；
- 剧情作用：揭示“求救信号不是实时信息”，并指出黑匣子的位置；
- 后续作用：若成功撤出，可以在第二关成为可用 Agent 或关键证人。

角色提醒采用可选的弹幕式短句呈现，但信息必须同时落入战报或地图标记。关闭角色提醒不会丢失任务必要信息。

## 5. 小队配置

第一关只使用三支定位明显的小队，避免教学阶段出现单位海。

| 编号 | 小队 | 定位 | 教学价值 |
| --- | --- | --- | --- |
| 1 | 突击队 | 正面作战、承受火力 | 移动、攻击、防守、集火 |
| 2 | 侦察队 | 高机动、视野、标记目标 | 侦察、路线、战争迷雾 |
| 3 | 支援队 | 治疗、压制或维修 | 小队协同、保护和站位 |

`1～3` 默认直接选择三支小队，UI 保留 `4～6` 空槽，让玩家从第一关就理解完整的六槽小队结构。具体战斗命令在 `QWERDF` 热区中的最终位置后期测试决定，教程读取实际绑定并显示对应按键。

## 6. 地图结构

地图采用一条清楚的主路线、两条风险支线和多条真实连通的撤离路线：

```text
                      [可选：废弃补给仓]
                             │
[降落区/紧急空运] → [外围营地] → [坠毁车队] → [北辰通信站]
                                              │          │
                                     [地下机房]      [载具维修场]
                                         │              │
                                  [地下通道撤离]    [地面车队撤离]
                                         │              │
                                         └──→ [塔台/最终空运]
```

- **主路线**保证首次玩家不会迷路；
- **支线**提供搜打撤的收益、撤离条件和风险选择；
- **通信站**承担剧情反转；
- **原计划撤离点失效**迫使玩家重新评估已经发现的路线；
- **紧急空运、地下通道、地面车队和最终空运**形成不同成本的退出方案；
- **塔台最终空运**提供完整深入路线的防守高潮，但不是唯一正确结局。

### 6.1 无缝地图与连续行军

第一战役采用一张连续地图和统一世界坐标。运输艇在开场放下部队后，玩家可以从降落区一路行军到通信站、地下机房和最终撤离点，全程不切换场景、不出现加载画面，也不通过瞬间传送改变部队位置。

无缝体验遵循以下原则：

- 所有主要地点在空间上真实连接，玩家走过的路线始终可以回看和返回；
- 地下机房通过坡道、隧道或真实运行的短程升降平台连接，不使用黑屏传送；
- 剧情演出可以短暂移动镜头，但不能偷偷移动玩家单位；
- 撤离点改变意味着部队需要实际穿越地图前往新地点；
- 已经发生的战斗痕迹、打开的补给箱、阵亡单位和被破坏设施尽量保留；
- 侦察得到的路线和已探索区域持续有效，让玩家建立真实空间记忆；
- 返回旧区域时不重新刷新同一批敌人，只允许符合剧情逻辑的追兵或增援进入。

第一关规模应控制在单场景可以稳定承载的范围内。Godot 中可以让整张地形、碰撞和导航始终存在，只按区域启用远处的高成本表现、AI 思考、音效和特效。

如果后续地图扩大，则采用玩家无感的分区流式加载：

- 地图按降落区、外围、车队、通信站、地下机房和撤离区划分 Sector；
- 玩家接近前，后台提前加载下一 Sector，而不是到达门口才开始加载；
- 山体、建筑、战争迷雾和路线转折用于遮挡尚未完成加载的远处细节；
- 导航边界、任务状态和单位数据跨 Sector 持续存在；
- 只有视觉资源和非关键模拟允许休眠，玩家小队、任务对象和已经接触的敌人不能因分区而重置；
- 性能不足时优先降低远处动画、特效和 AI 更新频率，不使用传送掩盖性能问题。

目标不是技术上“从不读取任何资源”，而是让玩家感知到一个连续、可信、没有加载中断的战场。

### 6.2 弹性时长与多种撤离方式

完整深入路线以一小时左右为目标，但游戏不要求所有玩家强制停留一小时。撤离权属于玩家：随着搜索推进，玩家会逐渐发现并解锁不同撤离方式，可以根据当前伤亡、物资、任务成果和风险承受能力决定何时离开。

| 撤离方式 | 最早时段 | 前置条件 | 优势 | 代价与风险 |
| --- | ---: | --- | --- | --- |
| 降落区紧急空运 | 约 20～30 分钟 | 修复信标并返回初始降落区 | 最早离开、路线已知 | 空中封锁下只能短暂停留，优先撤出伤员或关键物品，收益较低 |
| 地下维护通道 | 约 35～50 分钟 | 找到通行密钥并恢复闸门 | 敌军较少、无需长时间防守 | 通道狭窄，只能携带有限物资，需要放弃重型装备 |
| 地面装甲车队 | 约 40～55 分钟 | 搜集能源和维修零件 | 容量大，可带出多数人员与战利品 | 发动后暴露位置，需要护送并突破公路封锁 |
| 塔台最终空运 | 约 55～70 分钟 | 深入塔台并恢复远程通信 | 可以完成主要目标并带出最高价值成果 | 等待校准期间敌军持续进攻，风险最高 |

表中的时间是首次玩家的设计区间，不是硬性倒计时。熟练玩家可能更早满足条件，谨慎搜索的玩家也可能更晚抵达。

撤离系统遵循以下规则：

- 撤离方式通过侦察、终端、角色 Agent 或环境线索被发现，不在开局一次性全部标出；
- 发现撤离方式后，其位置、条件、容量、预计准备时间和风险会永久记录在地图上；
- 玩家主动发出“准备撤离”命令后才进入对应流程，普通探索不会突然触发不可逆倒计时；
- 确认前必须列出能够撤出的单位、物资、伤员以及需要放弃的内容；
- 允许分批撤离：先送走伤员、幸存者或黑匣子，剩余小队继续行动后选择另一条路线；
- 已撤离单位不能无理由重新返回战场，留下的小队继续承担风险；
- 每条路线必须产生不同的行军、护送、防守或资源决策，不能只是换一个出口播放相同动画；
- 敌方压力随暴露程度和停留时间逐渐提升，但不使用不可见的强制惩罚；
- 副官可以推荐撤离方案并比较风险，但不能替玩家确认撤离；
- 所有撤离都要求单位实际抵达入口或登上载具，不使用瞬间传送。

玩家控制时长的基本节奏为：

```text
约 20 分钟：已有少量成果，可以保守撤离
约 40 分钟：完成主要调查，可以选择中程撤离
约 60 分钟：完成深度搜索，挑战高风险完整撤离
```

这样“一小时”代表玩家主动选择的最大投入和完整体验，而不是被教程、路程或敌人血量拖延出来的固定时长。

### 6.3 地图行动路线蓝图

地图采用“主轴清楚、侧翼互通、撤离成环”的结构。玩家第一次进入时能沿主路稳定推进，熟悉地图后则可以利用山脊、地下通道和维修道路绕行。

```text
                                      北
                                      ↑

            [P5 观测山脊] ───── [P6 干扰阵地] ───── [P11 塔台下层] ── [X4 塔台最终空运]
                  │                    │                    │                │
                  │                    └──────┐             │                │
                  │                           │             │                │
[P3 废弃补给仓] ──┼── [P4 坠毁车队] ───── [P7 北辰通信站] ── [P10 载具维修场] ── [X3 东部公路出口]
       │          │          │                │                    │
       │          │          └──────┐         │                    │
       │          │                 │         │                    │
[X1/P1 初始降落区] ─ [P2 外围营地] ───┴── [P8 地下机房] ───── [P9 维护通道] ── [X2 地下出口]
       │
    地图西侧

图例：P = 行动/资源节点，X = 可用撤离出口；同一区域可以同时具有两种功能
```

关键连接关系：

- **基础主线**：X1 初始降落区 → P2 外围营地 → P4 坠毁车队 → P7 北辰通信站；
- **侦察侧线**：P2 → P3 废弃补给仓 → P5 观测山脊 → P6 干扰阵地；
- **地下搜救线**：P7 → P8 地下机房 → P9 维护通道 → X2 地下出口；
- **车队撤离线**：P7 → P10 载具维修场 → X3 东部公路出口；
- **最终深入线**：P7/P6 → X4 塔台最终空运；
- **紧急回撤线**：任意已探索主路 → P2 → X1 初始降落区。

地图必须允许侧线重新汇入主线。玩家不应因为选择侦察路线而被迫原路返回十分钟，也不应在选择撤离方式前才发现路线完全不连通。

### 6.4 路线长度与行军标准

实际 Godot 世界尺寸等单位移动、镜头缩放和战斗密度稳定后再确定。关卡设计阶段先使用玩家可感知的行军时间：

- 相邻普通节点之间，脱战行军约 45～90 秒；
- 初始降落区到通信站，首次包含搜索与教学约 20～30 分钟；
- 地图完全探索后，从通信站直接返回降落区约 3～5 分钟；
- 从通信站抵达任一中程撤离准备区约 2～4 分钟；
- 任意连续三分钟行军中至少出现一次路线判断、环境信息或轻量交互；
- 不用重复刷新的敌人拖延返程，已经清理的路线保持相对安全，但可能出现符合逻辑的追兵；
- 重要岔路口通过地标、光线、道路材质和地图标记辨识，不依赖小地图上的抽象箭头才能找到。

完整地图直接跑一圈不能耗时一小时。一小时来自搜索、战斗、资源权衡、情报判断和撤离准备，而不是单纯走路。

### 6.5 战场资源分类

第一战役只引入与搜打撤决策直接相关的五类资源，不在新手关同时展开完整基地经济。

| 资源 | 战场作用 | 是否占用带出容量 |
| --- | --- | --- |
| 弹药补给 | 恢复小队持续作战能力，部分重武器消耗更多 | 普通补充不占；密封弹药箱占用 |
| 医疗补给 | 治疗伤员、稳定白鸦、减少撤离途中减员 | 急救直接消耗；医疗箱占用 |
| 工程零件 | 修复终端、信标、闸门和装甲车 | 占用 |
| 能源核心 | 启动干扰器、载具、塔台或高价值设备 | 占用且较重 |
| 情报数据 | 揭示路线、敌军部署和后续战役信息 | 数据本身轻量，黑匣子占用重型槽位 |

资源分为三种取得结果：

1. **立即补充**：现场使用的普通弹药与医疗，不需要带出；
2. **任务工具**：工程零件、能源核心和密钥，用于开启路线或撤离方式；
3. **战役成果**：黑匣子、稀有装备和完整情报，只有成功撤离才计入长期收益。

玩家打开资源点时，界面必须说明“现在使用”“携带备用”和“留在原地”的区别。自动拾取不能让小队在玩家不知情时超载。

### 6.6 资源点布置

| 编号 | 地点 | 核心资源 | 风险与交互 | 对路线的影响 |
| --- | --- | --- | --- | --- |
| P1 | 初始降落区野战箱 | 少量弹药、医疗 | 安全，用于教学补充界面 | 为紧急回撤保留最低补给 |
| P2 | 外围营地 | 医疗箱、旧终端 | 低风险，搜索时发现信号异常 | 标出 P4 主线和 P3 支线 |
| P3 | 废弃补给仓 | 大量弹药、工程零件 | 有巡逻队；强行开门会制造噪声 | 零件可修复信标、闸门或载具 |
| P4 | 坠毁车队 | 工程零件、部分情报 | 激活终端后触发第一次正式交战 | 解锁 X1 紧急空运条件之一 |
| P5 | 观测山脊 | 敌军部署情报、狙击装备 | 需要侦察接近，正面上山容易暴露 | 提前显示 P6、P7 和公路伏击点 |
| P6 | 干扰阵地 | 能源核心、通信权限 | 中高风险，可摧毁或接管 | 降低空运等待和敌方增援强度 |
| P7 | 北辰通信站 | 主线记录、路线数据库 | 剧情反转；读取数据提升警戒 | 同时显示 X2、X3、X4 的大致条件 |
| P8 | 地下机房 | 白鸦、黑匣子、医疗补给 | 精英敌人、狭窄空间、微操压力 | 获得完整情报并找到 P9 密钥 |
| P9 | 维护通道 | 闸门控制器、少量工具 | 低能见度，追兵可能从后方进入 | 满足 X2 地下撤离条件 |
| P10 | 载具维修场 | 装甲车、燃料接口、重型弹药 | 启动车辆会大幅提高敌方警戒 | 满足 X3 车队撤离条件 |
| P11 | 塔台下层仓库 | 最终弹药、一次增援信标 | 高风险，拿取后无法再次补充 | 支撑 X4 最终防守，但不保证胜利 |

资源点采用“看得见的机会成本”：

- P3 的工程零件不足以同时完成所有维修，玩家必须选择信标、地下闸门或装甲车；
- P6 的能源核心可以用于降低空运风险，也可以保留为下一关成果；
- P8 的黑匣子占用重型携带槽，使小队移动速度下降；
- P10 的车队容量最大，但启动噪声会改变敌军巡逻和封锁；
- P11 是最后补充，不应无限刷新，玩家必须带着此前选择进入高潮。

### 6.7 四条撤离行动路线

#### X1：降落区紧急空运

```text
当前位置 → P4 坠毁车队 → P2 外围营地 → X1 初始降落区
```

- 适合：伤亡较高、已经获得少量情报或只想完成基础教学的玩家；
- 关键资源：工程零件修复信标；摧毁 P6 干扰器可以进一步降低风险；
- 行动变化：走已经熟悉的路线回撤，但敌军会尝试切断最后一段道路；
- 容量规则：运输艇停留时间有限，可能需要分批决定人员和物资优先级；
- 预计总时长：20～35 分钟。

#### X2：地下维护通道

```text
P7 通信站 → P8 地下机房 → P9 维护通道 → X2 地下出口
```

- 适合：希望救出白鸦、避免大规模战斗的玩家；
- 关键资源：维护密钥和一组工程零件；
- 行动变化：狭窄空间、封门、断后和低能见度追击；
- 容量规则：人员和轻型数据优先，重型装备及多余资源需要放弃；
- 预计总时长：35～55 分钟。

#### X3：地面装甲车队

```text
P7 通信站 → P10 载具维修场 → 东部维修道路 → X3 公路出口
```

- 适合：希望带走最多物资和多数人员的玩家；
- 关键资源：两组工程零件与一个能源核心；
- 行动变化：维修期间防守、分配驾驶/护卫小队、清除两处路障；
- 容量规则：容量最大，可以携带黑匣子、伤员和重型物资；
- 预计总时长：40～60 分钟。

#### X4：塔台最终空运

```text
P7 通信站或 P6 干扰阵地 → P11 塔台下层仓库 → X4 塔台平台
```

- 适合：完成深度搜索、追求全部主要成果和高风险战斗的玩家；
- 关键资源：通信权限；能源核心可以缩短校准时间；
- 行动变化：恢复塔台、布置防线、抵抗多方向进攻并分批登艇；
- 容量规则：理论容量最高，但伤亡风险和等待时间也最高；
- 预计总时长：55～75 分钟。

### 6.8 动态敌军压力

敌军压力由玩家行为推动，而不是只按现实时间不断刷兵。系统维护一个对玩家可解释的“暴露等级”：

| 等级 | 状态 | 典型触发 | 战场变化 |
| --- | --- | --- | --- |
| 0 | 未察觉 | 开局、隐蔽移动 | 固定巡逻，资源点风险最低 |
| 1 | 怀疑 | 发现痕迹、远距离交火 | 巡逻改变路线 |
| 2 | 搜索 | 读取终端、长时间交战 | 敌军检查关键路口 |
| 3 | 警戒 | 启动通信站、摧毁干扰设备 | 增援进入已知区域 |
| 4 | 封锁 | 启动装甲车、携带黑匣子暴露 | 公路和空运点被重点封锁 |
| 5 | 围剿 | 塔台呼叫最终空运 | 多方向持续进攻直到撤离 |

- UI 只显示可理解的描述，不需要暴露精确内部数值；
- 隐蔽侦察、关闭报警和快速转移可以延缓等级提升；
- 高暴露不会让敌人凭空出现在视野内，增援必须从地图边缘、设施或已知通道进入；
- 已探索资源点不会重置，敌人也不会为了补足数量重复占领所有旧区域；
- 角色 Agent 根据实际情报解释压力变化，例如“车队启动声已经暴露东部路线”。

### 6.9 地图节奏验收

- 玩家首次是否能在没有导航箭头常驻的情况下找到 P2、P4 和 P7？
- 玩家是否能在十秒内看懂四条撤离路线的方向差异？
- 每个可选资源点是否至少改变一种路线条件或撤离选择？
- 玩家是否会因为资源不足而做选择，而不是机械清空所有箱子？
- 清理过的路线是否明显缩短回撤时间？
- 走不同路线是否真正产生侦察、护送、潜行、防守等不同玩法？
- 暴露等级变化是否能够由玩家行为解释？
- 完整深入路线是否接近一小时，而最快撤离路线仍可在约半小时内完成？

## 7. 完整流程

### 阶段 0：冷开场——进入失联战区

**时长：3～5 分钟**

运输艇放下三支小队后立即离开。远处通信站间歇闪烁，求救信号重复播放。

玩家操作：

- 移动镜头、缩放和观察地图；
- 用 `1～3` 选择不同小队；
- 双击数字键定位小队；
- 给第一小队下达一次移动命令。

教学不使用长弹窗。副官只说：“先确认三支小队状态，再向外围营地推进。”对应 UI 高亮数字栏和第一个移动槽位。

完成条件：三支小队至少有一支抵达外围营地。

### 阶段 1：第一次搜索——空无一人的外围营地

**时长：5～7 分钟**

营地没有尸体，也没有明显交战痕迹，只留下被快速带走的设备。这里让玩家第一次感到“信息不对”。

玩家操作：

- 框选多个单位或小队；
- 使用 Shift 追加选择；
- 与终端、补给箱进行情境交互；
- 查看右侧战报和角色提醒。

搜索结果：

- 少量补给；
- 一条指向坠毁车队的足迹；
- 求救信号仍声称“我们被困在通信站”，但时间戳没有变化。

副官只提示事实：“信号内容重复，时间信息缺失。”不直接告诉玩家答案。

完成条件：检查终端或找到足迹。

### 阶段 2：侦察与第一次选择——车队残骸

**时长：7～9 分钟**

前往车队途中出现两条路线：

- 正面公路较快，但可能接敌；
- 右侧林地较慢，但适合侦察。

玩家可以用 UI、地图、文本或语音表达：“二队从右边侦察，其他人沿公路推进。”

AI 复述：

- 执行单位；
- 两条路线；
- 是否允许主动交战；
- 汇合地点。

这里第一次教学“自然语言命令不是聊天回复，而是可检查、可修改的行动计划”。

在车队附近，侦察队发现一支小规模敌军。玩家可以：

- 绕开敌人继续搜索；
- 伏击敌人获得补给；
- 让 AI 执行攻击，自己观察；
- 手动控制突击队完成第一次微操。

完成条件：搜索车队残骸，不要求消灭全部敌军。

### 阶段 3：第一次交战——被监听的求救频道

**时长：7～9 分钟**

车队终端被激活后，敌军沿最近路线进入。玩家学习完整战斗闭环：

- 指定攻击目标；
- 设置防守区域和追击边界；
- 使用小队特色能力；
- 用支援队保持阵线；
- 在 AI 托管与手动接管之间切换。

经典情节在这里第一次兑现：敌军不是偶然巡逻，而是在监听求救频道，等待搜救部队暴露位置。

战斗结束后，副官报告：

> “敌军在我们读取终端后立即响应。这个求救频道可能已经成为诱饵。”

玩家获得一次明确但不强制的撤离机会。谨慎玩家可以带着已有补给直接前往备用撤离路线，但会错过主要剧情与黑匣子。

### 阶段 4：通信站反转——过去的回声

**时长：6～8 分钟**

进入通信站后，玩家找到正在自动工作的通信 Agent。它没有敌意，也没有正常对话能力，只是在循环发送侦察七队六小时前录下的最后求救。

副官通过记录证明：

- 求救并非实时信息；
- 侦察七队曾经抵达这里；
- 他们发现敌方正在记录和模仿友军通讯；
- 一名幸存者带着黑匣子逃向地下机房。

这是本关的核心情节转折：希望暂时落空，但新的真实目标出现。

玩家选择：

1. **立即撤离**：风险最低，保留已有补给；
2. **寻找幸存者**：进入地下机房，承担额外交战；
3. **寻找黑匣子**：高价值目标，可能与幸存者路线部分重合；
4. **同时尝试**：收益最高，但会触发更早的敌方封锁。

角色 Agent 会表达不同意见，但不替玩家作决定。

### 阶段 5：搜救与高价值物资——地下机房

**时长：10～12 分钟，可选**

地下机房空间狭窄，无法依靠大范围框选解决问题。玩家需要控制一到两支小队交替推进，并保护支援队。

这里教学：

- 精确选择和局部微操；
- 集火高威胁目标；
- 队列命令；
- 让另一支小队由 AI 固守后方；
- 通过角色提醒识别哪个方向出现风险。

玩家找到受伤的“白鸦”。她持有部分数据，但完整黑匣子位于隔壁设备间。携带黑匣子会降低一支小队的移动速度，形成明确的搜打撤负担。

玩家必须决定：让谁携带、谁负责开路、谁负责断后。

### 阶段 6：原撤离点失效——选择如何离开

**时长：5～8 分钟**

当玩家准备呼叫原计划运输艇时，敌方干扰使该地点无法安全降落。这个转折不会把玩家强制送往唯一的新出口，而是把此前发现的撤离情报汇总成一张方案卡：返回降落区呼叫紧急空运、打开地下维护通道、修复地面装甲车队，或者继续深入塔台争取最终空运。

这不是无提示的强制反转。玩家在接近 A 点前会看到干扰强度升高，副官给出风险预警。若玩家此前完成可选的干扰设备目标，则：

- 更早获知 A 点可能失效；
- 所有空运方案的等待时间更短；
- 敌方增援数量减少。

副官会根据当前状态给出比较，而不是一个“最优答案”：

```text
紧急空运：预计 7 分钟，容量有限，当前成功率较高
地下通道：预计 9 分钟，需要放弃重型物资
装甲车队：预计 12 分钟，可带走全部物资，公路存在两处封锁
塔台空运：预计 18 分钟，可完成全部目标，敌军压力最高
```

玩家可以直接选择，也可以继续侦察后再决定。选择撤离方案后，地图显示准备步骤、实际行军路线和可能需要放弃的对象，玩家再次确认才进入不可逆的最后阶段。

玩家现在需要重新编组：

- 快速小队先行侦察所选路线；
- 携带黑匣子或伤员的小队走安全路线；
- 战斗小队负责阻滞追兵；
- 可以用自然语言一次下达整个撤离计划。

### 阶段 7：执行撤离——由玩家决定高潮

**时长：8～10 分钟**

最终高潮根据玩家选择发生变化：

- **紧急空运**：小队沿已经走过的区域快速回撤，在短暂降落窗口中决定撤出顺序；
- **地下通道**：在狭窄环境中边撤边封门，重点是控制追兵和决定放弃哪些重物；
- **装甲车队**：一支小队维修和驾驶载具，其余小队解除路障、护送并应对伏击；
- **塔台空运**：恢复通信并进行最长时间的区域防守，敌军从多个方向进攻，回报最高。

只有塔台路线使用“最后一班撤离艇”的完整防守场面。其他路线拥有不同高潮，不能缩减为同一场战斗换一个背景。

高潮需要同时支持两类玩家：

- 指挥型玩家可以把两支小队交给 AI 防守，自己调整整体优先级；
- 微操型玩家可以亲自控制关键小队集火、拉扯和保护伤员；
- 混合型玩家可以让 AI 守正面，自己处理侧翼突袭。

撤离不是必须全员同时登艇：

- 玩家可以让伤员和黑匣子先撤；
- 其他小队继续防守后分批撤离；
- 若坚持搜刮最后一个目标，可能错过当前窗口，但仍有机会改走其他路线；
- 至少一支小队撤出即可进入结算，不轻易用全盘失败否定玩家已经投入的整段行动。

撤离最后阶段减少非必要 UI 信息，只保留路线目标、准备进度、小队状态、预计容量和高优先级角色提醒。

### 阶段 8：结算——带回了什么

**时长：3～5 分钟**

结算不只显示击杀数，而是总结玩家的指挥结果：

- 撤出的小队与人员；
- 搜集到的补给和情报；
- 是否营救白鸦；
- 是否带回完整黑匣子；
- 使用了哪种撤离方式、何时决定离开以及分几批撤离；
- 使用 AI 托管和手动接管的关键时刻；
- 避免的战斗与主动承担的风险；
- 因玩家选择而改变的下一关条件。

若黑匣子成功撤出，结尾播放一段被截断的数据：敌人似乎正在学习己方的指挥模式，并能够伪造可信的战场通讯，为第二关埋下伏笔。

| 情境交互 | 搜索终端和补给箱 | 搜索本身就是任务目标 |

| 文本/语音复合命令 | 两路推进 | 玩家第一次表达战术意图 |
| 攻击、防守和追击限制 | 终端引来敌军 | 敌人主动制造战斗压力 |

| 信息可信度 | 求救时间戳异常 | AI 解释能力进入剧情核心 |

| 混合指挥 | 玩家选择的撤离高潮 | AI 指挥与微操同时产生价值 |

## 9. 搜打撤的收益与风险

### 9.1 可带出的成果

- 补给：影响下一关初始资源；
- 黑匣子：解锁敌军情报和新任务路线；
- 幸存者：新增角色 Agent、对话和能力；
- 战术记录：记录玩家常用战术，用于后续复盘或 AI 建议；
- 完整小队：保留经验、关系和角色状态。

### 9.2 风险来源

- 搜索时间越长，敌军封锁程度越高；
- 携带黑匣子或伤员会降低机动性；
- 弹药、治疗或技能资源有限；
- 部队伤亡可能影响后续战役；
- AI 建议基于有限情报，不保证一定正确；
- 高价值支线可能让玩家错过最佳撤离窗口。

风险必须可观察、可预警，不能靠突然刷兵或隐藏倒计时制造惩罚。

## 10. 分支与后续影响

| 本关结果 | 第二关影响 |
| --- | --- |
| 白鸦与黑匣子均撤出 | 获得完整情报和新角色 Agent，开启主动反制路线 |
| 只救出白鸦 | 获得角色证词，但敌方技术信息不完整 |
| 只带回黑匣子 | 获得战术优势，但团队质疑“任务高于人命”的选择 |
| 两者都未带回 | 进入防御性路线，通过其他方式调查敌军 |
| 多数小队完整撤出 | 下一关拥有更好的初始兵力和角色信任 |
| 伤亡严重 | 下一关获得补充兵，但老队员关系和台词发生变化 |
| 通过地下通道撤离 | 保留人员但损失重型物资，解锁地下网络情报 |
| 通过装甲车队撤离 | 保留大量战利品，下一关获得载具或额外资源 |
| 完成塔台最终空运 | 获得最完整的任务情报，但可能承担更高伤亡 |

所有结果都允许战役继续。第一次任务的重点是让玩家承担选择后果，而不是寻找唯一正确答案。

## 11. 失败与降级设计

- 关键教学操作连续失败时，副官先给建议，再询问是否临时协助，不能直接夺取控制权；
- 玩家没有使用自然语言时，仍可通过 UI 和快捷键完成全部任务；
- 语言模型离线时，由固定语法和快捷任务卡完成核心复合命令；
- 玩家错过幸存者或黑匣子时，不阻止撤离和后续战役；
- 全军覆没才是明确失败，允许从最近阶段检查点重试；
- 撤离阶段提供“立即重整”选项，避免玩家因早期编组失误陷入不可逆局面；
- 当前撤离方案失败时，只要战场条件允许，玩家可以尝试已发现的其他路线，而不是立即判定整局失败。

## 12. 首次演示建议

用于对外展示时，控制在 8～10 分钟，只展示完整流程中的关键片段：

1. 三支小队降落并用数字键快速选择；
2. 语音命令侦察队走右路；
3. 第一次交战中展示 AI 托管和手动接管；
4. 通信站揭示“求救只是过去的回声”；
5. 玩家决定营救白鸦并携带黑匣子；
6. 撤离点失效，展示四种方案的容量、时间和风险差异；
7. 玩家选择其中一种，并用一句复合命令重新组织撤离；
8. 撤离高潮中同时体现指挥和微操；
9. 结算展示撤离方式和带出成果如何影响下一关。

## 13. 本关体验验收

- 玩家是否在不阅读长教程的情况下完成基础选择和移动？
- 玩家是否理解“数字键选谁、QWERDF 做什么、鼠标决定目标”的操作模型？
- 玩家是否至少主动使用一次 AI 指挥，并看懂其复述结果？
- 玩家是否至少主动接管一次 AI 托管的小队？
- 玩家是否能解释求救信号为什么不可信？
- 玩家是否在继续搜索和提前撤离之间产生真实犹豫？
- 玩家是否理解不同撤离方式的容量、准备时间、风险和收益？
- 玩家是否感觉自己能够主动控制本关时长，而不是被流程强制拖延？
- 不同撤离高潮是否都允许宏观指挥和局部微操？
- 关闭角色提醒后，任务是否仍然完整可玩？
- 结算是否让玩家感到“这是我的选择造成的结果”？
- 玩家结束后是否愿意带着本关结果进入第二关？

## 14. 核心情绪曲线

```text
好奇进入
  → 轻松学习
    → 发现异常
      → 第一次胜利
        → 希望落空
          → 是否冒险的犹豫
            → 选择撤离时机和路线
              → 携带成果逃亡
                → 不同撤离方式的高潮
                  → 成功撤离与后续悬念
```

本关最终要留下的记忆，不是“我完成了新手教程”，而是：

> 我追着一段已经过时的求救信号进入战区，自己决定要深入到什么程度、为谁冒险、带走什么，并选择了最适合当时战况的撤离方式。
