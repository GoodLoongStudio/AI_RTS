# 12. 当前战役 RTS Demo P0 顺序

1. 选择与控制组
2. 输入与镜头
3. 指令与单位命令
4. 移动与导航稳定性
5. 战斗
6. 伤害与死亡
7. 战争迷雾与合法情报
8. 战役任务与战场事件推进
9. 胜负与对局生命周期
10. AI 副官接入正式 RTS 接口
11. 完成多个可完整游玩的战役关卡

以下系统当前不进入 P0：

- [暂缓] 资源采集与经济循环
- [暂缓] 基地建造循环
- [暂缓] 单位生产与扩军循环
- [暂缓] 科技
- [暂缓] 补给

当前 Demo 的核心验收目标是：**RTS 战斗、指挥、情报、AI 副官和战役流程完整可玩。**
