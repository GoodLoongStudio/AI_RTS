# 策划文档_战斗基础规则

> 状态：待评审  
> 本文定义普通攻击战斗流程、目标保持、追击、打断与战斗结束规则。

---

# 1. 战斗基本流程

单位进入普通攻击后，统一按照以下流程执行：

```text
获得攻击目标
↓
检查是否处于可攻击位置
↓
不满足
→ 接近目标

满足
→ 攻击前摇
↓
攻击事件发生
↓
攻击后摇
↓
等待下一次攻击
↓
重新检查目标
```

如果目标仍然有效，则继续下一轮攻击。

如果目标失效，则结束当前战斗或恢复原行为。

---

# 2. 战斗状态

普通攻击使用以下状态：

```text
无战斗目标
接近目标
攻击前摇
攻击后摇
等待下一次攻击
```

“攻击事件”是一次瞬时事件，不作为持续状态。

基础转换关系：

```text
无战斗目标
↓
获得目标

当前位置不能攻击
→ 接近目标

当前位置可以攻击
→ 攻击前摇

接近目标
↓
进入可攻击位置
→ 攻击前摇

攻击前摇
↓
到达攻击事件时点
→ 产生攻击事件
→ 攻击后摇

攻击后摇结束
→ 等待下一次攻击

攻击间隔满足
↓
目标仍然有效
→ 重新进入攻击前摇
```

---

# 3. 攻击目标保持

单位一旦拥有当前攻击目标：

> **只要当前目标仍然合法，默认继续攻击当前目标。**

普通情况下，不因为附近出现新的敌人频繁切换目标。

以下情况结束当前目标：

- 目标死亡或被摧毁；
- 目标离场；
- 目标变成不可攻击对象；
- 当前行为已经不允许继续追击；
- 玩家明确指定新的目标；
- 新的有效命令覆盖当前行为。

---

# 4. 明确攻击

玩家明确指定一个敌人进行攻击后：

```text
指定目标
↓
目标合法
↓
进入攻击流程
```

如果目标不在攻击位置：

```text
接近目标
↓
进入攻击位置
↓
开始攻击
```

目标移动后离开攻击位置：

```text
继续追击
↓
重新进入攻击位置
↓
继续攻击
```

途中出现其他普通敌人，不自动切换目标。

明确攻击持续到：

- 目标失效；
- 目标无法继续完成攻击；
- 新的有效命令覆盖当前攻击。

---

# 5. 攻击移动

攻击移动始终保留原推进目标。

```text
向目标区域推进
↓
发现敌人
↓
临时进入战斗
↓
当前战斗结束
↓
继续原推进目标
```

攻击移动中的战斗只是一段临时行为。

不会因为一次遇敌，把原推进目标永久替换掉。

---

# 6. 巡逻战斗

巡逻途中遇敌：

```text
巡逻
↓
临时进入战斗
↓
战斗结束
↓
继续原巡逻
```

一次战斗不会改变原巡逻路线。

---

# 7. 原地防守

原地防守时：

- 可以攻击当前位置能够处理的目标；
- 可以转向攻击；
- 不主动离开当前位置追击。

目标离开可攻击位置：

```text
停止攻击该目标
↓
继续保持原地防守
```

---

# 8. 空闲自动战斗

单位没有主要命令时，可以自动攻击附近敌人。

```text
空闲
↓
发现合法敌人
↓
进入战斗
```

如果目标需要接近：

```text
仍在允许的自动追击范围内
→ 接近目标
```

如果目标超出自动追击范围：

```text
放弃目标
↓
返回空闲
```

---

# 9. 追击规则

不同战斗来源使用不同追击方式。

| 当前行为 | 追击规则 |
|---|---|
| 玩家明确攻击 | 持续追击指定目标 |
| 攻击移动 | 允许临时追击，但不能无限偏离推进任务 |
| 巡逻 | 允许临时追击，结束后恢复巡逻 |
| 原地防守 | 不主动追击 |
| 空闲自动战斗 | 按自动追击范围执行 |

攻击移动、巡逻和空闲自动战斗需要配置对应追击范围。

超过允许范围后：

```text
停止追击
↓
放弃当前目标
↓
恢复原行为
```

---

# 10. 一次普通攻击

一次普通攻击分为：

```text
攻击前摇
↓
攻击事件
↓
攻击后摇
↓
攻击间隔
```

## 10.1 攻击前摇

攻击开始后，到真正产生攻击结果之前属于攻击前摇。

攻击事件发生前，如果玩家下达新的有效命令：

```text
本次攻击取消
```

---

## 10.2 攻击事件

攻击事件是一次普通攻击正式成立的时点。

```text
到达攻击事件时点
↓
本次攻击正式发出
```

攻击事件发生以后，即使单位立即收到移动命令，这次已经发出的攻击仍然有效。

---

## 10.3 攻击后摇

攻击事件发生后的动作收尾属于攻击后摇。

如果单位允许取消后摇：

```text
新的有效玩家命令
→ 提前结束后摇
→ 执行新命令
```

已经发生的攻击不会撤销。

---

## 10.4 攻击间隔

攻击间隔决定下一次攻击最早什么时候可以再次成立。

攻击间隔未结束时：

```text
不能再次产生新的攻击事件
```

---

# 11. 攻击位置变化

当前目标仍然有效，但已经离开攻击位置时：

```text
当前行为允许追击
→ 接近目标

当前行为不允许追击
→ 停止继续攻击
→ 恢复原行为
```

是否需要移动、移动到哪里，由单位当前攻击位置要求决定。

---

# 12. 目标失效

当前目标失效后，立即停止继续产生针对该目标的攻击。

随后根据当前行为恢复：

```text
明确攻击
→ 当前攻击结束

攻击移动
→ 继续推进

巡逻
→ 继续巡逻

原地防守
→ 继续原地防守

空闲自动战斗
→ 返回空闲
```

如果当前规则允许自动重新寻找目标，则可以重新进入新的战斗。

---

# 13. 玩家打断战斗

新的有效玩家直接命令可以打断当前战斗行为。

核心分界点是：

> **攻击事件是否已经发生。**

攻击事件发生前：

```text
新命令
→ 本次攻击取消
→ 执行新命令
```

攻击事件发生后：

```text
新命令
→ 执行新命令
+
已经发出的攻击继续有效
```

---

# 14. 战斗基础配置

能够普通攻击的单位至少需要提供：

```text
攻击距离

攻击前摇时间

攻击事件时点

攻击后摇时间

攻击间隔

是否要求停止移动后攻击

自动索敌范围

自动追击范围

攻击移动追击范围

巡逻追击范围

是否允许取消攻击后摇
```

具体数值由各单位或武器配置决定。

---

# 15. 基础验收

## 明确攻击

```text
指定敌人
→ 接近
→ 攻击
→ 敌人移动
→ 继续追击
→ 继续攻击
```

## 普通移动

```text
执行普通移动
→ 途中出现敌人
→ 不自动停下攻击
→ 继续移动
```

## 攻击移动

```text
推进
→ 遇敌
→ 临时战斗
→ 战斗结束
→ 继续推进
```

## 巡逻

```text
巡逻
→ 遇敌
→ 临时战斗
→ 战斗结束
→ 继续巡逻
```

## 原地防守

```text
敌人在攻击位置
→ 攻击

敌人离开攻击位置
→ 不追击
→ 继续防守
```

## 攻击前摇被打断

```text
攻击事件发生前
+
玩家下达移动命令
=
本次攻击取消
```

## 攻击事件已经发生

```text
攻击事件已经发生
+
玩家下达移动命令
=
移动生效
+
已经发出的攻击仍然有效
```

## 目标失效

```text
目标失效
→ 当前战斗结束
→ 恢复正确的原行为
```
