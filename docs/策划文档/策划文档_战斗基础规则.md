# 策划文档_战斗基础规则

> 状态：已完成  
> 本文定义当前 RTS 战役 Demo 必须具备的最小战斗闭环。  
> 当前只保留现有程序能够支持、且战役 Demo 必须使用的战斗规则；过度复杂的后续设计使用删除线保留。

---

# 1. 当前最小战斗闭环

当前普通攻击统一按照以下流程执行：

```text
获得合法攻击目标
↓
检查目标是否在攻击距离内
↓
不在范围
→ 接近目标

进入范围
→ 按攻击间隔产生攻击
↓
发射弹体 / 产生伤害
↓
目标生命下降
↓
目标继续有效
→ 继续攻击

目标死亡 / 离场 / 不再合法
→ 当前攻击结束
```

当前 RTS Demo 只要求这条闭环稳定运行。

---

# 2. 攻击目标合法性

攻击前至少检查：

- 攻击单位仍然存在；
- 攻击单位具备攻击能力；
- 目标仍然存在；
- 目标可以受伤；
- 阵营关系允许当前攻击；
- 目标战斗域属于攻击单位允许攻击的战斗域。

非法目标不进入正式攻击。

---

# 3. 玩家明确攻击

玩家明确指定敌方目标后：

```text
提交普通攻击
↓
目标不在攻击距离
→ 接近目标
↓
进入攻击距离
→ 持续攻击
```

只要目标仍然合法，明确攻击默认保持当前目标。

途中出现其他普通敌人时，不自动替换玩家明确指定的最终目标。

明确攻击结束条件：

- 目标死亡；
- 目标离场；
- 目标变成非法攻击目标；
- 目标无法继续被攻击；
- 新的有效单位命令覆盖当前攻击；
- 玩家执行停止。

---

# 4. 强制攻击

强制攻击使用当前程序已有的显式强制攻击语义。

强制攻击可以覆盖普通开火策略对本次命令的限制。

当前支持：

- 强制攻击实体；
- 具备对应能力的单位强制攻击地面位置。

强制攻击仍然受单位攻击能力和目标类型资格限制。

---

# 5. 攻击移动

攻击移动必须保留原始推进目标。

```text
向目标推进
↓
发现并处理途中合法敌人
↓
当前临时战斗结束
↓
继续原推进目标
```

一次途中交战不能把原攻击移动目标永久丢失。

当前支持：

- 地面攻击移动；
- 目标攻击移动。

目标攻击移动需要保留玩家指定的最终敌方目标身份。

---

# 6. 交战姿态

当前自主战斗只使用现有三种交战姿态：

| 姿态 | 当前基础行为 |
|---|---|
| 侵略 | 主动发现并处理合法敌人，允许追击 |
| 警戒 | 围绕当前岗位处理敌人 |
| 固守 | 不主动离开当前位置追击，只处理攻击距离内目标 |

交战姿态属于持续战斗策略，不创建新的单位命令。

---

# 7. 开火策略

当前使用：

- 自由开火；
- 停火。

自由开火：单位按照当前交战姿态执行自主攻击。

停火：单位停止普通自主攻击。

显式强制攻击按照强制攻击规则单独处理。

---

# 8. 空闲自主攻击

没有主要命令的战斗单位，在自由开火状态下可以根据当前交战姿态处理附近合法敌人。

固守状态下：

```text
敌人在当前攻击距离内
→ 可以攻击

敌人离开当前攻击距离
→ 不主动追击
```

当前阶段不为不同战斗来源建立多套复杂追击半径。

---

# 9. 攻击距离与攻击间隔

当前战斗最少需要两个基础参数：

```text
攻击距离
攻击间隔
```

攻击距离决定单位是否可以开始产生攻击。

攻击间隔决定下一次攻击最早什么时候可以再次发生。

当前程序已有攻击距离和攻击间隔，战役 Demo 继续使用这套基础模型。

---

# 10. 已发出的攻击

攻击已经正式发出后，弹体拥有自己的生命周期。

因此：

```text
攻击已经发出
+
单位随后收到移动 / 停止等新命令
=
单位执行新命令
+
已经发出的弹体继续按自身规则结算
```

这属于当前必须保留的基础战斗规则。

---

# 11. 目标失效

当前攻击目标死亡、被摧毁、离场或不再合法时：

```text
停止继续对该目标产生攻击
↓
结束当前明确攻击
或
恢复攻击移动推进
或
返回当前交战姿态的正常行为
```

目标失效不能导致单位永久卡在无效攻击状态。

---

# 12. 新命令与停止

新的有效主要命令会按照《策划文档_指令与命令执行规则》覆盖当前攻击命令。

“停止”会取消当前普通攻击、强制攻击或地面强制攻击，但不会清除：

- 当前交战姿态；
- 当前开火策略。

---

# 13. 当前 Demo 必须验收

必须保证：

1. 指定合法敌人后可以接近并持续攻击。
2. 目标移动出攻击距离后，允许追击的明确攻击可以继续接近。
3. 目标死亡后当前攻击正确结束。
4. 攻击移动途中可以接敌，战斗结束后继续推进。
5. 固守状态不会主动追出当前位置处理远处敌人。
6. 停火状态不会继续普通自主攻击。
7. 强制攻击仍可按照显式强制攻击规则执行。
8. 已经发出的弹体不会因为单位随后停止或移动而被撤销。
9. 新的有效命令可以覆盖当前攻击命令。

---

# 14. 当前阶段不做的复杂战斗设计

以下内容不是当前几个战役 Demo 的 RTS 最小必备能力，保留历史设计但不作为当前程序目标：

- ~~攻击前摇阶段。~~
- ~~单独配置攻击事件时点。~~
- ~~攻击后摇阶段。~~
- ~~攻击后摇可取消 / 不可取消。~~
- ~~攻击前摇被移动命令打断的专门阶段规则。~~
- ~~自动索敌范围、自动追击范围、攻击移动追击范围、巡逻追击范围四套独立配置。~~
- ~~巡逻过程中临时战斗并恢复巡逻。~~
- ~~Patrol 巡逻战斗。~~
- ~~Hold Position 独立战斗命令。~~
- ~~复杂攻击阶段状态机。~~

当前需要的是稳定的 RTS 基础战斗闭环，不提前实现这些战斗手感深化功能。

---

# 15. 当前原则

**目标获取 → 接近 → 攻击距离 → 周期攻击 → 伤害 → 死亡 / 目标失效 → 正确结束或恢复原命令。**

这条链路稳定后，才考虑更复杂的攻击动作阶段和战斗手感扩展。
