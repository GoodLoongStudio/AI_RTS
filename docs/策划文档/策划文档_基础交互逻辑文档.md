# 策划文档_基础交互逻辑文档

> 状态：已完成  
> 本文定义当前 RTS Demo 的基础输入、镜头、传统单位控制、数字编队和 AI 副官入口。  
> 当前版本不再定义独立“单位 AI”控制层。

---

# 1. 当前控制结构

当前战场统一使用 RTS 俯视 / 斜俯视战略镜头。

当前交互只保留两类主要入口：

1. **普通 RTS HUD**：玩家直接选择和控制单位。
2. **AI 副官 HUD**：玩家通过文字、语音和 AI 战场信息进行指挥与分析。

两套 HUD 操作同一个实时战场。

单位本身只保留：

```text
单位命令
+
交战姿态
+
开火策略
```

不存在独立“单位 AI 模式”。

---

# 2. 镜头

当前程序已经支持：

| 输入 | 功能 |
|---|---|
| `W` | 镜头向前移动 |
| `S` | 镜头向后移动 |
| `A` | 镜头向左移动 |
| `D` | 镜头向右移动 |
| `Q` | 镜头旋转 |
| `E` | 镜头反向旋转 |
| 鼠标滚轮 | 镜头缩放 |

`WASD + QE` 始终属于镜头，不用于单位命令或 AI 命令。

当前 Demo 默认关闭屏幕边缘移动，因此：

~~鼠标移动到屏幕边缘自动平移镜头。~~

`Space` 跳转最近重要战场事件属于 RTS 基础体验，当前程序尚未正式接入：

**`Space` → 最近重要战场事件【待实现】**

# 3. 鼠标基础操作

必须保留传统 RTS 的鼠标操作：

- 左键选择己方单位；
- 左键空地取消选择；
- 左键拖动框选；
- `Shift + 左键` 增减当前选择；
- 右键空地执行移动；
- 右键敌方单位执行普通攻击；
- 右键友方单位按合法上下文执行跟随 / 靠近。

当前正式命令体系没有通用 Interact，因此旧规则：

~~右键可交互对象 → 通用默认交互。~~

不作为当前正式功能。

---

# 4. 普通单位命令

当前程序已经存在以下正式单位能力：

- 移动；
- 靠近目标；
- 跟随目标；
- 强制移动；
- 地面攻击移动；
- 目标攻击移动；
- 战术撤退；
- 普通攻击；
- 强制攻击；
- 地面强制攻击；
- 采集；
- 施工。

当前程序还存在以下控制操作：

- 停止移动；
- 停止；
- 设置交战姿态；
- 设置开火策略。

# 6. 交战姿态

当前使用程序已有三种交战姿态：

| 姿态 | 行为 |
|---|---|
| 侵略 | 主动索敌并允许追击 |
| 警戒 | 围绕岗位处理敌人 |
| 固守 | 不主动移动追击，只处理射程内目标 |

交战姿态是单位持续战斗策略，不是独立 AI 模式。

---

# 7. 开火策略

当前使用：

- 自由开火；
- 停火。

自由开火时，单位按照当前交战姿态处理合法敌人。

停火时，单位停止普通自主开火。

强制攻击按照强制攻击规则单独处理。

---

# 8. AI 副官 HUD

当前设计：

**`Tab` = 普通 RTS HUD ↔ AI 副官 HUD**

当前程序已经存在独立 AI 副官原型 HUD，但正式 `Tab` 切换尚未接入默认输入：

**`Tab` 切换 AI 副官 HUD【待实现】**

切换 HUD 不改变：

- 当前选择；
- 当前活动命令；
- 当前交战姿态；
- 当前开火策略；
- 镜头位置。

AI 副官不是单位控制模式，而是另一套操作界面。

| 输入 | 功能 | 当前状态 |

# 10. 数字编队

当前正式程序已经支持：

| 输入 | 功能 |
|---|---|
| `1–9` | 调用对应数字编队 |

- 已失效单位；
- 非己方单位；

# 11. Esc 与菜单

当前策划目标：

- `Esc`：取消当前临时操作 / 返回；
- `F10`：暂停并打开游戏菜单。

当前程序默认仍存在 `Esc = global.toggle_menu` 的旧绑定，因此这里属于待同步程序输入的冲突项。

正式设计不恢复“Esc 必须打开菜单”的旧规则。

# 13. 当前基础交互原则

1. `WASD + QE` 固定用于镜头。
2. 普通 RTS HUD 负责传统单位控制。
3. AI 副官 HUD 负责 AI 对话、分析和自然语言指挥。
4. 单位只有命令、交战姿态和开火策略，不存在独立单位 AI 控制层。
5. 当前程序已有能力优先复用。
6. RTS 必须功能即使尚未接入快捷键，也保留为待实现项。
7. 过于复杂且当前不需要的旧设计使用删除线保留。
