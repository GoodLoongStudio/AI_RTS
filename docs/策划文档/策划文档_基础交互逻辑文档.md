# AI RTS P0 基础交互逻辑文档

> 状态：正式版 / 冻结  
> 本文定义 P0 的基础输入、控制层级、正常流程、异常与边界。  
> 本文只定义：
>
> 1. 鼠标
> 2. 键盘
> 3. Unit AI Command
> 4. System AI Command
> 5. 语音
>
> 本文不定义复杂组合输入、后续 Targeting 完整流程、AI 内部决策算法、寻路和战斗数值。

---

# 0. 核心原则

一句话核心规则：

> **玩家始终通过传统 RTS 直接输入控制战场；Unit AI 与 System AI 是两个独立的 AI 指挥层级，语音是独立输入通道。**

### 己方单位选择默认规则

> **选中任意己方单位 / 小队后，默认操作层始终是 Direct Control。**

- 选择己方单位 / 小队只改变当前控制对象，不自动进入 Unit AI Command。
- 即使该单位已经有 AI 行为正在生效，选中后仍默认进入 Direct Control。
- 如需调整该单位的 AI 行为，玩家必须再次明确按 `Tab` 进入 Unit AI Command。
- 在 System AI Command 中选择任意己方单位 / 小队，同样自动退出 System AI，并回到该对象的 Direct Control。
- Direct Control 只表示玩家当前操作层，不等于取消该单位已经生效的 AI 行为。

三种主要控制层级：

| 控制层级 | 作用对象 | QWER |
|---|---|---|
| Direct Control | 当前单位 / 英雄 | 普通技能 |
| Unit AI Command | 当前选中的单位 / 小队 / 选择集 | 单位级 AI 行为 |
| System AI Command | 整个战场 AI 指挥系统 | 系统级 AI 行为 |

# 1. 鼠标操作

## 1.1 基础鼠标定义

| 鼠标操作 | 本游戏定义 |
|---|---|
| 左键单击己方单位 | 选中单位 |

| 右键单击空地 | 当前选中单位移动到该位置 |
| 右键单击敌方单位 | 当前选中单位攻击该目标 |
| 右键单击友方单位 | 当前选中单位跟随 / 靠近该单位 |
| 右键单击可交互对象 | 执行对象默认交互 |

## 1.2 鼠标基础原则

- **左键：选择 / 查看**
- **右键：Smart Command / 直接命令**
- **拖动：框选**
- **滚轮 / 中键 / 屏幕边缘：控制镜头**
- 鼠标基础操作以 Warcraft / 传统 RTS / MOBA 的成熟操作习惯为基线。
- 当前不加入 AI 专属鼠标行为。
- 当前不定义键盘按下后再配合鼠标的组合操作。

## 1.3 鼠标异常与边界

| 情况 | 游戏处理 | 玩家反馈 | 原状态 |
|---|---|---|---|
| 没有可控制己方单位时右键空地 | 不下达移动命令 | 无效光标 / 轻反馈 | 保持 |
| 没有可控制己方单位时右键敌人 | 不下达攻击命令 | 无效光标 / 轻反馈 | 保持 |
| 右键目标在输入后失效 | 不执行对失效目标的对象命令 | 可转为空操作或短提示 | 保持 |
| 左键单击空地 | 取消当前选择 | 当前对象 UI 清空 | Direct 无选择 |
| System AI 中选择己方单位 | 选择单位并退出 System AI | HUD 回到该对象 Direct | Direct Control |
| System AI 中查看敌方单位 | 只查看敌方对象 | 保持 System AI HUD | System AI |

# 2. 键盘操作

## 2.1 操作层级切换

| 按键 | 本游戏定义 |
|---|---|
| `Tab` | 当前选中单位 / 小队的 Direct Control 与 Unit AI Command 切换 |
| `` ` `` / 反引号键 | 进入 System AI Command；已处于 System AI 时重复按下不退出 |
| `V` | 按住进行 AI 语音输入，松开结束语音输入 |

### 当前冻结原则

- `Tab` 是**单位 / 小队级 AI Command** 的专属切换键。
- `` ` `` / 反引号键是 **System AI Command 的单向进入键**，不是 Toggle。
- Unit AI Command 与 System AI Command 是两个不同指挥层级，不叠加。
- 系统级 AI 指挥不依赖“是否选中单位”自动触发。
- 玩家在 System AI Command 中重新选择己方单位 / 小队时，会自动退出系统级 AI 指挥并回到该对象的 Direct Control。

## 2.2 Direct Control / 普通单位控制

### QWERDF

| 按键 | 本游戏定义 |
|---|---|
| Q | 单位 / 英雄 Q 能力 |
| W | 单位 / 英雄 W 能力 |
| E | 单位 / 英雄 E 能力 |
| R | 单位 / 英雄 R 能力 |
| D | 扩展能力 / 道具槽 |
| F | 扩展能力 / 道具槽 |

### 其他单键

| 按键 | 本游戏定义 |
|---|---|
| Esc | 取消当前未完成的操作 / 指令状态 |
| Space | 快速回到英雄 / 主要控制单位 |
| 1–9 | 切换对应控制组 |
| F1 | 选择英雄 / 主控单位 |
| A | 进入 Attack Move 指令状态 |
| S | Stop，停止当前单位动作 |
| H | Hold Position，原地坚守 |
| P | Patrol，进入巡逻指令状态 |

## 2.3 键盘异常与边界

| 情况 | 游戏处理 | 玩家反馈 | 原状态 |
|---|---|---|---|
| 无己方可控制对象时按 `Tab` | 不进入 Unit AI | 轻量提示“请先选择单位” | 保持 |
| 当前查看的是敌方对象时按 `Tab` | 不进入 Unit AI | 提示“当前对象不可控制” | 保持 |
| System AI 中按 `Tab` | 不叠加 Unit AI | 提示先选择己方单位或无效反馈 | System AI |
| Unit AI 中按 `` ` `` | 进入 System AI，退出 Unit AI 操作层 | HUD 切为 SYSTEM AI | System AI |
| System AI 中再次按 `` ` `` | 不退出 System AI | 状态保持不变，可不给额外提示 | System AI |
| 控制组为空时按对应数字 | 不改变当前选择 | 轻量无效反馈 | 保持 |
| 不存在英雄 / 主控单位时按 `F1` | 不改变当前选择 | 轻量无效反馈 | 保持 |
| A / P 等待目标时按 `Esc` | 取消未完成指令 | 光标 / HUD 回到普通状态 | 当前控制层保持 |
| 当前对象在输入过程中失效 | 不继续向失效对象下达命令 | 清除失效对象反馈 | 回退合法状态 |
| 连续快速按模式切换键 | 每次严格按当前有效状态处理 | 只表现最终合法状态 | 不产生额外中间模式 |

# 3. Unit AI Command / 单位级 AI 指挥

按 `Tab` 进入 Unit AI Command 后，当前选中作战单位 / 小队的 QWER 从普通技能切换为 AI 战术行为。

进入前提：

> 当前存在可控制的己方单位 / 小队。

## 3.1 QWER 通用抽象

| 按键 | 通用定义 | 核心含义 |
|---|---|---|
| Q | **自主履职** | 根据当前环境、单位职责和已有任务，自主处理当前局部情况 |
| W | **主动强化** | 更积极地发挥当前单位的核心职责 |
| E | **稳守维持** | 围绕当前位置 / 当前区域稳定执行本职，不主动扩大行动范围 |
| R | **保全优先** | 停止高风险行动，优先脱离危险或保存自身与关键资源 |

### 四个按键的统一方向

- `Q` = **自主判断**
- `W` = **提高主动性**
- `E` = **稳定 / 防守**
- `R` = **保全 / 脱离**

QWER 的抽象方向固定，但不同单位会根据自身职责产生不同的具体行为。

## 3.2 不同单位类型的 QWER

| 单位类型 | Q 自主履职 | W 主动强化 | E 稳守维持 | R 保全优先 |
|---|---|---|---|---|
| **步兵 / 突击单位** | 根据附近战况自行走位、还击、协同 | 主动推进、寻找交战机会 | 守住当前位置 / 区域，不远追 | 脱离交战并后撤 |
| **侦察单位** | 隐蔽观察附近区域、补充情报 | 主动扩大侦察范围、搜索敌情 | 隐蔽监视当前区域 | 摆脱威胁并撤离 |
| **坦克 / 重装单位** | 自行调整站位、掩护友军、处理附近威胁 | 主动突破、推进、压制 | 占据位置形成防御支点 | 脱离战斗并退到安全位置 |
| **远程 / 火力支援单位** | 自主选择附近合适目标提供火力 | 主动寻找高价值目标输出 | 保持阵位并覆盖指定方向 | 停止输出并转移阵地 |
| **火炮单位** | 自主支援当前战斗、选择合适炮击目标 | 主动实施远程火力打击 | 保持炮位、警戒火力范围 | 收炮并转移到安全区域 |
| **防空单位** | 自动警戒附近空中威胁 | 主动扩大防空覆盖、处理空中目标 | 固守当前防空区域 | 脱离危险区域 |
| **医疗 / 支援单位** | 自动治疗、支援附近有需求的友军 | 主动跟进主力、寻找需要支援的单位 | 留在相对安全位置持续保障 | 优先远离敌人并保存自身 |
| **工程单位** | 自主处理附近维修、修复等工程需求 | 主动前往需要工程支援的位置 | 构筑、维修并维持当前阵地 | 停止工程并撤出危险区域 |
| **补给单位** | 自动服务附近缺少补给的友军 | 主动寻找需要补给的部队 | 留在安全区域提供补给 | 优先撤离并保存补给单位 |
| **运输单位** | 自主完成当前附近的装载、卸载、跟随 | 主动执行运输、接送需求 | 停靠并等待 / 保持待命 | 优先撤离乘员和自身 |
| **空中作战单位** | 根据自身职责在当前区域自主活动 | 主动搜索并攻击合适目标 | 巡逻 / 警戒当前空域 | 脱离战区 / 返航 |
| **建筑 / 固定设施** | 根据建筑职责自主运行 | 提高主动输出或主动服务能力 | 进入防御 / 节能 / 稳态运行 | 停止高风险行为并优先保存资源与自身 |

## 3.3 建筑类单位细分

| 建筑类型 | Q 自主履职 | W 主动强化 | E 稳守维持 | R 保全优先 |
|---|---|---|---|---|
| **防御塔** | 自主警戒 | 优先攻击 / 提高主动火力 | 防御待机 | 停火保全 |
| **生产建筑** | 自主生产 | 提高生产优先级 / 强度 | 维持基础生产 | 暂停生产、保存资源 |
| **雷达 / 侦测建筑** | 自主探测 | 扩大主动侦测 | 固定监视 | 关闭高耗能功能 |
| **维修 / 补给建筑** | 自主服务附近单位 | 提高保障强度 | 保持基础保障 | 停止外部服务、优先自保 |

## 3.4 Unit AI 状态与退出

| 当前状态 | 操作 | 结果 |
|---|---|---|
| Direct Control | `Tab` | Unit AI Command |
| Unit AI Command | `Tab` | Direct Control |
| Unit AI Command | `` ` `` | System AI Command |
| Unit AI Command | 当前对象死亡 / 销毁 / 离场 | 清除失效对象并退出该对象 Unit AI 操作层 |

退出 Unit AI Command 不等于取消已经设置的 AI 行为。

## 3.5 单位级 AI Command 异常

| 情况 | 游戏处理 | 玩家反馈 | 原状态 |
|---|---|---|---|
| 没有可控制对象 | 不进入 Unit AI | “请先选择单位” | 保持 |
| 对象失效 | 清除对象 | 当前对象区清空 | 回退无选择 Direct |
| 某项 AI 指令不可执行 | 不执行该项 | 对应 QWER 灰化 / 短提示 | Unit AI 保持 |
| AI 指令执行失败 | 不自动切模式 | 显示失败原因摘要 | Unit AI 保持 |
| 玩家退出 Unit AI | 仅退出操作层 | Direct 中保留轻量 AI 状态 | Direct Control |

## 3.6 单位级 AI Command 冻结原则

- `Q` 不等于“自动作战”，而是“按当前单位职责自主处理当前局部情况”。
- `W` 不重复 `Q`，而是明确提高当前单位的主动性。
- `E` 强调稳定、守住、维持当前职责，不主动扩大行动范围。
- `R` 的统一抽象是“保全优先”：
  - 移动单位通常表现为撤退 / 脱离；
  - 建筑通常表现为停火、停产、降载或关闭非必要功能。
- 当前只冻结单键语义，不定义与鼠标、语音或其他输入的组合行为。
- `Tab` 改变的是玩家操作层，不等于 AI 行为开关。

# 4. System AI Command / 系统级 AI 指挥

系统级 AI 指挥作用于**整个战场 AI 指挥系统**，而不是当前某一个单位。

进入方式：

- 使用 `` ` `` / 反引号键进入 System AI Command。
- 如果当前已经处于 System AI Command，再次按 `` ` `` 不退出，System AI 状态保持不变。
- 连续按、误触或双击 `` ` `` 都不能关闭 System AI。

退出方式：

- 玩家重新选择任意己方单位 / 小队时，自动退出 System AI Command，并将操作焦点切回当前选择对象。

System AI 不提供 `` ` `` 二次按下退出，避免重要全局 AI 状态因为误触、连按或键盘重复输入被意外关闭。

## 4.1 系统级与单位级焦点规则

- System AI Command 表示当前操作焦点位于**整个战场**。
- 玩家选择具体己方单位 / 小队，表示操作焦点重新回到**局部单位**。
- 因此，选择己方单位本身即可结束系统级 AI 指挥，不需要额外再按一次退出键。
- 退出 System AI Command 后，默认回到该单位 / 小队的 Direct Control；是否进入 Unit AI Command 仍由 `Tab` 单独控制。
- 查看敌方单位不等于重新取得己方单位控制，因此默认不退出 System AI。

## 4.2 系统级 QWER

| 按键 | 系统级定义 | 行为方向 |
|---|---|---|
| Q | **自主调度** | AI 在当前战略目标不变的前提下，自主协调各部队、岗位、支援和局部任务 |
| W | **全面进攻** | 整体提高进攻倾向，主动推进、集中兵力并加强前线投入 |
| E | **稳固防线** | 整体转向稳定与防守，补强薄弱区域、守住关键位置、限制无意义追击 |
| R | **收缩保全** | 停止高风险行动，脱离不利交战、收缩阵线并优先保存核心兵力和关键单位 |

## 4.3 单位级与系统级 QWER 对照

| 按键 | Unit AI Command | System AI Command |
|---|---|---|
| Q | 自主履职 | 自主调度 |
| W | 主动强化 | 全面进攻 |
| E | 稳守维持 | 稳固防线 |
| R | 保全优先 | 收缩保全 |

## 4.4 System AI 异常与边界

| 情况 | 游戏处理 | 玩家反馈 | 原状态 |
|---|---|---|---|
| 无任何己方单位被选中时按 `` ` `` | 仍可进入 System AI | SYSTEM AI HUD | System AI |
| System AI 中按 `Tab` | 不叠加 Unit AI | 提示先选择己方单位 / 无效反馈 | System AI |
| System AI 中选择己方单位 | 自动退出 System AI，并将该对象设为当前控制对象 | HUD 回到该对象 Direct | Direct Control |
| System AI 中查看敌方单位 | 仅查看，不改变全局操作焦点 | 敌方信息显示 | System AI |
| 系统级指令不可执行 | 不执行该项 | 短提示原因 | System AI |
| 系统级 AI 执行失败 | 不自动切模式 | 显示失败摘要 | System AI |

## 4.5 系统级冻结原则

- 单位级与系统级保持同一套 QWER 心智方向。
- 系统级 `Q` 只能在当前战略目标下自主调度，不代表 AI 可以自行改变主战略目标。
- 系统级 `W/E/R` 表示整个战场的总体行为倾向。
- 不要求所有单位执行同一个具体动作；不同单位仍按照自身职责响应。
- 当前只冻结系统级单键语义，不定义与鼠标、语音或其他输入的组合行为。
- Unit AI 与 System AI 不叠加。

# 5. 语音输入

## 5.1 默认语音快捷键

| 按键 | 本游戏定义 |
|---|---|
| V | 按住进行 AI 语音输入，松开结束语音输入 |

语音是独立输入方式。

语音不要求玩家预先进入 Unit AI Command 或 System AI Command；系统根据语义和当前上下文判断指令应该作用于单位级还是系统级。

## 5.2 语音指令作用层级

| 语音内容 | 判定层级 |
|---|---|
| 明确指向当前单位 / 当前小队 | 单位级 AI 指令 |
| 明确指定某个单位 / 编队 | 单位级 AI 指令 |
| 明确提到全军、整体、整个战场、战线等 | 系统级 AI 指令 |
| 明确要求 AI 统一协调各部队 | 系统级 AI 指令 |
| 语义未明确层级，但当前存在明确选中单位 / 小队 | 默认按当前选中对象处理 |
| 语义和当前上下文都无法判断作用范围 | 不执行，要求玩家补充确认 |

## 5.3 语义判定优先级

1. **明确语义**
2. **当前选中对象**
3. **默认上下文**

例如：

- 当前选中二队，但玩家说“全军收缩防线” → 系统级指令。
- 当前选中二队，玩家只说“自己处理” → 二队的单位级指令。
- 玩家只说“撤”，当前选中二队 → 默认理解为二队撤退。
- 玩家只说“撤”，且没有明确选中对象、语义也没有说明范围 → 不自动扩大为全军撤退，要求玩家确认作用范围。

## 5.4 语音异常与边界

| 情况 | 游戏处理 | 玩家反馈 | 当前模式 |
|---|---|---|---|
| 未识别到有效语音 | 不执行 | “未识别到有效指令” | 不改变 |
| 无法判断对象 / 范围 | 不执行 | 要求补充对象或范围 | 不改变 |
| 语义互相冲突 | 不执行高风险推断 | 要求重新说明 | 不改变 |
| 目标在识别完成前失效 | 不向失效目标执行 | “目标已失效” | 不改变 |
| 单位级语义但无合法单位对象 | 不自动升级为系统级 | 提示选择 / 指定单位 | 不改变 |
| 明确系统级语义 | 按系统级作用范围解释 | 显示 SYSTEM AI 作用范围反馈 | 不强制切 HUD 模式 |

## 5.5 语音安全原则

- 语音不得在作用层级不明确时自行扩大控制范围。
- 单位级语义不得自动升级为系统级指令。
- 系统级语义必须由玩家明确表达全局范围，或明确要求 AI 全局协调。
- `V` 只负责语音输入，不改变：
  - `Tab` = 单位 / 小队级 AI Command
  - `` ` `` = 系统级 AI Command
- 语音失败默认不改变当前控制模式。

# 6. 输入冲突与优先级

当多个规则同时成立时，默认优先级：

```text
明确玩家直接输入
>
明确模式切换
>
当前合法控制对象
>
当前控制层级规则
>
AI 自动行为
>
默认行为
```

补充说明：

- 玩家选择己方单位，会把 System AI 的全局焦点拉回该单位 Direct Control；
- `` ` `` 是 System AI 的单向进入键，不与 Unit AI 叠加；重复按下不会退出 System AI；
- `Tab` 只有在存在可控制己方对象时才进入 Unit AI；
- 语音作用范围优先按明确语义判断，不因为当前选择对象而覆盖明确的“全军 / 整体”表达；
- AI 正在执行行为时，如果玩家发出新的明确 Direct Control 输入，该输入应优先被系统接收；
- Direct Control 输入之后，AI 行为是暂停、覆盖还是恢复，由 AI 控制权专项规则定义，本文不扩展。

# 7. 通用异常默认原则

如果专项文档没有另外说明，P0 输入遵守：

### 7.1 不明确，不扩大

不确定作用范围时，不把单位级输入扩大到系统级。

### 7.2 操作失败，不自动切状态

无效输入默认保持当前合法模式和选择。

### 7.3 对象失效必须收敛

单位死亡、销毁、离场或失去控制权后，不能继续保持指向该对象的操作状态。

### 7.4 重复输入必须可预测

连续按键严格按当前有效状态处理，不产生额外隐藏状态。

### 7.5 玩家明确输入优先

AI 自动行为不能阻止玩家的明确控制输入被系统接收。

### 7.6 异常必须有最小反馈

高频小错误使用轻反馈；涉及 AI 作用范围的高风险歧义必须明确提示或要求确认。
