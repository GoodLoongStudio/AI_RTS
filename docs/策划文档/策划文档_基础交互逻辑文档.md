# 策划文档_基础交互逻辑文档

> 状态：待评审  
> 本文定义当前 RTS Demo 的基础输入、镜头控制、单位直接控制、单位 AI、系统 AI、数字编队以及 AI 输入规则。

# 1. 默认快捷键总表

## 1.1 镜头

| 输入 | 功能 |
|---|---|
| `W` | 镜头向前移动 |
| `S` | 镜头向后移动 |

| `D` | 镜头向右移动 |
| `Q` | 镜头向左旋转 |
| `E` | 镜头向右旋转 |

# 2. 基础术语

| 术语 | 含义 |
|---|---|
| 指令 | 玩家、AI 或系统提交的一次控制请求 |
| 命令 | 单位接受指令后实际执行的行为 |
| 当前命令 | 单位当前正在执行的主要命令 |
| 交战姿态 | 单位自主发现敌人后采取什么战斗行为 |
| 开火策略 | 单位是否允许自主开火 |

统一对应：

**Command = 指令**  
**Order = 命令**

策划文档统一不使用“订单”描述单位战场行为。

# 3. 控制结构

游戏始终使用 RTS 俯视 / 斜俯视战略镜头。

| 操作层 | 作用对象 |
|---|---|
| 直接控制 | 当前单位 / 当前选择集 |
| 单位 AI | 当前单位 / 当前选择集 |
| 系统 AI | 整个战场 |

选择己方单位后默认进入直接控制。

镜头操作与单位控制相互独立。

# 4. 镜头

`WASD` 平移镜头。  
`QE` 旋转镜头。  
鼠标滚轮缩放镜头。  
鼠标移动到屏幕边缘时，镜头向对应方向移动。

镜头移动不会：

- 改变当前选择；
- 取消当前命令；
- 改变交战姿态；
- 改变开火策略；
- 改变 AI 控制状态。

`Space` 用于跳转到最近一次重要战场事件。

重要战场事件包括但不限于：

- 己方部队遭到攻击；
- 发现重要敌军；
- AI 发出重要警告；
- 关键单位出现危险；
- 任务目标发生重要变化。

# 5. 选择与右键

左键负责选择和查看。

右键根据目标产生对应直接指令：

| 右键目标 | 结果 |
|---|---|
| 空地 | 移动 |
| 敌方单位 | 攻击 |
| 友方单位 | 跟随 / 接近 |
| 可交互目标 | 默认交互 |

玩家可以通过单击、框选、`Shift + 左键`、同类型选择和数字编队形成当前选择。

选择己方单位后进入该对象的直接控制。

# 6. 单位直接控制

## 6.1 攻击移动

按 `R` 后指定目标位置。

单位向目标区域推进，同时根据当前交战规则处理途中敌人。

## 6.2 停止

按 `F` 执行停止。

停止用于结束当前主要行动。

本文统一使用“停止”这一术语。程序中的“停止移动”是另一项独立能力，两者不混用。

## 6.3 原地防守

按 `G` 将当前单位设置为原地防守姿态。

原地防守不是一次性命令，而是持续交战姿态。

## 6.4 强制移动

按 `C` 后指定位置。

单位优先向指定位置移动。

## 6.5 强制攻击

按 `X` 后指定攻击目标。

单位显式攻击指定目标。

## 6.6 战术撤退

按 `Z` 后指定撤退位置。

单位向指定位置执行战术撤退。

具有倒车能力的单位可以倒车撤离，其他单位按照普通移动方式执行。

# 7. 交战姿态

当前使用三种交战姿态：

| 姿态 | 行为 |
|---|---|
| **主动进攻** | 主动寻找并追击感知范围内的敌方目标，同时受到最大追击范围限制 |
| **警戒防守** | 围绕当前岗位迎击目标，目标脱离后返回岗位 |
| **原地防守** | 不主动移动或追击，只攻击已经进入武器射程的目标 |

程序对应：

- `Aggressive` = 主动进攻；
- `Guard` = 警戒防守；
- `HoldGround` = 原地防守。

# 8. 开火策略

当前使用两种开火策略：

| 开火策略 | 行为 |
|---|---|
| **自由开火** | 按当前交战姿态自主选择并攻击目标 |
| **停止开火** | 禁止自主开火 |

停止开火状态下，玩家明确下达强制攻击后，单位仍然可以执行该强制攻击。

交战姿态决定单位如何自主战斗。

开火策略决定单位是否允许自主开火。

程序对应：

- `FireAtWill` = 自由开火；
- `HoldFire` = 停止开火。

# 9. 单位 AI

当前存在合法己方选择时，按 `Tab` 在以下两个操作层之间切换：

**直接控制 ↔ 单位 AI**

单位 AI 直接使用当前已有的交战姿态和开火策略。

交战姿态：

1. 主动进攻；
2. 警戒防守；
3. 原地防守。

开火策略：

1. 自由开火；
2. 停止开火。

玩家可以通过单位 AI 操作栏、AI 语音或 AI 文字设置这些状态。

自然语言指令可以直接映射到这些状态：

- “这队主动进攻。” → 主动进攻；
- “这队守住这里。” → 警戒防守；
- “原地别追。” → 原地防守；
- “先别开火。” → 停止开火。

# 10. 玩家直接控制与单位 AI

玩家明确直接指令优先于单位 AI 自动行为。

单位处于 AI 控制下时，玩家仍然可以随时直接下达命令。

玩家直接命令执行期间，单位 AI 让权。

玩家直接命令结束后，单位继续按照当前仍然有效的交战姿态、开火策略和 AI 任务运行。

交战姿态与开火策略属于持续状态，不因为一次普通移动或攻击命令自动消失。

# 11. 系统 AI

按反引号键进入系统 AI。

系统 AI 作用于整个战场。

系统 AI 状态下，玩家仍然可以：

- 使用 `WASD` 移动镜头；
- 使用 `QE` 旋转镜头；
- 使用滚轮缩放镜头；
- 查看战场；
- 查看敌我单位；
- 使用 `Space` 查看重要战场事件。

选择己方单位后，退出系统 AI 并进入该单位的直接控制。

查看敌方单位不退出系统 AI。

再次按反引号键时保持系统 AI 状态。

# 12. AI 语音与文字

按住 `V` 开始语音输入，松开后提交。

按 `Enter` 打开 AI 文字输入。

AI 判断作用范围时按照：

**明确语义 → 当前选择对象 → 当前上下文**

例如：

“1队主动进攻”

→ 作用于 1 队。

“所有部队停止开火”

→ 对当前合法全局控制对象设置停止开火。

“这队原地防守”

→ 作用于当前选择对象。

无法确定作用范围时，不执行并要求确认。

# 13. 数字编队

`Ctrl + 1–9`：覆盖保存当前选择到对应数字编队。

`Shift + 1–9`：将当前选择追加到对应数字编队。

`1–9`：选择对应数字编队。

快速双击数字：选择对应数字编队并将镜头定位到该编队。

数字编队只保存选择关系，不改变单位交战姿态、开火策略和当前命令。

# 14. Esc 与系统界面

`Esc` 统一用于取消和返回，包括：

- 取消尚未确认的目标选择；
- 取消当前临时操作；
- 取消 AI 文字输入；
- 返回上一层界面。

`Esc` 不直接打开游戏菜单。

`F9`：任务目标 / 任务日志。  
`F10`：暂停并打开游戏菜单。  
`F11`：战场关系 / 阵营信息。  
`F12`：AI 对话 / 通讯记录。  
`F1`：选择当前关卡主要控制单位。

# 15. 后续命令【待定】

候选输入：

`Shift + 命令`

候选规则：

将新的命令追加到当前命令之后。

当前程序尚未实现后续命令队列，因此本功能保持【待定】。

当前命令系统仍然按照：

**创建新命令 → 原当前活动命令取消 → 新命令成为当前活动命令**

执行。

# 16. 输入优先级

多个控制来源同时作用于同一单位时：

**玩家明确直接指令  
> 玩家明确操作层切换  
> 当前合法控制对象  
> 已确认 AI 任务  
> AI 自动行为  
> 默认行为**

镜头输入独立于单位控制优先级。

镜头操作不会改变单位当前命令。

# 17. 基础异常规则

无合法己方选择时按 `Tab`：保持当前状态。

AI 无法确认作用对象：不执行。

当前命令依赖的目标失效：按照该命令自身的失败或结束规则处理。

数字编队没有有效单位：按对应数字不改变当前合法选择。

无效玩家指令：不覆盖当前有效命令。

单位死亡、销毁或离场：结束该单位当前控制和当前命令。
