# 策划文档_游戏流程规则

> 状态：待评审  
> 本文定义玩家从进入游戏、选择玩法、进入战局、完成战斗到离开战局的统一流程。  
> 原则：程序已经存在的游戏流程正常保留；当前程序不存在且本阶段不准备实现的内容使用删除线保留。

---

# 1. 核心流程

游戏统一流程为：

**进入游戏 → 主界面 → 选择玩法 → 选择战斗内容 → 进入战局 → 战斗 → 胜负结算 → 后续选择**

当前已有单人战役和普通对局 / 自定义战斗两条实际入口。

---

# 2. 进入游戏

游戏启动完成后进入主界面。

当前程序已经存在：

- 单人战役；
- 普通对局 / 自定义战斗；
- 设置；
- 制作人员；
- 退出游戏。

以下当前程序没有，且不属于当前战役 Demo 开发重点：

- ~~联机玩法。~~

玩家选择玩法后进入对应内容选择流程。

---

# 3. 单人战役流程

单人战役当前使用：

**进入战役 → 选择章节 / 任务 → 查看任务信息 → 进入战局**

任务信息可以通过包括但不限于以下已有或可复用表现表达：

- 任务名称与目标文字；
- 过场演出；
- 地图标记与地图提示；
- 镜头移动与镜头聚焦；
- 战场中的真实事件；
- AI 副官提示；
- 单位对白与语音；
- 界面提示；
- 区域高亮与目标指示。

任务表达只负责让玩家理解：

**当前发生了什么、当前要做什么、下一步应该关注哪里。**

确认进入后加载当前战局。

---

# 4. 普通对局 / 自定义战斗流程

当前程序已经存在普通对局 / 自定义战斗入口。

当前流程为：

**选择地图 → 设置对局参与方 → 确认开始 → 加载战局**

当前已有能力包括：

- 选择地图；
- 设置玩家 / 规则 AI；
- 按地图支持人数配置参与方；
- 进入正式 Match；
- 打开设置。

当前已经存在的普通对局流程正常保留，不因为本阶段优先开发战役而删除。

---

# 5. 进入战局

进入战局时，根据当前玩法和现有系统初始化：

- 当前地图；
- 玩家与规则 AI；
- 初始单位与已有建筑；
- 当前已有资源状态；
- 当前胜负规则；
- 战役玩法的任务状态；
- 战争迷雾；
- 当前 AI 状态；
- 战局界面；
- 镜头位置。

资源、生产、建造等系统当前程序已有能力继续正常存在，只是当前几个战役不把完整经济循环作为验收重点。

复杂“已知通行地图”不是当前初始化要求。

---

# 6. 战斗开始

正式战斗开始后：

- 玩家获得战场控制权；
- 战局时间开始推进；
- 单位开始执行正式命令；
- 现有规则 AI 开始执行；
- AI 副官按照自身合法权限读取战场并与玩家交互；
- 战役任务开始推进；
- 当前胜负规则开始生效。

战斗持续到当前玩法产生最终胜负结果或战役流程明确结束。

---

# 7. 战斗进行中

战斗过程中，玩家可以：

- 选择并控制单位；
- 下达正式 RTS 命令；
- 使用数字编队；
- 调整交战姿态与开火策略；
- 使用 AI 副官进行文字 / 语音指挥与分析；
- 暂停与恢复；
- 查看当前任务与合法战场信息。

当前程序已有规则 AI 作为对局参与方，继续正常保留。

以下旧控制层不再作为当前正式设计：

- ~~独立 Unit AI 控制模式。~~
- ~~独立 System AI 操作层。~~

战役任务根据玩家行为和战场事件持续推进。

任务表现与任务逻辑分离：

**任务逻辑决定目标是否开始、推进、完成或失败。**

**任务表现决定玩家通过什么方式理解这些变化。**

---

# 8. 胜负产生

当前胜负规则产生最终结果后：

**战斗结束 → 锁定最终结果 → 进入结算**

普通对局使用当前正式 MatchOutcome 规则。

战役需要把任务完成 / 失败结果统一接入正式胜负结果，不长期保留独立于 MatchOutcome 的第二套结算真值。

---

# 9. 战局结算

结算界面至少展示当前玩法需要的结果：

- 胜利 / 失败；
- 当前任务完成情况；
- 当前玩法需要的战斗结果信息。

结算完成后进入后续选择。

---

# 10. 战役结算后的流程

单人战役结算后：

**任务完成 → 下一任务 / 返回战役界面**

**任务失败 → 重新挑战 / 返回战役界面**

当前几个战役允许通过关卡选择和已有战役状态继续推进。

完整跨局持久化存档当前处于暂缓状态，因此：

- ~~依赖完整战局存档保存全部战役运行现场。~~
- ~~复杂跨任务运行状态继承。~~

不作为当前 Demo 的流程前提。

---

# 11. 普通对局结算后的流程

普通对局结束后可以提供：

- 再来一局；
- 返回对局设置；
- 返回主界面。

当前普通对局入口本身是现有程序能力，正常保留。

---

# 12. 重新开始

玩家选择重新开始当前战局后：

**结束当前战局 → 使用当前战局初始配置重新创建 → 再次进入战斗**

重新开始使用当前关卡或对局初始数据。

---

# 13. 退出战局

玩家主动退出当前战局后：

**结束当前战局 → 返回当前玩法上一级界面**

- 单人战役返回战役界面；
- 普通对局返回对局设置或主界面。

~~联机玩法返回对应联机流程。~~

---

# 14. 战役连续任务

当前战役可以按章节 / 任务组织多个独立战局。

基础流程：

**当前任务结算 → 选择 / 解锁下一任务 → 加载下一战局**

当前 Demo 优先保证多个战役关卡可以完整进入、游玩、结算和继续。

~~跨关卡继承完整单位现场、命令现场、资源现场和战斗现场。~~

当前不作为必要功能。

---

# 15. 最终流程

当前游戏正式保留：

```text
主界面
↓
单人战役 或 普通对局
↓
选择战斗内容
↓
初始化战局
↓
进入战斗
↓
任务 / 胜负推进
↓
产生最终结果
↓
结算
↓
下一任务 / 重试 / 再来一局 / 返回
```

当前程序已经存在的玩法入口与基础系统继续正常保留；本阶段只是不把非战役核心系统作为开发重点。
