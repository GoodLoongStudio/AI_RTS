# 策划文档_游戏流程规则

> 状态：待评审  
> 本文定义玩家从进入游戏、选择玩法、进入战局、完成战斗到离开战局的统一流程。

# 1. 核心流程

游戏统一流程为：

**进入游戏 → 主界面 → 选择玩法 → 选择战斗内容 → 进入战局 → 战斗 → 胜负结算 → 后续选择**

所有玩法都在这条主流程上进行扩展。

# 2. 进入游戏

游戏启动完成后进入主界面。

主界面提供当前已经开放的主要入口，包括但不限于：

- 单人战役；
- 自定义战斗；
- 联机玩法；
- 设置；
- 退出游戏。

玩家选择玩法后进入对应内容选择流程。

# 3. 单人战役流程

单人战役统一使用：

**选择战役 → 选择章节 / 任务 → 查看任务信息 → 进入战局**

任务信息不限定必须使用文字界面表达。

任务内容可以由包括但不限于以下方式共同组成：

- 任务名称与目标文字；
- 过场演出；
- 地图标记与地图提示；
- 镜头移动与镜头聚焦；
- 战场中的真实事件；
- 人工智能指挥频道提示；
- 单位对白与语音；
- 界面提示；
- 区域高亮与目标指示。

任务表达方式只负责让玩家理解：

**当前发生了什么、当前要做什么、下一步应该关注哪里。**

不同任务可以使用不同组合，不要求所有任务都出现完整文字说明。

确认进入后开始加载当前战局。

# 4. 自定义战斗流程

自定义战斗统一使用：

**选择地图 → 设置对局内容 → 确认开始 → 进入战局**

对局内容根据当前玩法配置，包括但不限于：

- 玩家阵营；
- 人工智能阵营；
- 队伍关系；
- 地图；
- 胜负规则；
- 其他当前玩法开放的参数。

确认后开始加载战局。

# 5. 进入战局

进入战局时统一完成：

- 加载当前地图；
- 创建玩家与人工智能阵营；
- 创建初始单位与建筑；
- 初始化资源；
- 初始化胜负目标；
- 战役玩法初始化当前任务；
- 初始化战争迷雾与已知地图；
- 初始化人工智能任务状态；
- 初始化界面；
- 初始化镜头位置。

全部初始化完成后进入正式战斗。

# 6. 战斗开始

正式战斗开始后：

- 玩家获得战场控制权；
- 战局时间开始推进；
- 单位开始执行命令；
- 行为树人工智能开始执行；
- 大模型人工智能按照当前权限开始工作；
- 战役任务开始推进；
- 胜负规则开始生效。

战斗持续到当前玩法产生最终胜负结果。

# 7. 战斗进行中

战斗进行过程中，玩家可以按照当前玩法规则：

- 控制单位；
- 下达命令；
- 使用单位人工智能；
- 使用系统级人工智能；
- 使用语音指令；
- 暂停与恢复；
- 查看当前任务与已知战场信息。

战役任务根据玩家行为和战场事件持续推进。

任务推进过程中，可以继续通过：

- 过场演出；
- 地图提示；
- 镜头引导；
- 人工智能指挥频道；
- 战场事件；
- 界面提示；

向玩家传达新的任务信息与关注重点。

任务表现与任务逻辑分离：

**任务逻辑决定目标是否开始、推进、完成或失败。**

**任务表现决定玩家通过什么方式理解这些变化。**

自定义战斗主要根据当前胜负规则持续判断。

# 8. 胜负产生

当前胜负规则产生最终结果后：

**战斗结束 → 进入结算**

结算使用已经锁定的最终战局结果。

战役任务的完成结果可以共同参与战役结算。

# 9. 战局结算

结算界面展示当前玩法需要的结果信息。

基础信息包括：

- 胜利 / 失败；
- 当前任务完成情况；
- 主要战斗数据；
- 当前战役进度变化。

结算完成后进入后续选择。

# 10. 战役结算后的流程

单人战役结算后，根据当前任务结果提供对应流程：

**任务完成 → 更新战役进度 → 解锁后续内容 → 下一任务 / 返回战役界面**

**任务失败 → 重新挑战 / 返回战役界面**

战役进度由存档系统记录。

# 11. 自定义战斗结算后的流程

自定义战斗结束后提供：

- 再来一局；
- 返回对局设置；
- 返回主界面。

再来一局重新创建新的战局。

# 12. 重新开始

玩家选择重新开始当前战局后：

**结束当前战局 → 使用当前战局初始配置重新创建 → 再次进入战斗**

重新开始使用当前关卡或对局的初始数据。

# 13. 退出战局

玩家主动退出当前战局后：

**结束当前战局 → 返回当前玩法的上一级界面**

单人战役返回战役界面。

自定义战斗返回对局设置或主界面。

联机玩法返回对应联机流程。

# 14. 战役连续任务

战役任务需要连续进入下一任务时：

**当前任务结算 → 更新战役进度 → 加载下一任务 → 进入下一战局**

上一任务需要继承到下一任务的数据，由战役状态与存档规则明确记录。

# 15. 最终流程

整个游戏统一使用以下主流程：

**主界面**

↓

**选择玩法**

↓

**选择战斗内容**

↓

**初始化战局**

↓

**进入战斗**

↓

**产生胜负**

↓

**结算**

↓

**下一任务 / 重试 / 再来一局 / 返回**

游戏流程规则只负责玩家如何进入、进行和离开一场战局。

地图内部结构、战役地图、多地图连续战斗等玩法机制在实际需要时单独定义。
