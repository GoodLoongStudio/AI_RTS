# 策划文档_单位基础规则

> 状态：待评审  
> 定义范围：RTS 单位的身份、归属、类型、基础属性、空间属性、控制资格、命令资格、战斗资格、视野资格、状态、生命周期及单位间关系。  
> 前置依赖：无。  
> 后续依赖：《策划文档_地图空间与导航规则》《策划文档_移动与位置规则》《策划文档_战斗基础规则》《策划文档_技能基础规则》《策划文档_视野战争迷雾与情报规则》《策划文档_单位AI行为基础规则》《策划文档_编队小队与控制关系》。  
> 不包含：具体移动逻辑、伤害计算、技能效果、AI 决策、编队算法、程序实现。

# 1. 单位定义

单位是战场中具有独立身份、状态和行为资格的基础实体。

一个单位至少具有：

- 唯一身份；
- 阵营归属；
- 单位类型与标签；
- 控制归属；
- 生命周期状态；
- 基础属性；
- 空间属性；
- 移动能力；
- 命令能力；
- 战斗能力；
- 技能能力；
- 视野与情报能力；
- 状态效果；
- 可被交互关系。

# 3. 单位类型与标签

基础类型至少支持：

- 步兵；
- 载具；
- 英雄；
- 建筑单位；
- 空中单位；
- 水面单位；
- 特殊单位。

单位可同时具有多个标签，例如：

```text
载具 + 重型 + 机械 + 远程
```

具体兵种由“基础类型 + 标签 + 属性 + 能力”组合得到。

---

# 4. 阵营与关系

单位之间形成：

- 友方；
- 敌方；
- 中立；
- 特殊关系。

阵营关系用于判断：

- 选择；
- 控制；
- 攻击；
- 跟随；
- 交互；
- 视野与情报共享；
- 小队或编队关系。

---

# 5. 生命周期

```text
未生成
→ 生成中
→ 正常存在
→ 失去行动能力 / 死亡 / 被摧毁 / 离场
→ 失效
```

生命周期状态决定单位当前还能参与哪些规则。

---

# 6. 基础属性

## 生存

- 当前生命值；
- 最大生命值；
- 护盾；
- 护甲；
- 其他生存资源。

## 行动

- 移动相关属性；
- 转向相关属性；
- 攻击相关属性；
- 技能相关属性；
- 交互相关属性。

## 感知

- 视野能力；
- 探测能力；
- 情报共享能力。

## 单位自身资源

- 能量；
- 弹药；
- 充能；
- 其他单位专属资源。

具体计算由对应专项文档定义。

---

# 7. 空间属性

```text
移动能力：
移动空间层：
通行尺寸：
占位尺寸：
特殊通行能力：
```

用途：

- `移动能力`：匹配地图通行区域；
- `移动空间层`：确定主要使用的空间体系；
- `通行尺寸`：判断区域与连接能否通过；
- `占位尺寸`：表示单位需要占据的战场空间；
- `特殊通行能力`：飞行、两栖、跨越等特殊资格。

具体导航判定由《策划文档_地图空间与导航规则》定义。

---

# 8. 控制资格

单位定义是否允许：

- 被玩家选择；
- 被玩家直接控制；
- 接受玩家命令；
- 进入 Unit AI；
- 被 System AI 调度；
- 加入小队；
- 成为主要控制对象。

控制资格可随单位状态变化。

具体控制层规则由《策划文档_基础交互逻辑文档》和《策划文档_UI交互说明》定义。

# 13. 单位状态

## 生命周期状态

- 正常；
- 失去行动能力；
- 死亡 / 被摧毁；
- 离场。

## 行动状态

- 空闲；
- 移动；
- 攻击；
- 施放技能；
- 交互；
- 执行其他命令。

## 控制状态

- Direct Control；
- Unit AI 可用；
- System AI 可调度；
- 暂时失去控制资格。

## 效果状态

- 增益；
- 减益；
- 控制效果；
- 持续效果；
- 特殊任务状态。

状态可以改变属性和行为资格。

# 15. 单位目标资格

单位可作为：

- 选择目标；
- 攻击目标；
- 技能目标；
- Follow 目标；
- Approach 目标；
- Interact 目标；
- AI 指令目标；
- 任务目标。

合法目标由：

```text
阵营关系
+
单位状态
+
单位标签
+
对应行为规则
```

共同判断。

# 17. 单位失效

单位死亡、被摧毁或离场后，统一处理：

- 当前命令结束；
- 当前移动结束；
- 当前攻击结束；
- 当前技能行为结束；
- 控制资格解除；
- 小队或编队关系解除；
- 不再作为正常有效目标；
- 触发对应失效事件；
- 根据专项规则决定尸体、残骸或其他后续状态。

# 19. 系统依赖

```text
单位基础规则
→ 定义单位是什么、拥有什么属性与资格

地图空间与导航规则
→ 判断单位能进入哪里、能否通过

移动与位置规则
→ 决定单位如何完成移动

战斗 / 技能规则
→ 决定单位如何战斗和使用能力

视野与情报规则
→ 决定单位能看到什么、被谁发现

单位 AI / System AI
→ 在单位已有资格内决定行为

编队与小队规则
→ 组织多个单位共同控制
```
