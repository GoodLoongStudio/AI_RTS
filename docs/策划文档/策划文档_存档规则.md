# 策划文档_存档规则

> 状态：待评审  
> 本文定义单人玩法的战役进度存档、战局存档与读档恢复规则。

# 1. 核心结构

存档统一分为两类：

**战役进度存档**

**战局存档**

战役进度存档负责记录：

**玩家整个战役已经推进到哪里。**

战局存档负责记录：

**当前这一场实时战略战斗进行到哪里。**

# 2. 战役进度存档

战役进度存档保存整个战役长期保留的信息。

包括但不限于：

- 当前战役；
- 当前章节；
- 已解锁任务；
- 已完成任务；
- 已失败并需要保留结果的任务；
- 已触发的重要剧情事件；
- 已产生的剧情分支结果；
- 已解锁的后续内容；
- 需要跨关卡继承的数据。

完成关卡结算后，更新一次战役进度存档。

进入新的战役任务前，使用最新战役进度作为任务初始化依据。

# 3. 战局存档

战局存档保存当前战场完整运行现场。

读档后必须能够恢复到保存时的同一场战斗。

战局存档至少保存以下内容。

## 3.1 战场

- 当前地图；
- 当前战局时间；
- 当前阵营与队伍关系；
- 当前已经探索的地图；
- 当前战争迷雾状态；
- 当前已经获得的合法战场情报；
- 当前已经触发的地图事件。

## 3.2 单位与建筑

每个当前存在的单位与建筑保存：

- 当前类型；
- 当前所属阵营；
- 当前位置；
- 当前朝向；
- 当前生命；
- 当前护盾；
- 当前资源；
- 当前状态效果；
- 当前小队与编队关系；
- 当前控制状态。

## 3.3 命令与行动

每个单位保存：

- 当前命令；
- 当前命令目标；
- 当前目标位置；
- 当前命令执行进度；
- 当前等待执行的后续命令；
- 当前行动锚点。

## 3.4 战斗与技能

保存：

- 当前攻击目标；
- 当前攻击流程进度；
- 当前攻击冷却；
- 当前技能状态；
- 当前技能目标；
- 当前技能冷却；
- 当前持续效果；
- 当前持续效果剩余时间；
- 当前弹药、能量、充能等战斗资源。

## 3.5 人工智能

行为树人工智能保存：

- 当前任务；
- 当前单位职责；
- 当前行为姿态；
- 当前具体目标；
- 当前行为执行状态；
- 当前行动范围；
- 当前已经获得的合法情报。

大模型人工智能保存：

- 当前已经下达的任务；
- 当前任务目标；
- 当前目标区域；
- 当前任务优先级；
- 当前控制对象；
- 当前已经获得的合法战场情报；
- 当前仍然有效的高层决策结果。

## 3.6 生产与建造

保存：

- 当前资源；
- 当前生产项目；
- 当前建造项目；
- 当前生产队列；
- 当前生产与建造进度；
- 当前资源占用；
- 当前剩余时间。

## 3.7 战役任务

战役关卡额外保存：

- 当前任务目标；
- 当前任务进度；
- 已完成任务目标；
- 已失败任务目标；
- 已触发任务事件；
- 当前胜负目标；
- 当前剧情推进状态。

# 4. 手动存档

单人战局允许玩家创建手动存档。

创建手动存档时：

**记录当前完整战局现场 → 生成新的战局存档**

手动存档记录用于玩家识别的信息：

- 战役或地图名称；
- 当前任务名称；
- 保存时间；
- 当前战局时间；
- 存档名称。

玩家可以从已有手动存档恢复战局。

# 5. 自动存档

自动存档用于保护战役进度与关键游戏进度。

统一在以下时机自动保存：

- 战役任务正式开始；
- 战役任务完成并进入结算；
- 战役进度发生正式变化。

战役关卡可以在明确的重要阶段触发额外自动存档。

自动存档与手动存档分开保存。

自动存档更新不会覆盖玩家的手动存档。

# 6. 读档恢复

读取战局存档时统一执行：

**读取存档 → 重建地图与战场对象 → 恢复所有保存状态 → 恢复任务与人工智能状态 → 进入暂停状态**

恢复完成后，玩家看到的战场应与保存时保持一致。

包括：

- 单位回到原位置和原状态；
- 当前命令恢复；
- 攻击、技能和冷却恢复到原进度；
- 行为树人工智能恢复当前任务与执行状态；
- 大模型人工智能恢复已经确认的高层任务；
- 生产与建造恢复到原进度；
- 战役任务恢复到原进度；
- 战争迷雾与已获得情报恢复；
- 战局时间恢复到原时刻。

玩家选择继续游戏后：

**从保存时的战局现场继续推进。**

# 7. 读档后的重新判断

战局恢复完成后，各系统按照当前恢复状态继续运行。

恢复后的第一轮更新正常执行已有规则：

- 当前目标失效后重新选择目标；
- 当前路径失效后重新寻路；
- 当前命令需要重新判断时按照命令规则处理；
- 行为树人工智能按照当前任务继续判断；
- 大模型人工智能按照原有触发条件决定是否重新规划。

读档本身不产生新的战场决策。

# 8. 重新开始任务

重新开始战役任务时：

**读取该任务的初始状态 → 重新创建当前任务战局**

任务内产生的临时战场变化重新初始化。

已经写入战役进度存档的长期进度继续保留。

# 9. 存档显示

存档列表至少显示：

- 存档类型；
- 战役 / 地图名称；
- 任务名称；
- 保存时间；
- 战局时间。

战局存档可以附带保存时的战场截图，方便玩家识别。

# 10. 适用范围

本规则优先用于：

- 单人战役；
- 单人自定义战斗。

联机对局的数据恢复使用独立的联机重连与同步规则。

# 11. 最终规则

RTS 存档最终只解决两件事：

**长期进度有没有被记住。**

**当前战斗能不能从原现场继续。**

统一使用：

**战役进度存档 = 保存长期战役进度**

**战局存档 = 保存完整实时战场现场**

战局读档完成后先恢复完整现场，再由玩家继续推进战斗。
