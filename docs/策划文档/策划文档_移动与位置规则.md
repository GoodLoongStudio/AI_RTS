# 策划文档_移动与位置规则

> 状态：待评审  
> 前置依赖：《策划文档_单位基础规则》《策划文档_地图空间与导航规则》《策划文档_指令与命令执行规则》  
> 本文定义：RTS 单位的移动行为分类、目标关系、持续方式、完成条件、位置调整与移动结果。

---

# 1. 移动行为模型

所有移动统一由四部分组成：

```text
移动类型
+
目标结构
+
持续方式
+
完成条件
```

移动系统只负责让单位完成当前移动行为要求的位置关系。

---

# 2. 移动类型总表

| 移动类型 | 典型来源 | 目标 | 是否持续 | 完成方式 |
|---|---|---|---|---|
| 定点移动 | Move | 固定位置 / 区域 | 否 | 到达目标 |
| 推进移动 | Attack Move | 固定位置 / 区域 | 否 | 完成推进 |
| 跟随移动 | Follow | 动态单位 | 是 | 持续维持距离 |
| 接近移动 | Approach | 动态单位 / 目标 | 否 | 进入要求距离 |
| 巡逻移动 | Patrol | 路径 / 多个位置 | 是 | 持续循环 |
| 追击移动 | Attack | 动态敌方目标 | 条件持续 | 进入攻击位置 |
| 交互接近 | Interact | 动态 / 固定交互目标 | 否 | 进入交互位置 |
| 技能接近 | Skill Command | 技能目标 | 否 | 进入技能允许位置 |
| 队形移动 | 小队 / 多选移动 | 分配后的多个位置 | 否或持续 | 各单位完成分配位置 |
| 强制位移 | 击退 / 拉拽 / 推动等 | 方向 / 位移结果 | 否 | 位移结束 |
| 特殊移动 | 冲锋 / 跳跃 / 瞬移等 | 由能力定义 | 否 | 能力规则完成 |

---

# 3. 定点移动

定点移动对应普通 Move。

```text
指定目标位置
↓
目标可直接使用
→ 前往目标

目标点不可直接使用
→ 选择附近合法替代位置

到达
→ Move 完成
```

规则：

- 目标是固定的；
- 中途目标不会主动改变；
- 最终位置允许与点击坐标存在合理偏差；
- 替代位置必须尽量保持原始目标方向与区域意图。

---

# 4. 推进移动

推进移动对应 Attack Move。

核心目标：

> 向指定区域持续推进，同时允许战斗行为暂时介入。

基本结构：

```text
向推进目标移动
↓
出现符合 Attack Move 规则的敌人
→ 暂时进入战斗行为
↓
战斗结束 / 目标失效
→ 继续原推进目标
↓
到达推进区域
→ Attack Move 完成
```

Attack Move 的敌人选择与战斗优先级由《策划文档_战斗基础规则》定义。

---

# 5. 跟随移动

Follow 是持续位置关系，不是一次性到达。

```text
目标距离过远
→ 靠近

进入跟随范围
→ 保持

目标再次拉开
→ 再次移动
```

规则：

- 跟随目标持续更新；
- Follow 不要求与目标重合；
- Follow 自身不会因为一次进入距离范围而完成；
- 只有命令被覆盖、取消或目标失效时才结束。

---

# 6. 接近移动

Approach 是一次性位置关系。

```text
未进入要求距离
→ 靠近

进入要求距离
→ Approach 完成
```

与 Follow 的区别：

```text
Follow
→ 持续维持关系

Approach
→ 达到关系后结束
```

---

# 7. 巡逻移动

Patrol 使用一组有顺序的位置目标。

基础结构：

```text
巡逻点 A
→ 巡逻点 B
→ 巡逻点 C
→ 按规则继续循环
```

规则：

- 到达当前巡逻目标后切换至下一目标；
- Patrol 是持续命令；
- 战斗行为是否暂时介入，由战斗与 Patrol 规则共同决定；
- 新的有效主要命令覆盖 Patrol。

第一阶段至少支持：

```text
A ↔ B
```

多点巡逻可继续沿同一规则扩展。

---

# 8. 追击移动

追击移动不是独立玩家命令，而是 Attack 的移动阶段。

```text
Attack 目标合法
↓
当前不满足攻击位置
→ 向目标移动
↓
满足攻击位置
→ 停止追击
→ 进入攻击阶段
```

目标继续移动时，追击目标同步更新。

攻击目标失效后，由《策划文档_指令与命令执行规则》决定 Attack 的结束状态。

---

# 9. 交互接近

Interact 目标当前不满足交互位置要求时：

```text
Interact
↓
目标合法
↓
距离 / 位置不满足
→ 接近目标
↓
满足交互条件
→ 停止移动
→ 执行交互
```

交互目标失效时，Interact 按命令规则结束。

---

# 10. 技能接近

只有明确允许“自动接近”的技能才产生技能接近移动。

```text
技能目标合法
↓
当前位置不能执行
↓
技能允许自动接近
→ 移动至技能允许位置
↓
满足条件
→ 执行技能
```

如果技能不允许自动接近，则不产生该移动。

具体规则由《策划文档_技能基础规则》定义。

---

# 11. 队形移动

多个单位收到同一移动意图时：

```text
共同移动目标
↓
编队 / 小队规则分配各单位目标位置
↓
每个单位执行自己的移动目标
```

移动系统只执行分配后的单位目标。

以下内容由《策划文档_编队小队与控制关系》定义：

- 队形；
- 单位槽位；
- 队形保持；
- 集结；
- 队形重排。

---

# 12. 强制位移

强制位移不属于单位主动导航行为。

包括：

- 击退；
- 拉拽；
- 推动；
- 抛飞；
- 其他外部强制位置变化。

统一规则：

```text
外部效果产生位移
↓
按效果要求改变单位位置
↓
位移结束
↓
重新确认单位当前合法状态
```

强制位移是否可以越过普通导航限制，由具体效果规则定义。

---

# 13. 特殊移动

特殊移动是单位能力或技能产生的特殊位置变化。

包括但不限于：

- 冲锋；
- 跳跃；
- 瞬移；
- 穿越；
- 地下移动；
- 特殊飞跃。

特殊移动需要单独定义：

```text
目标类型
移动过程
可穿越规则
停止条件
中断条件
结束位置要求
```

具体内容由对应单位或技能规则定义。

---

# 14. 目标位置与替代位置

普通导航移动都遵循：

```text
原目标可用
→ 使用原目标

原目标不可直接停留
但附近存在合法位置
→ 使用替代位置

不存在能够保持原意图的合法位置
→ 当前移动无法完成
```

替代位置优先级：

1. 满足原命令的位置关系；
2. 合法可达；
3. 满足单位占位；
4. 尽量接近原目标；
5. 形成稳定停止位置。

---

# 15. 单位占位与停止

单位最终停止时必须形成稳定占位。

多个单位进入同一区域时：

```text
目标区域
↓
分配各自停止位置
↓
空间不足
→ 向附近合法位置展开
```

移动层只负责单位最终位置稳定。

队形优先级与位置分配方式由编队规则定义。

---

# 16. 动态阻挡

移动过程中出现临时阻挡时：

```text
存在其他可行移动结果
→ 调整后继续

阻挡预计可解除
→ 短暂等待

目标仍可达但原移动结果失效
→ 更新后继续

目标已无法合理完成
→ 移动结束
```

单位移动最终必须收敛到明确状态。

---

# 17. 移动完成条件

所有主动导航移动，都必须明确自己的完成条件。

| 类型 | 完成条件 |
|---|---|
| 定点移动 | 到达目标或替代位置 |
| 推进移动 | 到达推进目标 |
| 跟随移动 | 无普通“完成”，持续维持 |
| 接近移动 | 进入目标距离 |
| 巡逻移动 | 无普通“完成”，持续循环 |
| 追击移动 | 进入攻击位置 |
| 交互接近 | 进入交互位置 |
| 技能接近 | 进入技能执行位置 |
| 队形移动 | 到达分配位置 |
| 强制位移 | 效果位移结束 |
| 特殊移动 | 按具体能力定义 |

---

# 18. 移动结果

一次移动阶段最终只允许进入：

- 到达；
- 保持；
- 等待；
- 调整后继续；
- 被新命令覆盖；
- 目标失效结束；
- 不可达结束；
- 特殊移动完成。

---
