# 策划文档_移动与位置规则

> 状态：已完成  
> 前置依赖：《策划文档_单位基础规则》《策划文档_地图空间与导航规则》《策划文档_指令与命令执行规则》  
> 本文定义当前 RTS Demo 已有移动命令的目标结构、持续方式、完成方式与停止规则。

---

# 1. 当前移动体系

当前程序正式存在的移动相关命令为：

| 策划名称 | 程序命令 | 目标 |
|---|---|---|
| 移动 | `Move` | 世界位置 |
| 靠近目标 | `ApproachEntity` | 稳定战场实体 |
| 跟随目标 | `FollowEntity` | 稳定单位 / 建筑 |
| 强制移动 | `ForceMove` | 世界位置 |
| 地面攻击移动 | `GroundAttackMove` | 世界位置 |
| 目标攻击移动 | `EntityAttackMove` | 敌方实体 |
| 战术撤退 | `TacticalWithdraw` | 世界位置 |

“停止移动”属于控制操作，不创建新的移动命令。

---

# 2. 通用移动流程

移动类指令统一经过：

```text
指定单位和目标
↓
检查单位是否存在、是否属于当前玩家、是否可移动
↓
检查目标是否合法
↓
执行端接受移动请求
↓
创建单位命令
↓
进入执行中
↓
到达 / 完成 / 暂停 / 不可达 / 目标丢失 / 取消 / 单位失效
```

无效移动指令不会覆盖当前合法命令。

---

# 3. 移动

普通移动对应 `Move`。

```text
指定世界位置
→ 请求移动
→ 单位前往目标
→ 到达后命令进入已到达
```

普通移动只要求单位完成到达目标位置这一意图。

具体路径计算、避障和可达性由导航执行端负责。

---

# 4. 靠近目标

靠近目标对应 `ApproachEntity`。

目标可以是当前程序允许识别的战场实体。

基本流程：

```text
指定目标实体
→ 向目标靠近
→ 到达目标 footprint 对应的有效接近位置
→ 命令完成
```

靠近目标是一次性关系。

达到要求距离后，命令结束。

---

# 5. 跟随目标

跟随目标对应 `FollowEntity`。

```text
指定单位 / 建筑
→ 持续跟随目标
→ 目标位置变化
→ 持续更新跟随关系
```

跟随不会因为第一次进入有效距离就自动完成。

只有以下情况结束当前跟随：

- 被新命令覆盖；
- 被停止；
- 目标失效；
- 执行单位失效。

---

# 6. 强制移动

强制移动对应 `ForceMove`。

```text
指定世界位置
→ 创建强制移动命令
→ 单位向目标位置移动
```

强制移动在命令层与普通移动保持独立语义。

当前执行端仍使用正式移动端口完成位移。

---

# 7. 地面攻击移动

地面攻击移动对应 `GroundAttackMove`。

```text
指定世界位置
→ 向目标区域推进
→ 按当前交战姿态和开火策略处理中途敌人
→ 继续推进
→ 到达目标区域
```

攻击移动保留原始推进目标。

途中战斗不会把推进目标永久替换为普通攻击目标。

具体接敌和战斗流程由《策划文档_战斗基础规则》定义。

---

# 8. 目标攻击移动

目标攻击移动对应 `EntityAttackMove`。

```text
指定敌方实体
→ 保留该实体作为最终目标
→ 向目标推进
→ 按当前交战策略处理中途敌人
→ 继续追踪最终目标
```

与地面攻击移动的区别：

```text
地面攻击移动
→ 最终目标是位置

目标攻击移动
→ 最终目标是稳定敌方实体
```

最终目标失效时，当前命令按目标丢失规则结束。

---

# 9. 战术撤退

战术撤退对应 `TacticalWithdraw`。

```text
指定撤退位置
↓
单位具备倒车能力
→ 沿导航路径倒车撤退

单位不具备倒车能力
→ 使用普通移动执行撤退
```

撤退目的地必须由当前指令明确提供。

战术撤退不会自动寻找“安全方向”。

---

# 10. 停止移动

停止移动用于暂停当前位移，不创建新命令。

适用当前命令：

- 移动；
- 靠近目标；
- 跟随目标；
- 强制移动；
- 地面攻击移动；
- 目标攻击移动；
- 战术撤退。

执行结果：

```text
停止当前位移
→ 当前移动类活动命令进入暂停
```

停止移动不会改变：

- 当前交战姿态；
- 当前开火策略。

---

# 11. 新命令覆盖移动

单位存在移动类活动命令时，如果新的有效单位命令创建：

```text
旧移动命令
→ 已取消

新命令
→ 成为当前活动命令
```

当前 Demo 每个单位只保留一个当前活动命令。

当前不支持多命令移动队列。

---

# 12. 批量移动

一次玩家操作可以向多个单位提交相同移动意图。

系统仍然按单位逐个处理：

```text
单位 A → 独立校验 → 独立命令
单位 B → 独立校验 → 独立命令
单位 C → 独立校验 → 独立命令
```

因此部分单位无法执行时，不要求整批移动全部失败。

每个单位拥有独立命令状态。

---

# 13. 目标失效

依赖实体目标的移动：

- 靠近目标；
- 跟随目标；
- 目标攻击移动。

目标失效后：

```text
当前实体目标不可继续使用
→ 命令进入目标丢失或由对应执行规则结束
```

不会继续追踪已经失效的场景对象。

---

# 14. 不可达

移动执行端确认目标无法完成时：

```text
当前移动无法继续
→ 命令进入不可达
→ 不再作为当前活动命令
```

具体采用何种寻路、重寻路、局部避障和动态阻挡算法，由《策划文档_地图空间与导航规则》和程序导航实现决定。

---

# 15. 单位失效

移动中的单位死亡、被摧毁或离场：

```text
当前移动命令
→ 单位失效
→ 移动结束
```

失效单位不再继续占用正常单位命令状态。

---

# 16. 当前移动结果

当前移动类命令统一收敛到正式命令状态：

- 已接受；
- 执行中；
- 暂停；
- 已到达；
- 已完成；
- 不可达；
- 目标丢失；
- 已取消；
- 单位失效。

移动文档不再额外创造与程序状态机重复的移动结果枚举。

---

# 17. 当前范围

当前版本不把以下能力写成已经存在的正式移动命令：

- 巡逻；
- 通用交互接近；
- 技能接近；
- 技能特殊移动；
- 冲锋；
- 跳跃；
- 瞬移；
- 击退；
- 拉拽；
- 独立队形移动命令。

多单位选择和控制组仍然属于 RTS 基础操作，但每个单位最终通过现有正式移动命令独立执行。

后续新增移动能力时，继续接入当前“指令 → 单位命令 → 移动执行端 → 命令状态”的统一结构。
