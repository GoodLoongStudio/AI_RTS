# 04 · 策略库：侦察与情报

> 覆盖：侦察、敌情过期、信息不足。
> 侦察线**与经济线并行**——不是"侦察完成后才采集"。
> 策略参考；四列任务、生命周期和验收以 [当前执行入口](../../程序文档/AI副官_当前执行入口.md) 为准。下文坐标为程序展开后的目标，模型只选择合法引用。

## 1. 情报的现实约束

| 约束 | 说明 |
|---|---|
| 没有全局视野 | `visible_enemy_ids` 仅指当前玩家可见实体；历史敌情另存最后目击位置和时间，不得混入当前可见目标 |
| 观测可能被截断 | `tactical_summary.truncated=true` 时，**未返回 ≠ 阵亡** |
| 敌情会过期 | 敌方单位离开视野后信息滞留；陈旧信息不能当"当前事实" |
| `drone` 无武器 | 用 `drone` 侦察可以，但**不要派它交战** |

## 2. 侦察线的判断

| 判断 | 依据 | 结论 |
|---|---|---|
| 需要侦察吗 | `visible_enemy_ids` 为空 或 长期无更新 | 提供侦察与维持等候选，由模型决定 |
| 谁去 | `own_units` 中 `can_move=true` 且**未被占用**的作战/机动单位 | 优先作战单位之外的闲人 |
| 去哪 | 未探索方向 / 已知敌情方向的反面 / 地图资源富集侧 | 给 `target_pos=[x,z]` |
| 侦察占用上限 | 按授权执行者、局势和策略配置 | 以 1 个机动单位为待实测起点，不能写成全局硬上限 |

**硬纪律**：侦察仅占用模型明确选择的授权对象；其余单位继续原有任务。
下列模板以 1 个机动单位说明，实际规模允许通过策略配置与模型选择调整。到达目标点只表示移动完成，侦察仍须满足观察或探索条件。

## SCT-01 · 开局散点探路（含探矿）

```yaml
id: SCT-01
name: 开局散点探路
适用条件:
  - 开局无可见敌人
  - 且无可见资源 或 资源仅 1 处
必需事实: own_units（可移动单位）、visible_resources、map_bounds（战略视图）
禁止条件:
  - 基地受袭（先 DEF-01）
  - 已有 scout 意图在途中（属于"维持"）
可选任务:
  - 派 1 个机动单位 scout 到 target_pos=[x,z]（朝地图未探索方向）
  - 其余单位继续既定任务
资源与控制范围: 1 个机动单位
成功证据:
  - 该单位进入新区域后，后续观测的 visible_resources / visible_enemy_ids 增加
  - 或权威探索覆盖指标扩大（不得把分页观测的 covered 字段当成地图探索率）
失败分支:
  - 目标不可达 → 换方向；连续两次不可达 → 标记该方向并改方向
退出条件: 已发现新的资源点或敌情
重新评估条件: 每轮；发现敌情后立即转 SCT-02
parameters:
  scout_target_distance: 待实测
```

## SCT-02 · 定向侦察敌方基地

```yaml
id: SCT-02
name: 定向侦察敌方基地
适用条件:
  - 已知敌情存在但位置信息陈旧（长时间无更新）
  - 或准备进攻前需要确认敌方主基地位置
必需事实: visible_enemy_ids、历史敌情、map_bounds
禁止条件:
  - 无可用机动单位（此时"信息不足"是合法结论，不要强行派工人去送死）
可选任务: scout 到敌情方向的更远处（target_pos）
资源与控制范围: 1 个机动单位
成功证据: 后续观测新增敌方实体（尤其建筑类）
失败分支:
  - 侦察单位被击毁 → 记录 unit_lost，本轮起"信息不足"，**不得**盲目进攻
退出条件: 已获得敌方基地位置或确认该方向无敌方基地
重新评估条件: 敌情再次过期 / 玩家给出目标
parameters:
  intel_stale_ticks: 待实测   # 超过该时长视为过期
```

## SCT-03 · 信息不足时的合法选择（**重要**）

```yaml
id: SCT-03
name: 信息不足 → 先侦察 / 或等待
适用条件:
  - 准备进攻但无可见敌情
  - 或 visible_enemy_ids 为空且侦察单位不可用
必需事实: visible_enemy_ids、own_units（可移动单位数）
禁止条件: 无（这是兜底选择，任何局势都合法）
可选任务:
  - scout（若能派出）
  - 维持现有任务（等待）
  - gather（把单位用于经济，总比站着强）
资源与控制范围: 维持不新增占用；侦察或采集仅使用模型明确选择且能力匹配的授权对象
成功证据: 维持只记录等待理由与已有任务进展，不伪造完成；侦察和采集按对应执行证据判断
失败分支: 长期无情报且无经济进展 → 上升为 degraded 原因供玩家查看
退出条件: 获得情报 / 玩家给出目标 / 有足够军队需要集结
重新评估条件: 每轮
parameters: {}
```

**必须明确写进模型可选项**：`维持现有任务` 与 `信息不足先侦察` 都是**有效选择**——
否则 2B 模型会在无情报时编造坐标（历史缺陷：合法 JSON 里 `attack` 使用位置而非实体 id）。

## 3. 反模式（不要做）

| 反模式 | 为什么错 |
|---|---|
| "等若干轮没发现就向地图中心推进" | "中心必有遭遇"是**未经验证的假设**，地图尺寸/布局可变 |
| 派侦察单位去建造/采集 | 能力不匹配，权威层会拒（历史 `ProductNotAllowed` 类问题的近亲） |
| 用全局 `revealed_units` 判敌 | 违反迷雾公平性，副官只能用本玩家视野 |
| 侦察单位被击毁后仍按旧情报进攻 | 陈旧情报当作当前事实 |
