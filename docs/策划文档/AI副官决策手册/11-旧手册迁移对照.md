# 11 · 旧手册迁移对照

> 对象：`docs/ai-adjutant-handbook/`（README + 01~07 章）。
> 该手册**面向 Hermes 副官**（云端会话 + tool calling + `sleep` 轮询），
> 与 2026-09-11 的**本地完整副官**架构（本机 Ollama + LangGraph + PydanticAI +
> `DirectiveBatch` + 玩家意图确认）**直接冲突**。
>
> **处理方式：保留原文件作为历史追溯，加本对照表说明状态；不删除、不重写。**
> 建议在旧手册 README 顶部加一行指向本手册（本轮已在本手册侧记录，旧文件本轮不改动）。
