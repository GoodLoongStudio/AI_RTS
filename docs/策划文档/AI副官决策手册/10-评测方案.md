# 10 · 评测方案

> **状态：仅方案，尚未执行。本节不得填写任何虚构结果。**
> 目的：验证"手册 + 候选筛选"是否真的让 2B 模型决策更好，而不是把答案提前给死。

## 1. 对照设计（同条件）

| 组 | 配置 | 变量 |
|---|---|---|
| **A 组（基线）** | 无手册约束、无候选菜单（现状提示词） | — |
| **B 组（本手册）** | 手册策略 + 候选筛选 + `DirectiveBatch` | 唯一变量 |

**必须同条件**：

- 同一模型（同标签、同 `num_ctx`、同 `num_predict`、同温度 0）
- 同一组输入：**真实观测**或**明确标注的回放文件**
- 同一超时与调度（每局一个在途请求、同一 TTL）
- 同一评测脚本、同一统计口径

## 2. 输入集要求

至少 100 次真实请求，覆盖以下场景族（每族 ≥ 12 次，含变体）：

| 场景族 | 要点 | **禁止** |
|---|---|---|
| 经济取舍 | 多矿点就近 vs 换点；缺工人 vs 缺钱 | 输入里写出"应该去 ResourceB" |
| 基地受袭 | 敌近基地 + 工人采集 + 无塔/有塔 | 输入里写"应该回防" |
| 侦察不足 | 无可见敌人 | 输入里写"应该侦察" |
| 撤退 | 敌方数量多于我方作战单位 | 输入里写"应该撤退" |
| 玩家介入 | `player_controlled_units` 非空 | 输入里写"不要碰 Unit_3" |
| 多小队冲突 | 工人 + 作战单位 + 敌人同时存在 | 输入里写"派 2 个士兵" |

- **输入不得包含标准答案**；**允许多个合理选择**（评分按"语义合法 + 必要动作覆盖"）。
- 回放输入必须**标明来源与生成方式**，不得与真实观测混算。

## 3. 统计指标

| 指标 | 定义 | 口径 |
|---|---|---|
| 输入 token | 请求实际 token（Ollama 上报或同口径估算） | 均值 / P95 |
| 输出 token | 同上 | 均值 / 最大 |
| **首次语义合法率** | **单次**调用（无重试）产出是否通过契约**且**语义合法 | 分母 = 全部请求 |
| 结构合法率 | JSON/`DirectiveBatch` 校验通过率 | 同上 |
| 修复次数 | 靠重试救回的次数 | 占比 |
| 超时率 | 超过单轮期限的比例 | 占比 |
| **端到端 P50 / P95** | 从发起到拿到合法结果 | 冷启动**单独记录** |
| 任务推进情况 | 该场景**必要动作**是否出现在结果里 | 见 §4 |

**目标（来自上位方案，需实测确认）**：热态 **P50 ≤ 1.5 s、P95 ≤ 4 s**。
A/B 两组用**同一套目标**比较，不得只报 B 组。

## 4. 任务推进情况的判定（防"选项太少所以错误率低"）

对每个场景预先声明**必要动作集合**（可多选，任一满足即算覆盖），例如：

| 场景 | 必要动作（任一即可） |
|---|---|
| 基地受袭 | `attack` 或 `defend` 或 `retreat` |
| 侦察不足 | `scout` 或（`move` 到未知区域） |
| 撤退 | `retreat` 或 `move` 朝基地方向 |
| 发展阶梯 | `build`（兵营/车厂）或 `produce` 作战单位 |
| 玩家介入 | 结果中**不包含** `player_controlled_units`（这是**必须**，不是任一） |

**两项额外检查**（关键，防自欺）：

1. **候选覆盖率**：构造"必须建造/必须撤退/必须侦察"的观测，
   检查候选集**确实包含**该必要动作。若不含 → 候选生成缺陷（不是模型问题）。
2. **选择分布敏感性**：把候选从 3 条扩到 6 条（加入更多合法变体），
   观察模型选择是否真的变化。若**完全不变** → 候选过度具体，等于提前定答案。

## 5. 执行与产物

```
评测脚本（建议路径）tmp_logs/langgraph_recon/bench_handbook.py
  ① 加载同一回放集 → 分别以 A/B 配置请求模型
  ② 记录每条：输入/输出 token、耗时、结构/语义合法性、覆盖的必要动作
  ③ 输出对照表 + 逐条明细（含失败原因）
```

**产物要求**：

- 原始明细（JSONL），**可复现**（同输入 + 同配置 → 同结果）
- 汇总表（A/B 并列）
- 结论必须写明：**哪些指标改善、哪些没改善、样本量、置信度局限**
- 未跑的场景**留空**，不得填"预期会改善"

## 6. 已知偏差与限制

| 限制 | 影响 |
|---|---|
| 单个 2B 模型的结论不能外推到其它模型 | 换模型须重测 |
| 合成场景 ≠ 真实对局 | 需另有 15 分钟真实对局验收（见上位方案） |
| 温度 0 下同输入结果相同 | 变体必须来自**输入差异**，不是重复采样 |
| GPU 显存/温度状态影响 | 记录 `ollama ps` 与显存，避免把 OOM 回退 CPU 当"模型变慢" |
