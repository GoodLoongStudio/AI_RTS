# 策划文档_目标选择与Targeting规则

> 状态：待评审  
> 本文定义：当命令或技能需要目标时，目标类型、Targeting 进入与退出、目标确认方式、合法性检查、快捷施法以及异常处理规则。  
> 本文不定义：基础按键总表、命令执行生命周期、寻路算法、伤害公式、技能具体数值、战争迷雾实现、UI 具体视觉表现。  
> 前置规则：《策划文档_基础交互逻辑文档》《策划文档_指令与命令执行规则》。

---

# 1. 核心原则

> **Targeting 负责“确认目标并生成合法命令”；目标确认完成后，后续执行交由《策划文档_指令与命令执行规则》处理。**

同一玩家同一时间只能存在一个主动 Targeting 状态。

新的 Targeting 会替换旧 Targeting。

---

# 2. 目标类型

当前统一使用以下目标类型：

| 目标类型 | 示例 |
|---|---|
| 无目标 | 自身强化、Stop、Hold Position |
| 地面位置 | Move、Attack Move、位移技能 |
| 己方单位 | Follow、治疗、增益 |
| 敌方单位 | Attack、单体攻击技能 |
| 任意单位 | 特殊技能 / 特殊交互 |
| 区域 | 炮击、扫描、范围技能 |
| 方向 | 冲锋、锥形攻击 |
| 可交互对象 | 门、终端、任务对象 |

具体技能使用哪种目标类型，由技能规则定义。

---

# 3. 是否进入 Targeting

命令已经能够直接确定目标时，不进入 Targeting。

例如：

```text
右键敌方单位
→ 已确定敌方目标
→ 直接生成 Attack
```

需要玩家进一步指定目标时，进入 Targeting。

例如：

```text
按 Attack Move
→ 进入地面 Targeting
→ 玩家选择位置
→ 生成 Attack Move
```

技能同理：

```text
按技能
→ 技能需要目标
→ 按当前施法模式进入 Targeting 或直接读取鼠标目标
```

---

# 4. Normal Cast：普通目标确认

普通施法 / 普通目标选择规则：

```text
触发技能或命令
↓
进入 Targeting
↓
移动鼠标选择目标
↓
左键确认
↓
目标合法性检查
↓
生成 Command
```

基础操作：

- 左键合法目标：确认；
- 左键非法目标：不生成命令；
- `Esc`：通用取消当前 Targeting；
- 右键：**不是通用取消键，必须按当前 Targeting 与右键上下文规则判断。**

右键只在满足以下条件时取消当前 Targeting：

1. 当前 Targeting 允许被普通右键命令打断；
2. 当前右键能够产生一个合法的新命令。

例如：

```text
技能 Targeting 中
→ 右键可移动地面
→ 当前技能允许被普通移动命令打断
→ 取消技能 Targeting
→ 生成 Move
```

如果当前右键没有合法语义，或该 Targeting 明确不允许被右键打断，则不得因为一次右键输入自动取消。

因此：

> **`Esc` 是明确、通用的取消操作；右键只是“在特定上下文下可能导致 Targeting 被取消”的输入。**

右键规则属于本项目交互设计，不视为所有 RTS 的统一行业规则。

---

# 5. 技能施法确认模式

技能的“目标类型”与“确认方式”是两个独立概念。

当前支持以下确认方式：

| 模式 | 规则 |
|---|---|
| Normal Cast | 按技能键后进入 Targeting，左键确认 |
| Quick Cast | 按技能键时直接读取当前鼠标位置 / 鼠标指向目标并尝试施放 |
| Quick Cast With Indicator | 按住技能键显示 Targeting 指示，松开按键确认 |
| Instant Cast | 按技能键立即执行，不需要额外目标确认 |

---

# 6. Quick Cast：快捷施法

Quick Cast 不进入“等待左键确认”的 Targeting 流程。

例如地面技能：

```text
鼠标位于 B 点
↓
按 Q
↓
读取 B 点
↓
合法性检查
↓
生成 Skill Command
```

例如单位目标技能：

```text
鼠标指向敌方单位 A
↓
按 Q
↓
A 为合法目标
↓
生成 Skill Command
```

如果当前鼠标位置或鼠标指向对象不是合法目标：

```text
Quick Cast
↓
合法性检查失败
↓
不施放
↓
轻量失败反馈
```

核心规则：

> **Quick Cast 只跳过“左键确认”步骤，不跳过目标合法性检查。**

---

# 7. Quick Cast With Indicator

该模式用于希望兼顾快捷操作与施法范围预览的玩家。

基础规则：

```text
按住技能键
↓
显示范围 / 方向 / 区域指示
↓
移动鼠标调整目标
↓
松开技能键
↓
合法性检查
↓
确认施放
```

如果松开时目标非法，则不施放。

取消方式按输入设置执行，至少支持 `Esc` 取消。

---

# 8. 技能施法模式设置

施法确认方式应作为玩家操作设置，而不是强制所有技能使用同一种模式。

建议支持：

- 全部普通施法；
- 全部快捷施法；
- 逐技能配置。

例如：

```text
Q = Quick Cast
W = Normal Cast
E = Quick Cast With Indicator
R = Normal Cast
```

Instant Cast 仅用于技能设计本身无需选择目标的技能，不由玩家强制修改为 Targeting 技能。

---

# 9. 目标合法性

无论 Normal Cast、Quick Cast 还是其他确认方式，最终均使用同一套目标合法性检查。

至少判断：

- 目标类型是否正确；
- 目标是否仍然存在；
- 阵营关系是否允许；
- 当前对象是否允许被选择；
- 当前技能 / 命令是否允许该目标；
- 当前状态是否允许产生该命令。

非法目标不得生成 Command。

---

# 10. 合法目标与执行距离

> **目标合法不等于当前已经处于执行距离。**

例如：

```text
Attack 目标合法
但目标超出攻击距离
→ Attack 仍可成立
→ 单位后续自动接近目标
```

技能是否允许“确认远距离目标后自动接近”，由具体技能规则定义。

因此 Targeting 只判断：

> 当前目标能否成为该命令的目标。

实际移动、接近和执行由后续命令系统处理。

---

# 11. Targeting 取消与替换

以下情况取消当前 Targeting：

| 情况 | 游戏处理 |
|---|---|
| 玩家按 `Esc` | 取消当前 Targeting |
| 玩家触发新的 Targeting | 新 Targeting 替换旧 Targeting |
| 重新选择其他己方单位 / 小队 | 取消原对象 Targeting |
| 当前施法 / 执行单位死亡、销毁或离场 | 取消 |
| 技能在确认前变为不可用 | 取消 |
| 玩家进入不兼容的操作层 | 取消 |
| 右键产生合法的新命令，且当前 Targeting 允许被右键打断 | 取消 Targeting，并执行该右键命令 |
| 右键无合法命令，或当前 Targeting 不允许被右键打断 | 不按“通用取消”处理，保持当前合法状态 |

取消 Targeting 不应产生原命令。

---

# 12. 目标在确认前失效

Targeting 阶段目标失效时，不得生成针对无效目标的 Command。

例如：

```text
进入单位目标技能 Targeting
↓
目标死亡
↓
玩家点击原目标位置
↓
合法性检查失败
↓
不生成 Skill Command
```

目标在“确认之后”失效，则不再属于 Targeting 规则，由《策划文档_指令与命令执行规则》处理。

边界原则：

> **确认前归 Targeting；确认后归 Command。**

---

# 13. 视野与战争迷雾

Targeting 不自行定义“单位是否可见”。

单位是否属于当前可识别目标，由后续《策划文档_视野战争迷雾与情报规则》定义。

Targeting 只遵循：

> **当前规则判定为不可合法选择的对象，不允许确认成为目标。**

---

# 14. 冲突与优先级

Targeting 层默认遵循：

```text
明确取消 Targeting
>
新的玩家 Targeting
>
当前合法 Target
>
原 Targeting 状态
```

并遵循以下原则：

- 同时只能存在一个主动 Targeting；
- 新 Targeting 替换旧 Targeting；
- `Esc` 是 Targeting 的通用明确取消输入；
- 右键不是通用取消输入，仅在上下文规则满足时打断 Targeting；
- Quick Cast 与 Normal Cast 使用相同目标合法性；
- 非法目标不得产生命令；
- 目标确认完成后立即退出 Targeting；
- Targeting 不负责命令确认后的执行过程；
- 重复输入不得产生多个并行 Targeting 状态。

---
