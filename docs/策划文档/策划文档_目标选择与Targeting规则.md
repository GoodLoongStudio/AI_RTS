# 策划文档_目标选择与Targeting规则

> 状态：已完成  
> 本文只定义当前 RTS Demo 已有的单位命令 Targeting。  
> 技能、复杂施法模式和多段 Targeting 当前不进入正式实现范围。

---

# 1. Targeting 的职责

Targeting 只负责：

```text
进入目标选择
→ 玩家确认目标
→ 检查目标是否合法
→ 提交正式指令
→ 退出 Targeting
```

目标确认完成后的移动、攻击和命令状态由对应 RTS 系统处理。

同一时间只允许存在一个主动 Targeting。

新的 Targeting 会替换旧 Targeting。

---

# 2. 当前程序已支持的 Targeting

当前单位命令 HUD 已经支持四类 Targeting：

| Targeting | 确认目标 |
|---|---|
| 强制移动 | 右键地面 |
| 强制攻击 | 右键单位或地面 |
| 战术撤退 | 右键地面 |
| 攻击移动 | 右键地面或敌方单位 |

这些能力分别对应现有正式指令入口。

---

# 3. 强制移动

```text
点击“强制移动”
→ 进入强制移动 Targeting
→ 右键地面
→ 合法性检查
→ 提交强制移动指令
→ 退出 Targeting
```

再次点击当前“强制移动”按钮：

**取消当前强制移动 Targeting。**

---

# 4. 强制攻击

```text
点击“强制攻击”
→ 进入强制攻击 Targeting
→ 右键单位或地面
→ 合法性检查
→ 提交强制攻击 / 地面强制攻击指令
→ 退出 Targeting
```

单位是否允许攻击纯地面位置，由单位能力决定。

再次点击当前“强制攻击”按钮会取消 Targeting。

---

# 5. 战术撤退

```text
点击“撤退”
→ 进入战术撤退 Targeting
→ 右键地面
→ 合法性检查
→ 提交战术撤退指令
→ 退出 Targeting
```

撤退位置必须由玩家明确指定。

系统不会自动寻找“安全方向”。

再次点击当前撤退按钮会取消 Targeting。

---

# 6. 攻击移动

攻击移动允许两种正式目标：

## 地面

```text
进入攻击移动 Targeting
→ 右键地面
→ GroundAttackMove
```

## 敌方实体

```text
进入攻击移动 Targeting
→ 右键合法敌方单位
→ EntityAttackMove
```

再次点击当前攻击移动按钮会取消 Targeting。

---

# 7. 不经过 Targeting 的常用操作

目标已经由鼠标上下文直接确定时，不需要额外进入 Targeting。

包括当前传统 RTS 基础操作：

- 右键空地 → 普通移动；
- 右键合法敌人 → 普通攻击；
- 右键合法友方实体 → 按当前规则跟随 / 靠近。

停止移动、停止、设置交战姿态、设置开火策略也不需要目标选择。

---

# 8. 目标合法性

目标确认时至少检查：

- 当前是否存在合法己方执行单位；
- 单位是否具备对应能力；
- 地面位置是否为有效输入；
- 实体目标是否仍然存在；
- 阵营关系是否允许；
- 目标战斗域是否允许攻击；
- 强制攻击地面时单位是否具备对应能力。

非法目标不生成正式指令。

---

# 9. Targeting 取消

当前必须支持：

- 再次点击当前 Targeting 命令按钮 → 取消；
- 选择状态失去可执行单位 → 取消；
- 进入新的 Targeting → 替换旧 Targeting；
- `Esc` 作为统一取消入口【待程序输入完全同步】。

取消 Targeting 不产生原命令。

---

# 10. 当前阶段不做的复杂设计

以下内容保留历史设计，但当前 Demo 不进入正式 Targeting 系统：

- ~~Normal Cast / 普通施法模式。~~
- ~~Quick Cast / 快捷施法。~~
- ~~Quick Cast With Indicator / 按住预览、松开确认。~~
- ~~逐技能配置普通施法、快捷施法和指示器施法。~~
- ~~Q/W/E/R 技能 Targeting。~~
- ~~方向型技能 Targeting。~~
- ~~范围技能 Targeting。~~
- ~~多段技能连续选择多个目标。~~
- ~~技能目标确认后自动接近再施放。~~
- ~~Unit AI / System AI 自动 Targeting。~~

当前技能系统本身处于暂缓状态，因此 Targeting 不为技能提前建立复杂框架。

---

# 11. 当前基础验收

必须通过：

1. 强制移动可以进入、确认、取消。
2. 强制攻击可以选择单位或地面，并正确区分能力资格。
3. 战术撤退必须明确指定地面目的地。
4. 攻击移动可以选择地面或合法敌方单位。
5. 新 Targeting 不与旧 Targeting 并存。
6. 选择失效后不能继续提交旧 Targeting。
7. 非法目标不会生成正式指令。

---

# 12. 当前原则

**Targeting 只解决“这次命令指向哪里”，不提前承担技能系统、导航系统或战斗系统的职责。**
