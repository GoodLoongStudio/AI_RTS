# 策划文档_暂停与恢复规则

> 状态：待评审  
> 本文定义战局暂停时的冻结规则、状态保留规则与恢复规则。

# 1. 核心机制

暂停统一执行：

**触发暂停 → 冻结战局推进 → 保留当前运行状态**

恢复统一执行：

**解除暂停 → 读取当前保留状态 → 从原进度继续**

暂停与恢复针对当前正在进行的战局生效。

# 2. 暂停后停止推进的内容

进入暂停后，所有依赖战局时间推进的内容统一停止。

包括但不限于：

- 战局时间；
- 单位移动；
- 攻击流程；
- 技能施放流程；
- 技能冷却；
- 持续效果时间；
- 生产与建造进度；
- 行为树人工智能执行；
- 大模型人工智能的战场任务推进；
- 战役任务计时；
- 与战局时间关联的事件计时；
- 胜负条件的持续变化判断。

暂停后，当前战场保持在暂停发生的时刻。

# 3. 暂停期间保留的战局信息

暂停期间保留当前战局全部继续运行所需要的信息。

## 3.1 单位信息

每个当前存在的单位保留：

- 当前位置；
- 当前朝向；
- 当前生命；
- 当前护盾；
- 当前资源；
- 当前状态效果；
- 当前所属阵营；
- 当前所属小队与编队关系；
- 当前控制状态。

## 3.2 命令信息

每个单位保留：

- 当前正在执行的命令；
- 当前命令目标；
- 当前命令目标位置；
- 当前命令执行进度；
- 当前等待执行的后续命令；
- 当前行动锚点。

## 3.3 战斗信息

正在进行中的战斗行为保留：

- 当前攻击目标；
- 当前攻击阶段；
- 当前攻击冷却进度；
- 当前技能施放阶段；
- 当前技能目标；
- 当前技能冷却进度；
- 当前持续效果；
- 当前持续效果剩余时间；
- 当前弹药、能量、充能等战斗资源。

## 3.4 人工智能信息

行为树人工智能保留：

- 当前任务；
- 当前单位职责；
- 当前行为姿态；
- 当前具体目标；
- 当前行为树执行位置；
- 当前行动范围；
- 当前合法战场情报。

大模型人工智能保留：

- 当前已经下达的任务；
- 当前任务目标；
- 当前目标区域；
- 当前任务优先级；
- 当前控制对象；
- 当前已经获得的合法战场情报；
- 当前仍然有效的决策结果。

## 3.5 生产与建造信息

所有正在进行中的生产与建造保留：

- 当前生产项目；
- 当前建造项目；
- 当前完成进度；
- 当前生产队列；
- 当前资源占用；
- 当前剩余时间。

## 3.6 任务与关卡信息

战役与关卡保留：

- 当前任务目标；
- 当前任务进度；
- 当前已经完成的任务；
- 当前已经失败的任务；
- 当前已经触发的事件；
- 当前胜负目标；
- 当前战局时间；
- 当前已获得战场情报。

# 4. 恢复规则

玩家恢复游戏后：

**所有被冻结的系统从暂停时记录的原状态继续运行。**

统一恢复结果：

- 战局时间从暂停时刻继续；
- 单位从原位置继续；
- 当前移动从原路径与原进度继续；
- 当前攻击从原攻击阶段继续；
- 当前技能从原施放阶段继续；
- 冷却从原剩余时间继续；
- 持续效果从原剩余时间继续；
- 行为树人工智能从原任务与原执行位置继续；
- 大模型人工智能继续使用暂停前已经确认的任务与合法情报；
- 生产与建造从原进度继续；
- 战役任务从原任务进度继续；
- 战局事件从原计时位置继续。

# 5. 恢复后的重新判断

恢复后的第一轮更新使用当前保留状态进行正常规则判断。

需要重新判断的系统按照自身已有规则处理：

- 目标已经失效时，重新选择合法目标；
- 路径已经失效时，重新寻路；
- 单位状态已经影响当前命令时，重新判断当前命令；
- 行为树人工智能根据当前任务与当前合法信息继续判断；
- 大模型人工智能按照原有触发规则决定是否需要重新规划。

暂停本身不额外制造新的决策。

# 6. 暂停菜单

暂停期间提供：

- 继续游戏；
- 游戏设置；
- 重新开始当前战局；
- 退出当前战局。

继续游戏执行恢复规则。

重新开始重新创建当前战局。

退出当前战局结束本次战局流程。

# 7. 最终规则

暂停机制统一理解为：

**冻结当前运行现场。**

恢复机制统一理解为：

**从被冻结的运行现场继续。**

暂停时必须保留：

**单位状态 + 命令状态 + 战斗状态 + 人工智能状态 + 生产状态 + 任务状态 + 战局时间**

恢复时：

**所有仍然有效的内容从原进度继续，需要重新判断的内容按照各自系统原有规则重新判断。**
