# 策划文档_地图空间与导航规则

> 状态：待评审  
> 定义范围：地图通行区域、单位与区域匹配、区域连接、通行尺寸、可经过/可停留、动态导航状态、可达性。  
> 前置依赖：《策划文档_单位基础规则》。  
> 后续依赖：《策划文档_移动与位置规则》。  
> 不包含：单位避让、拥堵处理、多单位分布、编队、寻路算法、程序实现。

---

# 1. 通行区域

地图由若干通行区域组成。

每个通行区域定义：

- 区域类型；
- 允许哪些移动能力进入；
- 是否允许作为正常停留位置；
- 当前是否有效。

区域只描述地图本身的通行事实。

---

# 2. 单位移动能力与区域匹配

单位的移动能力由《策划文档_单位基础规则》定义。

导航只判断：

```text
单位移动能力
+
区域进入条件
↓
匹配
→ 可进入
```

“可进入”只表示单位具备使用该区域的资格。

---

# 3. 区域连接

两个区域之间只有存在有效连接时，才形成直接通行关系。

每个连接定义：

- 连接的两个区域；
- 单向 / 双向；
- 哪些移动能力可以使用；
- 当前是否开放；
- 通行尺寸要求。

连接决定：

> 单位能否从一个区域进入另一个区域。

---

# 4. 通行尺寸

区域或连接可以设置通行尺寸要求。

单位具有自身通行尺寸。

判定：

```text
单位通行尺寸
符合
区域 / 连接尺寸要求
↓
可以通过
```

通行尺寸用于表达：

- 小型单位可通过；
- 中型单位可通过；
- 大型单位可通过；
- 特大型单位可通过。

具体尺寸等级由《策划文档_单位基础规则》统一定义。

---

# 5. 可经过与可停留

区域需要分别定义：

```text
可经过
可停留
```

两者独立判断。

因此一个区域可以是：

| 可经过 | 可停留 | 结果 |
|---|---|---|
| 是 | 是 | 可正常通过并作为目标位置 |
| 是 | 否 | 可作为通行区域，不作为正常停止位置 |
| 否 | 否 | 当前不可用于该单位导航 |

是否可停留只描述地图导航事实。

具体单位最终停在哪里，由《策划文档_移动与位置规则》处理。

---

# 6. 动态导航状态

运行中的地图可以改变导航事实。

允许变化的导航状态包括：

- 区域开放 / 关闭；
- 区域进入条件改变；
- 区域可停留状态改变；
- 连接建立 / 移除；
- 连接开放 / 关闭；
- 连接使用条件改变；
- 通行尺寸要求改变。

具体表现可以是门、桥、地形变化、战役事件等。

导航规则只记录最终发生了哪一种导航状态变化。

---

# 7. 可达性

必须区分：

```text
可进入
≠
可达
```

目标可达需要同时满足：

```text
目标区域允许单位进入
+
目标区域允许当前目标所需的停留关系
+
当前位置到目标区域之间存在连续有效连接
+
单位满足沿途所有区域进入条件
+
单位满足沿途所有连接使用条件
+
单位满足沿途通行尺寸要求
=
可达
```

导航系统最终只输出：

```text
可达
或
不可达
```

# 8. 地图策划配置规范

## 通行区域

```text
区域类型：
允许移动能力：
可经过：
可停留：
当前状态：
```

依赖：

- `允许移动能力`：来自《策划文档_单位基础规则》；
- `当前状态`：可由地图或任务状态改变。

## 区域连接

```text
区域 A：
区域 B：
方向：
允许移动能力：
通行尺寸：
当前状态：
```

依赖：

- `允许移动能力`：来自《策划文档_单位基础规则》；
- `通行尺寸`：与单位通行尺寸规则匹配；
- `当前状态`：可由地图或任务状态改变。

# 9. 具体地图内容的规则映射

具体场景内容只用于表现导航规则。

| 场景表现 | 导航规则 |
|---|---|
| 墙 | 两侧区域之间无当前有效连接 |
| 门 | 可动态开启 / 关闭的连接 |
| 坡道 | 两个不同高度区域之间的地面连接 |
| 悬崖 | 普通地面单位缺少可用连接 |
| 桥 | 两个区域之间的连接 |
| 水域 | 具有特定移动能力要求的通行区域 |
| 狭窄通道 | 设置较高的通行尺寸限制 |

新增地图表现时，优先使用现有“区域 + 连接 + 条件 + 状态”组合表达。

---

# 10. 与移动规则的职责边界

《地图空间与导航规则》只负责：

```text
这里是什么通行区域
谁能进入
哪里可以经过
哪里可以停留
区域之间如何连接
谁能使用连接
通行尺寸是否满足
当前是否可达
```

《移动与位置规则》负责：

```text
单位具体去哪里
目标点不可用时如何调整
移动过程中如何处理阻挡
多个单位如何分布
什么时候算移动完成
```

- 友军 / 敌军拥堵处理；
- 多单位位置分配；
- 编队移动；
- 路径选择策略；
- 具体寻路算法；
- 导航网格等技术方案；
- 移动速度、加速度、转向；
- AI 如何选择移动路线；
- 地图编辑器程序实现。
