# 策划文档_地图空间与导航规则

> 状态：已完成  
> 本文定义当前 RTS 战役 Demo 必须具备的最小地图通行与导航规则。  
> 当前以现有程序的地面 / 空中移动域、导航网格、单位半径、避让和可达性为基础；复杂地图拓扑设计使用删除线保留。

---

# 1. 当前导航目标

当前 Demo 的导航只需要保证：

```text
单位拥有移动能力
↓
玩家 / AI 指定目标位置或目标实体
↓
导航系统判断目标是否可达
↓
可达
→ 沿当前导航路径移动

不可达
→ 返回不可达结果
```

导航系统负责保证单位可以在当前战役地图上稳定移动，不要求当前阶段建立复杂地图拓扑系统。

---

# 2. 当前移动域

当前程序使用基础移动域区分不同导航空间。

当前至少保留：

- 地面移动域；
- 空中移动域。

单位只能使用与自身移动域匹配的导航空间。

具体单位是否能够移动，由单位自身移动能力决定。

---

# 3. 导航网格与可达性

当前程序使用导航网格处理路径移动。

当前基础判定：

```text
目标位置存在可用导航路径
→ 可达

目标位置无法形成有效路径
→ 不可达
```

当前战役 Demo 只需要稳定区分“可以移动过去”和“当前无法到达”。

---

# 4. 单位半径

移动单位具有自身导航半径。

导航半径用于：

- 避免单位中心穿过不可通行区域；
- 参与单位之间的基础避让；
- 保证不同尺寸单位在当前导航网格上保持合理距离。

当前不建立“小型 / 中型 / 大型 / 特大型”四档策划尺寸系统。

---

# 5. 基础避让

RTS 最小可用移动必须保证多个单位不会长期完全重叠。

当前基础要求：

- 单位移动时启用基础避让；
- 多单位前往同一区域时能够形成不同最终位置；
- 单位短时拥堵后能够继续尝试移动；
- 单位长时间无法推进时能够进入卡死处理或最终失败流程。

复杂正式阵型不属于当前导航规则。

---

# 6. 动态阻挡

当前战役地图可以存在运行时阻挡对象。

导航系统需要处理：

- 当前静态不可通行区域；
- 当前动态障碍；
- 其他单位造成的局部避让；
- 当前路径变化后的重新导航。

战役事件如果改变地图可通行状态，只要求最终导航网格能够反映新的可达性。

---

# 7. 战术撤退

战术撤退仍然使用当前导航路径。

具备倒车能力的单位：

```text
指定撤退位置
→ 沿导航路径移动
→ 车体保持倒车撤退表现
```

不具备倒车能力的单位按当前正式命令规则退化为普通移动。

---

# 8. 不可达与卡死

当前必须区分：

- 正常到达；
- 当前不可达；
- 移动过程中卡死且无法恢复。

最终结果需要回传到正式单位命令状态。

```text
正常完成移动
→ 已到达

重新处理后仍无法抵达
→ 不可达
```

卡死处理属于执行层行为，不能让单位永久保持一个永远不会结束的移动命令。

---

# 9. 与移动规则的职责边界

《地图空间与导航规则》负责：

```text
单位使用哪个导航空间
当前位置到目标是否存在可用路径
基础避让
动态阻挡
不可达结果
```

《移动与位置规则》负责：

```text
单位收到什么移动命令
最终去哪里
多单位目标点如何分布
什么时候算移动完成
目标实体变化后如何继续移动
```

---

# 10. 当前 Demo 必须验收

必须保证：

1. 地面单位可以在当前地面导航网格中移动。
2. 空中单位可以使用自己的导航空间。
3. 可达目标可以正常到达。
4. 不可达目标不会让单位永久卡住。
5. 多单位移动时不会长期完全重叠。
6. 基础避让和卡死处理能够工作。
7. 战术撤退能够沿当前导航路径执行。
8. 导航终态能够正确反馈给正式单位命令。

---

# 11. 当前阶段不做的复杂地图导航设计

以下内容不是当前几个战役 Demo 的 RTS 最小必备能力，保留历史设计但不作为当前程序目标：

- ~~把整张地图抽象为独立“通行区域”实体。~~
- ~~每个区域配置单独的进入条件。~~
- ~~区域之间建立显式单向 / 双向连接图。~~
- ~~连接单独配置允许哪些移动能力使用。~~
- ~~小型 / 中型 / 大型 / 特大型四档通行尺寸。~~
- ~~区域和连接分别配置通行尺寸要求。~~
- ~~“可经过”和“可停留”作为独立策划属性。~~
- ~~区域开放 / 关闭、连接建立 / 移除、连接条件变化的完整拓扑状态机。~~
- ~~用区域连接专门表达坡道、悬崖、桥梁、水域。~~
- ~~不同高度区域之间建立正式高差连接体系。~~
- ~~为复杂高差地形改造点击落点、框选、小地图和导航。~~
- ~~按每个控制方维护独立“已知通行地图”并进行认知寻路。~~
- ~~未探索阻挡不参与寻路、发现后再重新规划的完整探索寻路系统。~~
- ~~最大探路范围。~~

这些能力以后真正需要复杂地图、多人阵营或高级侦察玩法时再单独立项。

---

# 12. 当前原则

当前战役 Demo 的导航目标是：

**能走、能避让、能到达、不能到达时有明确结果。**

不为了几个战役提前建设复杂地图拓扑和认知寻路系统。
