# 策划文档_UI交互说明

> 状态：正式版 / 冻结  
> 本文定义：Direct Control、Unit AI Command、System AI Command 与语音输入在同一套 RTS HUD 中的显示、切换、反馈、异常与边界。  
> 本文不定义：AI 内部决策算法、单位寻路、伤害公式、语音识别技术实现、程序节点与类结构。  
> 前置规则：《策划文档_基础交互逻辑文档》。

---

## 1. UI 总体原则

游戏始终使用同一套 RTS HUD，不因为 AI 模式切换到新的页面。

一句话核心规则：

> **Direct / Unit AI / System AI 只改变当前操作层和 HUD 表达，不切换到新的游戏页面。**

UI 主要分为：

| 区域 | 作用 |
|---|---|
| 战场区域 | 显示实时战场 |
| 小地图 | 显示战场位置与单位分布 |
| 当前对象区 | 显示当前选中单位 / 小队 / 系统 AI 状态 |
| QWER 操作区 | 根据当前控制模式显示普通技能或 AI 指令 |
| AI 副官区 | 显示 AI 状态、必要提示和反馈 |
| 语音提示层 | 按住 `V` 时临时显示语音识别与指令结果 |

### UI 固定原则

- 战场始终可见。
- QWER 的屏幕位置始终固定，只改变内容。
- Direct / Unit AI / System AI 必须一眼可区分。
- 当前正在生效的 AI 行为必须能够被玩家看到。
- 临时提示不能取代常驻状态显示。
- 操作失败默认不改变当前控制模式。

---

## 2. Direct Control

默认状态。

核心规则：

> **选中任意己方单位 / 小队后，默认操作层始终是 Direct Control。**

选择己方单位 / 小队只改变当前控制对象，不会自动进入 Unit AI Command。
如需进入 Unit AI Command，必须由玩家再次明确按 `Tab`。

### 当前对象区

选中己方单位 / 小队时显示：

- 当前单位 / 小队名称
- 头像
- 生命、能量等基础状态
- 单位基础信息
- 如果该单位仍有 AI 行为正在生效，可显示轻量 AI 状态

例如：

`AI：主动进攻`

### QWER 操作区

显示当前单位 / 英雄的普通技能：

`Q / W / E / R = 普通技能`

UI 以传统 RTS / MOBA 风格显示。

### 无选择状态

当前没有己方单位 / 小队时：

- 当前对象区显示“未选择单位”或保持空对象状态；
- 不显示 Unit AI 操作内容；
- 单位专属 QWER 不应表现为当前可执行状态。

具体视觉形式由 UI 视觉稿决定，但不能让玩家误以为仍在控制已经失效的单位。

---

## 3. Unit AI Command

按 `Tab` 进入。

进入前提：

> 当前必须存在可控制的己方单位 / 小队。

### 当前对象区

继续显示当前选中的单位 / 小队，并增加：

- `UNIT AI` 标识
- 当前 AI 行为

例如：

`当前 AI：主动进攻`

### QWER 操作区

普通技能切换为当前兵种对应的 AI 行为。

例如普通作战单位：

| Q | W | E | R |
|---|---|---|---|
| 自主 | 进攻 | 稳守 | 保全 |

当前启用的行为需要明显高亮。

不同兵种的具体文字可以变化，但 QWER 的位置保持不变。

### 玩家反馈

进入 Unit AI 后，至少需要同时满足：

1. `UNIT AI` 状态可见；
2. QWER 文案已经从普通技能切换为 AI 行为；
3. 当前已生效的 AI 行为有明显选中 / 高亮状态。

不能只依靠颜色变化表达“当前已经进入 Unit AI”。

---

## 4. 退出 Unit AI Command

再次按 `Tab`：

- QWER 恢复普通技能；
- UI 返回 Direct Control；
- 已经设置的单位 AI 行为不会因此取消。

如果单位仍由 AI 行动，当前对象区保留轻量提示：

`AI：主动进攻`

核心原则：

> **`Tab` 切换的是玩家当前操作层，不等于打开 / 关闭单位 AI。**

---

## 5. System AI Command

按 `` ` `` 进入。

System AI 不与 Unit AI 叠加。

进入后，当前操作对象从“具体单位 / 小队”切换为“整个战场 AI”。

### 当前对象区

改为显示：

- `战场 AI 指挥`
- `SYSTEM AI`
- 当前系统级 AI 姿态

例如：

`当前姿态：全面进攻`

### QWER 操作区

| Q | W | E | R |
|---|---|---|---|
| 自主调度 | 全面进攻 | 稳固防线 | 收缩保全 |

当前启用的系统行为需要明显高亮。

### 玩家反馈

进入 System AI 后：

- `SYSTEM AI` 必须明显可见；
- 当前对象区不再把某一个单位表现为“当前操作对象”；
- QWER 必须明确切换为系统级命令；
- 原本选中的单位可以保留为战场信息，但不能造成“System AI 只作用于该单位”的误解。

---

## 6. 退出 System AI Command

System AI 不使用 `` ` `` 作为退出键。

`` ` `` 是 **System AI 的单向进入键**：

- 当前不在 System AI 时，按 `` ` `` 进入 System AI；
- 当前已经处于 System AI 时，再次按 `` ` `` 不退出，状态保持不变；
- 连续按、误触或双击都不能关闭 System AI。

System AI 的正常退出方式：

- 玩家选择任意己方单位 / 小队，把操作焦点明确拉回具体对象。

选择己方单位后：

- 自动退出 System AI；
- 当前对象区重新显示该单位；
- QWER 返回该单位的 Direct Control 普通技能。

不弹确认框。

核心原则：

> **选择具体己方单位，代表玩家把操作焦点从全局重新拉回局部。**

### 查看敌方单位

在 System AI 中查看 / 选中敌方单位时，不视为重新取得己方单位控制权。

因此默认：

- System AI 保持；
- 当前系统级 QWER 不变；
- 敌方信息只作为查看信息显示。

---

## 7. 不同兵种的 Unit AI 显示

QWER 位置固定，文字根据兵种变化。

| 单位类型 | Q | W | E | R |
|---|---|---|---|---|
| 步兵 / 突击 | 自主行动 | 主动进攻 | 防守警戒 | 脱离撤退 |
| 侦察 | 自主侦察 | 主动搜索 | 隐蔽监视 | 脱离撤退 |
| 坦克 / 重装 | 自主作战 | 突击推进 | 阵地防御 | 脱离战斗 |
| 火炮 | 自主支援 | 主动轰击 | 火力警戒 | 转移阵地 |
| 医疗 / 支援 | 自主支援 | 主动跟进 | 后方保障 | 安全撤离 |
| 建筑 / 固定设施 | 自主运行 | 主动强化 | 稳态运行 | 保全 |

本文只定义 HUD 如何显示这些行为，不重新定义各行为的内部逻辑。

## 8. 语音 UI

默认语音键：`V`

按住 `V` 时，在战场 HUD 上方显示临时语音提示：

`🎙 岚正在听……`

松开后，短暂显示 AI 对指令作用范围和行为的理解。

单位级示例：

`侦察队 → 主动搜索`

系统级示例：

`SYSTEM AI → 稳固防线`

语音提示结束后自动消失，不强制切换当前 UI 模式。

### 语音异常反馈

如果语音没有形成可执行指令：

| 情况 | UI 处理 |
|---|---|
| 未识别到有效内容 | 显示短提示“未识别到有效指令” |
| 无法判断作用对象 / 范围 | 显示“请明确作用对象或范围” |
| 指令对象已经失效 | 显示“目标已失效” |
| 系统拒绝执行 | 显示简短原因，不切换当前模式 |

语音失败不能自动扩大控制范围，也不能为了“完成指令”擅自切换 Unit AI / System AI。

---

## 9. 三种核心 UI 状态

| 状态 | 当前对象区 | QWER |
|---|---|---|
| Direct Control | 当前单位 / 小队 | 普通技能 |
| Unit AI Command | 当前单位 / 小队 + 当前 AI 行为 | 当前兵种 AI QWER |
| System AI Command | 战场 AI + 当前系统姿态 | 系统级 AI QWER |

### 状态切换表

| 当前状态 | 玩家操作 | 结果 |
|---|---|---|
| Direct Control | `Tab`，且存在可控制己方对象 | Unit AI Command |
| Unit AI Command | `Tab` | Direct Control |
| Direct Control | `` ` `` | System AI Command |
| Unit AI Command | `` ` `` | 进入 System AI；Unit AI 操作层退出，但单位已设 AI 行为不因此取消 |
| System AI Command | `` ` `` | 保持 System AI，不退出 |
| System AI Command | 选择己方单位 / 小队 | 自动回到该对象 Direct Control |
| System AI Command | 查看敌方单位 | 保持 System AI |

---

## 10. 异常与边界规则

| 异常情况 | 游戏处理 | 玩家反馈 | 原状态 |
|---|---|---|---|
| 无己方选择对象时按 `Tab` | 不进入 Unit AI | 轻量提示“请先选择单位” | 保持 |
| 当前选中的是敌方对象时按 `Tab` | 不进入 Unit AI | 轻量提示“当前对象不可控制” | 保持 |
| Unit AI 中当前单位死亡 / 销毁 / 离场 | 清除失效对象，退出该对象 Unit AI 操作层 | 当前对象区切换为无选择状态 | 回到无选择的 Direct 状态 |
| System AI 中选择己方对象 | 自动退出 System AI | HUD 立即切回该对象 Direct | Direct Control |
| System AI 中按 `Tab` | 不叠加 Unit AI | 提示“请先选择己方单位”或无效反馈 | 保持 System AI |
| 当前 QWER 指令不可执行 | 不执行 | 对应按钮灰化或短提示原因 | 保持 |
| 连续快速切换模式 | 每次严格按当前有效状态切换 | UI 只显示最终合法状态 | 不产生第三种中间状态 |
| AI 指令执行失败 | 不自动切换模式 | AI 副官区 / 临时提示显示简短原因 | 保持 |
| 当前对象信息失效但 UI 尚未刷新 | 下一次状态刷新必须清除失效对象 | 不继续显示为可操作对象 | 回退到合法状态 |

## 11. 冲突与优先级

当多个 UI / 输入规则同时成立时，默认优先级：

```text
明确的玩家模式切换
>
当前合法控制对象
>
当前控制层级
>
AI 自动行为显示
>
默认 UI 状态
```

具体规则：

- `` ` `` 只负责进入 System AI；已经处于 System AI 时再次按下不会退出；
- System AI 的退出必须来自明确的己方单位 / 小队选择；
- 选择己方单位时，局部控制焦点优先，自动退出 System AI；
- Unit AI 与 System AI 不同时显示为“当前操作层”；
- 语音只显示其作用范围和执行结果，不因为语音内容自动改写玩家当前 HUD 模式；
- 指令失败时，默认保持当前合法状态，不跳到其他模式。

---

## 12. UI 关键要求

- 不打开额外页面，始终保持战场可见。
- Direct / Unit AI / System AI 必须一眼可区分。
- QWER 的位置始终固定。
- Unit AI 下，根据兵种改变 QWER 文案。
- 当前正在生效的 AI 行为必须高亮。
- System AI 必须明确显示 `SYSTEM AI`，避免误以为仍在控制某个单位。
- 语音只使用临时浮层，不占用常驻 HUD。
- 无效操作不能让 UI 进入一个没有对应游戏状态的“假模式”。
- 失效对象不能继续显示为当前可操作对象。
- 高频小错误使用轻提示，不使用阻断式弹窗。

---

## 13. 当前明确不包含

本文暂不定义：

- 混合兵种多选时 Unit AI QWER 的最终文案；
- AI 指令执行中的完整进度 UI；
- AI 内部失败原因分类；
- 语音识别技术与网络异常；
- 技能冷却、资源不足等普通战斗 UI 规则；
- Targeting 模式下的鼠标光标和目标确认；
- 具体动画时长、颜色、字号和视觉资源。

这些内容应在对应专项文档中定义。
