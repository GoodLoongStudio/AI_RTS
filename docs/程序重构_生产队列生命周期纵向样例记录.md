## 1. 实现范围

本切片把单位生产的权威状态从 `ProductionQueue.gd` 迁移到纯 C# `ProductionService`。Human、规则 AI 和未来 Agent 共用相同的入队、资格、容量、扣款、取消和部署边界。

已实现：

- 稳定 `ProductionItemId`、`ProductionDefinitionId` 和只读快照；
- `Queued → Producing → AwaitingDeployment → Completed` 主流程；
- `Cancelled` 与 `ProducerLost` 两类终态；
- 每 Producer 一条顺序生产线，统一容量 5；
- 按物理 Tick 推进的整数工作量，重复 Tick 不重复推进；
- 多资源原子扣款、主动取消全额幂等退款、建筑失效不退款；
- 可信产品目录负责成本、工期与允许生产建筑，调用者不能自报低价或缩短工期；
- 有界出生点搜索、部署受阻保留队首、成功后只生成一次；
- Legacy HUD、开始/完成 Signal、资源不足提示和集结点行为的迁移期兼容；
- 删除规则 AI 的 `ignore_limit` 容量绕过入口。

## 2. 明确不实现

当前 Legacy 生产系统不存在暂停。本轮不新增暂停状态、暂停命令、顺序调整或相关 UI。未来采用红警式还是群星式管理方式，由策划与 UI 评审后另开需求。

渐进支付、资源分配、正式集结点命令、强类型外部数值配置、生产建筑占领/出售，以及导航和局部避障优化也不属于本切片。

## 3. 分层与兼容边界

- Domain：保存生产定义、项目状态和快照，不引用 Godot；
- Application：校验生产资格、所有权、容量与资源，推进状态机并发布权威事件；
- Godot Adapter：映射当前四种 PackedScene、注册生产建筑、寻找出生位置并生成单位；
- Legacy GDScript：`ProductionQueue.gd` 仅保留 HUD 视图、菜单入口和旧 Signal 兼容，不再自行计时或改余额。

当前产品目录仍在 Godot Adapter 内硬编码，以保持与既有 Demo 数值一致；它会在 `ECO-007` 迁入带版本和校验的强类型配置。
