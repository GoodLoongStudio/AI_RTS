## 3. 建造 / 碰撞 / 导航 / 出生点使用的实际公式

① 相邻可建（GodotStructurePlacementWorldPort.AdjacentToOwnStructure）

~~~text
PlanarDistance(candidate_center, own_unit) <= candidate_radius + Radius(own_unit) + EdgeClearanceMeters(0.75)
~~~

② 脚印重叠拒绝（同文件 Overlaps / Occupied）

~~~text
PlanarDistance(candidate_center, existing) <= candidate_radius + Radius(existing)  → issue = Occupied
另有：界内 center ± radius ∈ [0, mapSize]；水面遮断；地形可建采样 SampleCircle(center, radius × TerrainProbeRadiusScale)，
采样点若落在障碍 carve 洞内视为被遮挡。
~~~

③ 导航 carve（本次修复核心，Godot 4.7.1 实测）

~~~text
洞半径 = 障碍 vertices 环的世界外缘 × 障碍 global scale + navmesh.agent_radius(2.8)
        （radius 字段与 CollisionShape3D 均不参与；vertices 由 MovementObstacle._sync_carve_vertices()
          按 radius / global_scale 生成 16 边形）
~~~

④ 出生点（UnitPlacementUtils.find_valid_position_radially_yet_skip_starting_radius）

~~~text
起始环距离 = starting_radius + produced_radius + spacing            （starting_radius > 0）
第 n 环距离 = 起始环距离 + produced_radius × 0.5 × n
环上角步长 = asin((produced_radius + spacing) / 环距离)
合法性     = 不在任何既有单位 footprint 内（dist <= existing.radius + radius 即非法）+ 导航面可走（含 carve 遮挡）
兜底       = 起点前方一点，必须再过一次同一套校验；不合法返回 Vector3.INF（上层保留待部署/重试）
~~~

实测校验点：车辆工厂（6.65）旁生成矿车，落点距建筑 10.98m / 8.77m，理论下界 = 6.65 + 2.0 + 0.1 = 8.75m ✓

⑤ 贴合/采集（UnitMovementUtils.units_adhere，本次修复）

~~~text
阈值 = max(a.radius + b.radius + 0.5,  (b.radius + navmesh.agent_radius) + 0.5)   ← 仅当 b 会 carve
~~~

⑥ 相机开局档位（IsometricCamera3D）

~~~text
projection = 正交；rotation.x = −45°；size = 42.5；离地高度 = 60m
大图：size_max >= 0.48 × 短边；开局 size = min(size_max, max(42.5, 0.346 × 短边))
~~~
