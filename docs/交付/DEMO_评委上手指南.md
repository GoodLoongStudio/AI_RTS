# DEMO 上手指南（给评委）

> 随包交付用；纯文本版见导出目录里的 `使用说明.txt`（内容相同）。

## 1. 运行要求

| 项 | 要求 |
|---|---|
| 系统 | Windows 10 / 11（64 位） |
| 显卡 | 独立显卡或较新的集成显卡，需支持 Vulkan（近 5 年的卡基本都行） |
| 内存 | 8GB 及以上 |
| 磁盘 | 约 1GB 空闲（单文件 exe，无需安装） |

第一次启动需要 10~30 秒加载资源，属正常现象。

## 2. 启动

1. 双击 `Open RTS.exe`（单文件，双击即玩，**不需要安装任何东西**，也不需要装 Godot/.NET）。
2. 若 Windows 弹出「Windows 已保护你的电脑」（SmartScreen 蓝框）：
   点 **更多信息 → 仍要运行**。
   （这是对"未签名程序"的常规提示；本 demo 未购买代码签名证书。）
3. 若杀毒软件拦截：加入信任/白名单后重试。

## 3. 三分钟上手

**开一局**：主菜单 →「单人 / 离线」→ 选地图（如 `PlainAndSimple`）与对手难度 → 开始。

**基本操作**

| 操作 | 作用 |
|---|---|
| 鼠标左键 | 选中单位；按住拖拽 = 框选一队单位；点小地图 = 跳转视角 |
| 鼠标右键 | 下达命令：移动 / 攻击敌人 / 采集资源 / 建造放置 |
| W A S D | 平移镜头 |
| 鼠标滚轮 | 缩放 |
| 鼠标中键拖拽 | 平移镜头（另一种方式） |
| Shift + 左键 | 加选 |
| Ctrl + 1~9 | 把当前选中的单位编为第 N 队 |
| 数字键 1~9 | 选中对应编队 |
| R | 旋转待放置的建筑 |
| ESC | 取消 / 逐级返回 |
| F10 | 对局内菜单（继续 / 设置 / 退出） |

**经济与建造**

1. 选中「工人」→ 右键点地图上的**资源矿**（A 矿）→ 自动往返采集。
2. 选中「指挥中心」→ 侧栏「生产」页 → 造工人。
3. 选中工人 → 侧栏切到「建筑」页 → 选建筑 → 在空地上放置（`R` 旋转，`ESC` 取消）。

**战斗**

选中战斗单位 → 右键点敌人或敌方建筑。地图有战争迷雾，需要先派单位侦察。

## 4. 这个 demo 看什么

- **程序化地图**：已内置多张自动生成的地图（选图页可见）。
- **电脑对手 AI**：三档难度（简单 / 普通 / 困难），会扩张、侦查、编队进攻与撤退。
- **AI 副官（岚）**：游戏内的「副官」面板可以让 AI 接管你的部队——
  ⚠ **本 demo 包为纯离线包，副官需要额外的本地 AI 环境（Python + 本地模型），未随包提供**；
  面板可能显示"尚未启动"，属预期。副官效果请以现场演示 / 录屏为准。

## 5. 已知限制（提前说明，避免误判）

- 副官面板"尚未启动"= 正常（本机没装 AI 环境）。
- 「在线」入口需要自建服务器，本 demo 以单机体验为主。
- 首次进入对局会有一次地图烘焙（几秒），之后同地图秒进。

## 6. 常见问题

| 现象 | 处理 |
|---|---|
| 双击后没反应 / 一闪而过 | 显卡驱动过旧或不支持 Vulkan；更新显卡驱动后重试 |
| 黑屏只有小地图 | 显卡驱动问题，同上；或把 exe 放到英文路径下再试 |
| 卡顿 | 关闭其他占用显存的程序（浏览器视频、其他游戏） |
| 想改画质 | 对局内 F10 → 设置 |
| 被 SmartScreen / 杀软拦 | 见第 2 节 |
