# 更新与发布流程（开发者用）

> 目标：每次游戏更新后，用 **约 12 分钟** 把新版本发到评委的下载页。
> 原理：AI 运行环境（Python + Ollama + 模型，约 9GB，**几乎不变**）与游戏本体（556MB，**每次都变**）分开打包，更新时只传游戏包。

## 一、日常更新：改了游戏代码（约 12 分钟）

### 1.1 关掉正在跑的游戏
游戏 exe 被占用会导致导出失败（报「重命名临时文件失败」）。

### 1.2 导出新版 exe（约 8 分钟）
```powershell
powershell -ExecutionPolicy Bypass -File g:\AIRTS\AI_RTS\tools\build_windows.ps1 -Out build\AI_RTS_Demo.exe
```
- 结束标志：输出里出现 `BUILD OK`
- ⚠ 若 Godot 进程卡住不退出但 exe 时间戳已更新，可直接 `Stop-Process` 掉它，exe 是好的

### 1.3 打游戏包（约 1 分钟）
```powershell
powershell -ExecutionPolicy Bypass -File g:\AIRTS\AI_RTS\tools\release\pack.ps1
```
- 产物在 `G:\AIRTS\release_v4\`：
  - `AI_RTS_Game_v0.4.zip`（游戏包，**每次更新就传这个**）
  - `AI_RTS_Adjutant_Runtime.7z.001~.004`（AI 环境包，**不用重传**）
- 💡 只想打游戏包时，可以把脚本里 `[B]` 那段注释掉，10 秒就完

### 1.4 上传游戏包（约 3 分钟）
```powershell
$env:GH_TOKEN = "<你的token>"
python g:\AIRTS\AI_RTS\tools\release\upload.py G:\AIRTS\release_v4 --only AI_RTS_Game
```
- **已存在且大小一致的资产会自动跳过**，中断了重跑即可，不用重传
- ⚠ token 用完到 https://github.com/settings/tokens 撤销

### 1.5 （可选）更新 Release 正文
```powershell
$env:GH_TOKEN = "<你的token>"
python g:\AIRTS\AI_RTS\tools\release\update_body.py G:\AIRTS\release_v4\RELEASE_NOTES_v2.md
```

## 三、AI 环境变更（罕见，约 45 分钟）

适用：升级 Ollama、更换/增加模型、改 Python 依赖。

1. 修改 `build\adjutant_runtime\` 下的对应内容（ollama / models / python）
2. 重跑 `pack.ps1` 的 `[B]` 段（会重新生成 4 卷）
3. 上传时**不加** `--only`（B 包也要传）：
```powershell
python g:\AIRTS\AI_RTS\tools\release\upload.py G:\AIRTS\release_v4
```
4. 上传完检查 `00-READ-ME-FIRST.txt` 还在（清资产脚本会删它，需要重新上传）

## 五、踩过的坑（务必看）

1. **导出前关游戏** —— exe 被占用会导出失败
2. **别同时开两个导出** —— 会写出损坏的 PCK
3. **上传中断没关系** —— 重跑自动跳过已传完的资产（按大小比对）
4. **`.ps1` 脚本一律纯 ASCII** —— PowerShell 5.1 按 GBK 读 UTF-8 脚本，中文会变成乱码导致语法错误
5. **cmd 里调 PowerShell 时 `$_` 会被吞** —— 检查文件用 `Select-Object Name, Length`，别用 `$_` 表达式
6. **`re.subn` 的替换串含反斜杠会被当转义** —— 用 `lambda m: repl` 或纯字符串替换
7. **GitHub 上传中文名资产** —— 必须显式 `urlencode(..., encoding="utf-8")`，否则名字会损坏；保险起见资产名用英文
8. **GitHub PATCH release 必须用 release id** —— 用 tag 会 404
9. **打包用目录联接（junction）可免复制 9GB** —— `mklink /J <stage>\AI_RTS_Demo <build>`，7-Zip 正常跟随
10. **清资产脚本会把 `00-READ-ME-FIRST.txt` 一起删** —— 重新上传或加 `--keep`
11. **新版本启动更慢（含模型预热）** —— 自动化点击前先截图确认已到主菜单，别按老时间盲点
12. **直接双击 exe 不会自动起副官** —— 需 `adjutant_local.cfg` 里有 `auto_takeover=true`（启动脚本会写）；游戏本体已新增 `AdjutantModelService` 自动保障模型服务，双保险
