# AI 副官双层改造

日期：2026-09-07。状态：设计与交接完成，功能尚未实现，线上部署未核实。

## 决策

先用两路外接模型 API：战略模型制定阶段计划，战术模型按事件提出短命令。游戏权威执行层验证并执行命令。DGX3 后续仅替换战术推理提供方，本轮不接入。

第一阶段先实现动态规则、足够的战术观测、统一副官命令入口及确定性验证，交由负责人审查；第二阶段再接真实双模型、中文界面和实战评估。第一阶段不得以模拟模型测试宣称实际双模型已完成。

项目已有 IGameBalanceCatalog、Godot 资产映射、CommandRuntime 和 UnitCommandGateway，必须优先复用。不要建立副官专属的第二套兵种平衡数据、资源账本或物理逻辑。

用户未来三天会大量修改单位和建筑。先稳定契约，内容数值从当前对局加载的 Catalog 获取；新增机制需要显式能力支持，不能宣称所有新机制自动适配。

## 当前证据边界

本地已检查：v5 服务脚本为单 Hermes 会话；技能要求 lite 状态，但 lite 缺少战术所需单位坐标和血量；UI 通过日志关键词拼接动作与结果。现有测试汇总不是实际模型闭环验收。服务器配置及线上版本未在本轮核验。

文档内的新字段与入口是拟议契约，不表示现有接口已经支持。实现者须映射实际类型，记录兼容偏差，不可把计划文字当作运行结果。
