## 一、定位与管线

为 `AI_RTS`（Godot 4.7 自研 RTS）生成**确定性、可验证、有战术结构**的 2 人对战地图。
不做"好看的噪声地形"，产出**抉择结构**——哪里能走、哪里争夺、为什么要在那里打。

```
P1 战术骨架（skeleton.gd _build_2p）
    出生点对 + 进攻轴线（主/边/水）+ 台地团意图 + 资源 10 + 岛椭圆意图
        ↓
P2 分区拼图（zones.gd）
    类型场（环海/湾楔/基地/台地团）→ 独立战术分区（9 个连续大区）→ 坡道槽位
        ↓
P3 实体化（heightfield.gd _build_2p_from_zones）
    P2 折线类型场驱动高度场（SDF + 波对有机边缘 + 海滩带 + 坡道 carve + 孤离水回填）
    → 语义 4 通道（class/height/marks/passability）+ 14_mapview 真地图风总览
        ↓
P4 材质（image2 可选精修，见 §八）
        ↓
P5 3D 网格与渲染（未做）
```

主运行器：`scripts/run_hf.gd`（headless 可跑）。

## 二、硬契约（不可违背）

| 项 | 值 | 依据 |
|---|---|---|
| 地图尺寸 | 96×48 世界单位（2p） | 骨架拍板 |
| 栅格 | 类型场 480×240（0.2/格）；高度场 1920×960（0.05/格） | zones/heightfield |
| 层高 | 水 -2.4 / 平地 0.6 / 台地 3.6（层差 3.0，max_y 5.0 内） | AI_RTS 烘焙约束 |
| 坡道 | 30°、宽 5.0、长 5.196（层差反推），限坡侧肩 2.8 | 拍板沿用 |
| 对称 | 180° 点对称（每层都守；镜像强制收尾是保险，天然对称是设计） | 公平性 |
| 出生净空 | ≥3.0（基地盘强制 + 断言双保） | 拍板 |
| 无桥涵 | 水体之间不放陆桥；2p 无内湖（孤离水一律回填） | 拍板 |
| 导航约束 | agent_radius 0.9 / cell_size 0.3 / agent_max_climb 0.0 / 坡度自检上限 45° | AI_RTS |
| 确定性 | 同 seed 输出位级一致；失败响铃退出，禁止静默 | 项目文化 |

## 三、P1 战术骨架

- **出生点对**：左半区验收采样（岛内 er<0.9），点对称补出；基地盘半径 7~9。
- **进攻轴线**（`routes`，带 `corridor_w`）：
  - 主轴 1：穿中央争夺区（via = 中心 ± 偏移对），走廊宽 7~8
  - 边路 2：上/下绕行（via 钉在岛肩），走廊宽 6~7
  - 水路 1：环海两栖巡逻点 4（供滩头槽位投影）
- **台地团意图**（`region_intents.plateau_blobs`）：中央争夺团 r9~11 + 侧翼团 1 对 r6~8
  （96 次采样：岛边 8 向端点 er<0.985、避出生盘；失败兜底必保 1 对——战术高台不可缺）。
- **资源 10**：私有 3×2（2 近矿 + 1 天然二矿，朝中场）+ 高台矿对（中央团内）+ 开阔矿对。
- **岛椭圆意图**（`region_intents.ring`）：超椭圆 a41~45 / b17~21 / p2.2~3.0。
- **出图**：`01_skeleton.png`（点位+意图盘）、`02_routes.png`（轴线纯线+箭头+咽喉红斜十字+登陆绿圈；
  **不画走廊带**，走廊宽数据只在 meta/生成逻辑里）。

## 四、P2 分区拼图

**类型场先行**（480×240）：环海超椭圆 + 偶次谐波（a2/a4 任意相位）+ 湾楔 2~4 对（凹，
amp 0.15~0.30）+ 海岬 1~2 对（凸，负 amp，避开出生方向与湾楔）→ 台地团（偶次调制，
对称对共享参数）→ 基地盘强制平地。进攻轴线和资源点不改写类型场，避免胶囊切口、资源圆坑和
孤立台地传导成额外 3D 几何；小于坡道承载尺度的地形块/闭合口袋（400 格）直接并入相邻主地形。
水域占比自校准至 ~0.46（允许 0.40~0.60），确定性重试 ≤6。

**功能分区**（展示层，不参与高度场/3D；与三层地形类型完全解耦）：

| 功能编号 | 区块 | 数量 |
|---|---|---|
| 3/4 | 红方本阵 / 蓝方本阵 | 2 |
| 5 | 中央争夺区 | 1 |
| 6/7 | 红方前沿 / 蓝方前沿 | 2 |
| 8/9 | 北 / 南侧机动翼 | 2 |
| 10/11 | 北 / 南侧咽喉区 | 2 |

全图 **9 块战术区**（Z10 断言）。水域、平地、台地只是 `type_field` 的三层高度类型，
不进入功能分区，也不在 `03_zones.png` 里作为独立色块插入其它区域。功能场只分割可玩陆域，
水域以低对比度无语义底色保留地图范围，沿 P1 主轴和上下边路生成直线/折线边界；
P2 不预先使用正弦扭曲、圆形距离场或嵌套地形块。`03_zones.png` 只画基地、接近、中央争夺、
北/南侧机动翼和北/南侧咽喉区五类战术语义、细边界和紧凑图例。

各区职责：本阵负责出生、初始经济和防守纵深；前沿是从本阵进入中央争夺区的第一接触带，
承接扩张与集结；中央争夺区承接 P1 标出的主轴、中央资源和高价值交战；侧机动翼对应 P1
上下边路，是较长但更安全的绕行与登陆方向；侧咽喉区是边路与主路线的转换节点，负责控制
进入中央的通行权。高台、水域、低地仍是独立的三层高度类型，不承担上述功能区命名。
槽位、轴线、资源和出生点留在 P1/P3 调试通道，正式 P2 图不叠加。

**坡道槽位**：台地↔平地边界提名——选团外缘（距质心最远前 25%）中距轴线最近者，
避矿（5.5 单位）、上台预检（-dir 3 单位内连续台地）、下坡预检（dir 6 单位内连续平地，防跨海）；
大团（≥8000 格）2 槽。
陆坡槽位另有两条硬约束（防 proper 剖面互相覆盖 / 被镜像抹除，A6 根因）：
- **中心最小间距 8.0 单位**（`MIN_RAMP_SPACING`）：proper 5.0×5.196 剖面，两坡道中心 <7.2 会重叠互相覆盖剖面。
- **拒绝跨点对称中心线 y=24**（`_ramp_crosses_center`）：坡道实体落在源半场/镜像半场分界时，下半截会被末尾镜像循环抹掉。
滩头槽 = 水路巡逻点投影最近岸格，窄湾避让（射程 6 单位内必须全是水，防堤坝切水），总数 ≤8。

## 五、P3 实体化

- **高度场**：类型场 → 水/台地边界双向 Chamfer SDF（格距×0.2 转世界单位）→ 逐像素剖面：
  - 海岸：全海岸 30° 缓坡海滩带（宽 5.196，beach 类）
  - 台地边缘：崖过渡（宽 1.6 ≈62°）
- **有机化**：P2 的直线/折线边界进入高度场后，再用 cos 平面波对位移（波长 6~14 单位、
  幅度 ≤0.22/波、无相位——q→-q 不变 → 点对称）生成连续复杂边缘
- **坡道**：槽位高端锚定真实台地顶（沿 -dir 搜索 h≥3.3，最长 10 单位）+ 显式层高 3.6→0.6 构造；
  滩头坡道射线锚定（`_shore_top`）；`_carve2` 复用（水下段归水类，防堤坝）
- **孤离水回填**：最终场四角洪泛，主分量外的水回填平地（2p 无内湖）
- **资源点**：只做位置合法性校验和装饰标记，不在类型场或高度场打圆形洞、不制造资源环形悬崖；
  台地实体化后对每个资源点打**平地口袋**（`_punch_pocket`，r=2.4 / edge=1.2）——按当前高度归整到
  L0=0.6 或 L1=3.6，把落在崖过渡带/碎边上的资源点吸附到就近整层（A10 根因）
- **镜像强制**：收尾复制上半场（保险层）；镜像源半场阈值 = `W2_H*0.5`（=24.0），
  下半场陆坡槽位（y≥24）先点镜像到上半场、方向取反再 carve（否则被镜像循环抹掉）。
- **出图**：语义 4 通道（`10_class`/`11_height`/`12_marks`/`13_passability`）+
  `14_mapview.png` 真地图风总览（类型着色、浮雕梯度光照、崖线粗线 2px、坡道阶梯纹、台地顶等高线）。

- **生成侧**：`scripts/verify/zone_check_2p.gd`（22 条）——Z1 zones 成功 / Z2 水占比 0.35~0.65 /
  Z3 陆连通（双出生+10 资源）/ Z4 水连通 / Z5 出生净空+低地 / Z6 资源归属+高台矿 /
  Z7 坡道台≥1、滩头≤8、滩头入水 / Z8 点对称 ≥0.98 / Z9 边界尺度 L1/L32 ∈[20,80] /

  Z12 无微小功能分区 / Z13 无微小地形块或闭合圆坑
- **产物侧**：`scripts/verify/hf_check.gd`（17 条，校验交付 PNG）——尺寸/色板/对称/平台/
  崖壁垂直/坡道 30°/水体数/陆连通 0.95+/出生资源/分形签名/值域/坡道数区间/结构清单/点位合法
- **回归（生成侧）**：`pwsh -File scripts/run_seeds_hf.ps1 -A 1 -B 24`（只跑 zone_check_2p，不写图）
- **回归（产物侧）**：`bash scripts/run_seeds_hf2p.sh 1 24`（run_hf 生成 + hf_check 断言，每 seed 一行摘要）
- **单跑**：`Godot --headless --path . --script res://scripts/run_hf.gd -- --seed=N --mode=2p`
- **纪律**：新断言必做负向测试；失败要响不要静默；先观测后收紧。

## 九、阶段运行与验收

- **P2 单独生成**：`Godot --headless --path . --script res://scripts/run_hf.gd -- --seed=N --mode=2p --stage=p2`。该模式只构建 P1→P2，输出 `output/p2_terrain/03_zones.png` 后退出，不调用 `heightfield.gd`。
- **P2 正式图**：`03_zones.png` 是唯一的 P2 图，输出与 P1/P3 主图统一为 1920×960；只表达独立战术分区的直线/折线边界，水/平地/台地不作为分区显示。
- **P3 诊断图**：`04_level.png`、`05_ramp.png`、`06_height_gray.png` 虽保留在 `output/p2_terrain/` 旧路径中，但它们读取最终高度场，属于 P3 诊断产物；P3 正式交付仍是 `output/p3_semantic/10~14`。
- **完整生成**：省略 `--stage` 或使用 `--stage=all`，按 P1→P2→P3 顺序生成全部兼容产物。
- **P2 验收**：`Godot --headless --path . --script res://scripts/verify/zone_check_2p.gd -- --seed=N`；该校验器会额外重建高度场检查跨阶段契约，不能被误解为 P2 图生成步骤。

## 十一、设计契约修订版 7：全面取消水（2026-09-02）

> 本节为最新口径，与 §二~§七 冲突处以本节为准；被作废条款保留原文仅作历史参考。

### 决策依据
- 素材库无船，海军玩法不存在；水域占地图 35%~65% 且不可通行，是无战术功能的死地。
- 用户拍板（2026-09-02）**全面取消水**。修订版 6 中所有水域条款全部作废：
  环海绕边、中央大陆完整、水体连通、滩头配额、出生点背靠水、水路巡逻轴线、Y_WATER=-2.4。

### 新地形结构：全平地 + 台地团
- 无岛椭圆 / 环海概念。地形由台地团（plateau blobs）+ 陆坡定义：
  - 中央争夺台地 1（中心，r 9~11）
  - 侧翼台地 1 对（点对称，r 6~8）
  - 兜底位（采样失败必保 1 对——战术高台不可缺）
- 台地团不得压出生盘、不得互相重叠。

### 高度层
- 两层 L0=0.6 / L1=3.6（层差 3.0 不变）；Y_WATER 作废。
- 坡道仅陆坡 L0↔L1，几何不变（宽 5.0 × 长 5.196 = 30°，`RAMP_LENGTH = LEVEL_STEP/tan30°`）；
  坡道 SAT 不重叠规则保留。
- 滩头 / 海滩类删除。

### P1 骨架新定义
- 出生点：平地自由采样 + 点对称（无 er 约束，兜底点作废岛肩假设）；基地盘 base_r 7~9 保留（防台地贴脸）。
- 进攻轴线：主轴 1 + 边路对（`corridor_w` 切平地走廊）；水路轴线删除。
- 资源 10 结构不变（私有 3×2 + 高台矿对 + 开阔矿对）。

### 语义分类：六类减为四类
低地 / 台地 / 坡道 / 崖（水、海滩两类删除）。

### 校验器断言清单变更
- 删除：水占比范围、水体连通、滩头数量/入水、出生点离水净空、海滩判据。
- 保留：陆连通（出生点+资源可达）、资源站位非坡道、高台矿站台地、坡道剖面 30°、
  坡道不重叠、点对称、战术分区结构、无微小分区。
- 新增：台地占比合理范围、坡道数量合理范围（数值**待实测回填**——待管线实测后回填具体区间）。

### P5 影响
- ArrayMesh 材质无水通道；原水域区域并入 L0 低地。
