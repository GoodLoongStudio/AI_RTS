# G2 战略台地约束

用户要求：台地必须足够大、足够多，并具有实际战略意义。后续优化不得仅为降低耗时或提高通过率，将台地重新缩成零散小块。

7.10.0 默认规则：

- 台地数量 6–8 座，上限默认 8，包含 2 座出生台地。
- 中立台地尺度默认 1.7，基础半径优先 24，退让档位 21、18；保留组合地块。
- 台地可通行顶面至少占全图 12%，纳入硬验收。
- 每座中立台地至少两处坡口，绑定实际穿越的高地路线。超过四座中立台地时允许增加独立路线，不覆盖其他台地的路线。
- 优先桥头、河岸与接近路线周围的完整空地；中立台地完整轮廓与地图边界至少相距 8 个逻辑米，不截断边界凑面积。
- 保留台地接近公平、40% 阻碍目标、双河道、默认六桥、任意单桥封闭后四家互通的验收。

这些是 G2 几何和寻路约束，不等同于已经验证高地射程、视野优势或 G4 实机战术效果。
