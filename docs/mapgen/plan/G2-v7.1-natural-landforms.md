# G2 v7.1 自然地块轮廓

2026-09-06。依据用户本轮确认实施：台地高差3m可以保留，主要问题是G2轮廓不够自然。玩法仍由障碍、少数不同高度的平面和连接坡道组成。

## 范围与版本

G2算法与随机流版本均升级为7.1.0。沿用v7的战略规则：暴露出生点的平顶台地、玩家间路线高地、可选中部高地、连通主河与多过河点。G1出生点与territory原样继承，中心出生仍有专门回归。

新产物在 `runs_v7_1/<seed>/G2`，审阅图在 `review_v7_1/G2`。旧 `runs_v7` / `review_v7` 保留。新版按版本随机流重新生成地貌，河道和中立高地的位置可以改变，并非对旧地图逐格修边。没有修改AI_RTS，没有执行G3/G4；G2候选manifest仍未放行。

## 实际几何改动

1. **台地轮廓。** 用7–9个不等间隔主控制点形成长短不一的崖段；一侧延伸地块，另一段插入浅凹口；转角做小幅非对称削角。替代旧版正弦扰动的拉伸圆形。轮廓填充直接决定region、悬崖、blocking和height，不只是预览换色。
2. **区域走向。** 每张地图生成一个缓慢变化的地貌方向场，台地和岩体沿所在位置的走向生成，并有小幅局部偏转。保护岩脊兼顾区域走向和敌人接近方向；不围绕出生点画弧墙。
3. **坡口选位。** 在朝向战略目标的候选方向中，结合浅凹口、崖面斜切程度和绕路程度选入口。保持标称8m穿崖宽，地面侧入口展开至11m并检查落脚空间。每块台地至少两个有效出口。
4. **岩体组织。** 85%的候选位置从崖脚或河岸附近提出，其余允许零散出露；不再轮流填满4×4格子。完整候选轮廓避让出生区、台地、通路和扩张区；岩体间留出间距。根据剩余障碍面积与最多10块的预算分配大小，避免堆小碎石凑密度。
5. **岩体语义。** 自然岩体统一记录为rock，不再因为面积大或形状长就随机归类为ruin或wall。旧分类函数保留供历史代码兼容。
6. **平顶预览。** 移除顶面的三圈内缩纹线，以免水平面被误读为层层隆起。比较图中的新旧两侧使用同一套无同心线渲染，便于单独判断实际轮廓变化。

主河沿用v7的边界到边界连通曲线、缓慢宽窄变化和三座桥，没有新增水文模拟或不连通支流。

## 数据颗粒度与接口

仍是256×256、1m栅格，栅格为玩法权威数据。地面0.6m、台地3.6m，实际高差3m；水体-2.4m、坡口过渡格2.1m。顶面保持水平，未添加任何细碎起伏。

出生台地的连续轮廓先保证包含24m圆盘，再栅格化并提取两格悬崖条带。原有20m出生净空盘必须完整位于水平顶面内。

mapspec新增：

- `landform_frame`：区域方向及X/Z方向上的缓慢转向参数，弧度。
- `plateaus[].outline`：生成实际台地范围的世界XZ坐标闭合多边形，首尾隐式连接。回归测试检查其栅格化结果与实际region一致。
- `plateaus[].landform_angle`：该地块使用的方向，弧度。

原有通道、台地用途、所有者、路线、坡口中心和方向、完整水床字段均保留。当前坡口仍是G2的分类过渡格；11m入口展开不等于已经实现了游戏内连续坡面，单位动画与最终坡面衔接仍需G4验证。
