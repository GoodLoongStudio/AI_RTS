# 台地与坡道正式建模流程

唯一入口是 `tools/godot/modular_plateau_component.gd`，基础依赖是 `plateau_base.gd`。

台地主体、主坡道和左右小坡道必须由同一张连续高度场生成。主坡道保持 10m 高差、18m 展开、约 29–30° 坡度和 18–22m 通行宽度。两侧小坡道只在台地边缘衰减带内形成较窄、较低的渐进过渡，不得出现孤立土块、悬空薄片或断缝。岩壁 Kit 只覆盖外侧陡壁，不能覆盖坡道通行面。顶部、坡面和岩壁统一使用暖色砂岩，禁止青绿色边缘和程序化色带。

正式输出为 `review/G4/kit_samples/modular_plateau_final/overview.png`、`ramp_socket.png`、`low_angle.png` 与 `component.json`。验收必须包含主坡道近景和能同时看清左右小坡道的俯视角，并确认无青绿色边缘、断缝和独立抬高土块。
