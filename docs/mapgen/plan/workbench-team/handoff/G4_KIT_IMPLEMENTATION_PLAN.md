# G4 Kit 实施计划

由 Codex 负责 G4 Kit 层。Qwen 的 G2/G3 结构数据作为只读施工图：G4 不重新生成地形逻辑，只把标准素材组件按结构锚点拼装。

第一阶段先将已确认的 4006 单层桥组合正式化：主桥面重复段、每岸一层端收口、两侧连续栏杆、端部立柱和支撑。输出实例必须记录 kit_id、piece_role、source_asset、anchor、transform、scale 和依赖哈希。

第二阶段复用同一解析器建立多层 Kit 库。逻辑上只认三类 G2 结构：平面、平面之间的坡道、独立水体；视觉 Kit 不得新增第四种逻辑地形。

- 平面表面 Kit：暖土、沙地、碎石、工业地板等表面模块，只改变外观，不改变高度和通行。
- 台地边缘 Kit：直崖、弧崖、端部、转角、坡口接触件；附着在平面边界，表达高差，不重新造台地。
- 坡道 Kit：坡面中段、上下端、侧缘、转角；唯一连接两个不同高度平面的通行视觉结构，保持 G2 的坡道方向和长度。
- 河岸 Kit：直岸、内外弯、浅滩、岸角、桥头过渡；只包裹独立水体边界，不能缩放或截断水域。
- 桥 Kit：桥面中段、端收口、护栏、立柱、支撑；跨越水体，桥下水仍是独立逻辑水体。
- 湖岸 Kit：湖边浅滩、岩岸、平台、资源边缘，只处理湖岸外观，不把湖变成可走地面。
- 障碍 Kit：大岩体、中岩块、墙段、废墟、掩体、端部和转角；放在 G2 blocking 区或视觉保护区，不新增逻辑阻挡。
- 连接/装饰 Kit：桥头、坡脚、岸线碎石、植被和小件，只能在保护区允许的视觉范围内使用。

每套 Kit 都必须有中段、端部、转角/收口和连接件；尺寸适配限制在清单允许范围内，超限即失败。

第三阶段接入 G4 导出和 review：同一 G2 任务、同一结构 ID 生成 Kit 实例、真实截图和可追溯来源。视觉装饰不能改变 blocking、passable、water footprint 或导航。

当前桥 Kit 原型定义在 `rtsmap/data/visual_kits.json`；桥组合样例和重建脚本在 `review/G4/bridge_assemblies` 与 `tools/godot/bridge_assemblies.gd`。原型渲染已验证模型可组合，但尚未接入生产导出器和实际单位通行验收。
