## 二、用户要什么

最终工作台一键生成G4真实地图，视觉达到自然、协调的风格化场景品质。G2的战略地形和普通用户界面已经基本认可，不能因美术调整重做出生位置、强制中央战场、恢复机械防守半圈或缩小湖泊。

逻辑层保持平面、台地、坡道和障碍。你的任务是让它们在游戏中看起来像同一片地形：岩石与崖体有整体感、坡面和地面衔接、河岸自然、地表有组织、装饰疏密合理、单位和资源易辨。

用户提供的视频链接在视觉索引文档中。本轮总控没能重新播放，不要声称你已看到它。你若正常访问成功，按实际画面记录视觉规律；仍不可访问就保留未验证标记，依据已明确目标和本地截图继续，不能臆造参考是森林/荒漠或擅自改整个项目题材。

## 三、你可以改什么

只修改`handoff.json`的`allowed_visual_files`列出的视觉模块、样式配置、派生材质/着色器、视觉资产索引和视觉测试/文档。默认方向为`rtsmap/presentation/`和`rtsmap/data/visual_profiles/`，最终以Qwen交接实际接口为准。

通过Qwen提供的接口改变色彩、材质、光照参数、合法装饰、结构模型的受控外观与镜头呈现。调用已有“固定逻辑地图重建视觉”功能，不另造随机地图生成器。

以下由Qwen负责，你不可悄悄修改：

- G1出生坐标/领地、G2地貌位置/高度/坡口、河湖大小与桥数量、G3资源与逻辑blocking/passable。
- 结构碰撞、导航烘焙、单位运动、点击/建造高度与游戏规则。
- 验收阈值、approval、API/任务schema、原始素材、整个游戏的全局材质或渲染设置。

视觉需要工程支持时写问题单，附具体场景、复现命令、截图和期望接口；不要靠扩大视觉岩石掩盖漏洞，或改碰撞让错误地形“能走”。

## 五、按这个顺序改善场景

### 1. 色调和大面积地表

先以当前场景为基线建立协调的土、岩、水颜色关系。地面加入低频色块和克制细节，避免整张纯色、棋盘平铺、每格不同色或满地高对比噪声。纹理变化只影响表面，不改变逻辑高程。

保持RTS常用视角下单位、资源和通路可读。曝光正常，不靠深阴影、浓雾、景深、过曝或强后期遮掩接缝。先完成一个稳定自然样式，不开发多套未经打磨的主题。

### 2. 崖体与岩石组织

连续地形由Qwen的真实网格提供。你选择能覆盖/衬托崖体的岩件，沿实际崖线方向组织，形成少量主要岩面、辅助岩块和局部碎石的层次。

避免等距串珠、每个部位同样大小、完全随机朝向、重复同一模型、岩石悬空、露出方盒基底。缩放和旋转要在接口允许范围内，视觉包围体不能挡住坡口、桥头、道路或资源净空。

如果主地形仍是错误高度或方盒导致无法自然衔接，提交Qwen问题单，不用更多模型把错误盖住。

### 3. 坡道与接触过渡

坡面结构已由Qwen做对；你通过材质、坡向纹理、崖脚少量碎石与颜色过渡，让坡口与上下平面连贯。避免一圈等宽描边、悬崖根部纯黑线和地面穿模。

坡道上保持干净，不能把斜坡变成碎石台阶。常用游戏视角必须能一眼识别坡口和高地入口。

### 4. 河湖与岸边

在原水域footprint不变的前提下，统一水色、适当深浅和轻微动态效果；确保桥下视觉仍连续。岸边用克制颜色/砂砾/局部植被过渡，保留能看懂的水陆界。

不要每格摆一个水板、用小石子排整圈边框或放大岸石侵占水面/通路；不要为岸线好看缩湖、截断河流、隐藏真实桥面。岸线网格如需工程修正，通过问题单交给Qwen。

### 5. 植被和装饰

基于高度、岸线距离、崖脚与空地组织成簇，保留大面积可作战地面。装饰密度有主次，不全图均匀撒点。风格跨包时控制尺寸、材质与色调，不将多个题材素材堆在一起。

纯视觉无碰撞不代表可以占路。使用接口的保护区与包围范围检查，禁止遮住基地盘、资源、桥头和坡口，也不能制造看起来不可走但实际可走的假墙。

## 六、每次改动如何验证

1. 先用同一张基准地图、相同镜头和配置小步迭代；改善成立后跑其余两张。不能靠换Seed挑一张漂亮图。
2. 运行Qwen提供的视觉契约测试，比较G1/G2/G3权威通道、资源坐标、碰撞和导航摘要。视觉Seed可以改变装饰，不能改变结构。
3. 保存同镜头、同分辨率、同渲染器的修改前后正交与游戏斜视，以及崖脚、坡口、河岸局部图。记录光照设置变化，不做后期涂改或拼入参考图假冒结果。
4. 实际检查贴图绑定、依赖路径、实例贴地、可走地面与岸线是否被视觉侵占；至少一次在正常游戏视角看到单位通过坡口/桥，不能只有静态美图。
5. 测量素材/材质/网格实例数、重建耗时和可用的运行性能，与Qwen基线对照。优先共享材质、合理实例化、减少碎件；不要靠大量透明叠层和过密小物件换自然感。
6. 先后检查全图组织、常用游戏视角和局部接缝。近看漂亮但全图像噪声、单位看不清，也需要修改。
7. 所有改进必须由样式配置和生成代码复现，不能只手改三张.tscn；更不能只修改工作台PNG。

# 视觉口径补充：台地不使用专门草地材质

台地是高程/战术地形，不是独立草原生态区。台地顶沿用主地表的暖土/砂土材质，不得因高度阈值自动混成绿色草地或要求额外草贴图；高差通过崖壁岩化、坡面受光、边缘阴影和材质明度差表达。验收图中台地与周围地表应属于同一地貌材质体系。

# 桥和坡道必须使用标准素材融合

用户追加要求：桥和坡道不能继续用程序直接生成的裸色块、矩形盒或无识别度的默认几何作为最终视觉。优先从素材目录筛选标准桥/坡道模型，再通过视觉接口按权威桥端点、坡口方向、宽度和高度进行定位、旋转、受控缩放与贴地融合。当前候选包括 `SM_Bld_Bridge_01.fbx`、`SM_Env_Detail_Bridge_01.fbx` 以及目录中的标准 Ramp 模型；必须先看预览、AABB、原点和材质，再决定是否可用，不能按文件名猜。

标准素材只负责可见结构和接触过渡；桥下水、桥面碰撞、坡道高度场、导航和通行语义仍以 Qwen 的权威数据为准。模型不得遮住桥头/坡口、制造视觉假墙、改变水域 footprint 或代替真实坡面。若素材尺寸或碰撞不匹配，记录具体接口问题交给 Qwen，不能靠放大石块或修改逻辑凑图。

# G4 统一采用 Kit 拼装

桥的组合方式应推广到所有结构：以 G2 图和语义数据为施工图，分别建立台地边缘 Kit、河岸/桥 Kit、障碍岩体 Kit、坡口接触 Kit 和少量装饰 Kit。每个 Kit 由中段、端部、转角、收口和连接件组成；通过锚点、方向、有限缩放和材质统一拼装，不能让 G4 重新猜地形或用程序色块替代标准素材。视觉交付须记录每个 Kit 实例对应的 G2 结构 ID，保证地图重建可复现。

请先阅读 `handoff/BRIDGE_RAMP_ASSET_RESEARCH.md`。第一轮优先试 4006 同组桥组件（Bridge、End、Rail、Rail_End/Half、Rail_Pillar、Strut，必要时 Platform）组合成完整桥并统一调色。4019 两件 Trench_Bridge 目前确认主要是桥面变体，不能单独当完整桥。463 工业桥必须整套同风格使用，不能与木桥或 4006 混搭。每套都要由中段、端部、支撑/栏杆和岸边接触件组合，不得直接把单个 Bridge_01 放进地图。
