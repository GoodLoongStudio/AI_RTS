# 分阶段 Kit 工作流

这是当前项目后续开发的工作顺序，目的是把复杂的 G2-G4 集成拆成可单独验收的组件。

## 阶段一：单组件原型

分别生成并审核以下组合：

1. 平面：连续地面、材质、边界和基础装饰。
2. 台地 + 坡道：以 `modular_plateau_component.gd` 及 `modular_plateau_final` 为唯一视觉基线。
3. 平面 + 河道：连续河床、河面、两侧岸坡和岸边 Kit。
4. 平面 + 湖泊：独立湖面、湖床、湖岸和浅滩 Kit。
5. 河道 + 桥：河床连续，桥面跨水，桥头和岸边连接件完整。

每个原型独立输出截图、参数和实例清单；原型未通过时不接入完整地图。

## 阶段二：Kit 组合验收

在固定的 G2 结构数据上分别组合台地、坡道、河道、湖泊、桥和装饰 Kit，确认视觉拼装不改变权威结构。重点检查锚点、方向、尺度、接缝、岸坡连续性和通行面。

## 阶段三：G2-G4 合并

只有单组件和组合 Kit 都通过后，才把它们接入完整 G4 导出：

- G2 提供平面、台地、坡道、独立水体、桥位和保护区。
- G4 按结构 ID 将已审核 Kit 拼装到对应锚点。
- 高度场、碰撞、导航和水域 footprint 仍来自权威 G2/G4 数据。
- 裸高度场或临时色块只能作为诊断图，不能作为最终 G4 视觉输出。
