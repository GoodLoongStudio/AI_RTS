## 自然感的具体标准

| 部位 | 应当达到的效果 | 自检方式 |
| --- | --- | --- |
| 大地形 | 平面高度明确，台地像完整地块；自然轮廓、整体与局部有层次 | G2逻辑图、G4正交和斜视三者对照 |
| 地表 | 基础土色有低频分区、细微明暗与有限纹理变化，避免整张纯色或满屏噪点 | 全图看组织，常用游戏视角看重复与噪声 |
| 悬崖 | 连续山体基底结合少量大、中、小岩件；按崖线走向放置，有主次与嵌入感 | 检查等距串珠、重复朝向、方盒接缝、悬空与露底 |
| 崖脚/岸边 | 颜色、砂砾和少量装饰形成过渡，材质与岩石协调 | 近看接触处；全图不形成一圈整齐描边 |
| 坡道 | 与上下平面自然连接，坡口易辨；纹理顺势变化 | 实际单位上下坡，不能用石块盖住接缝或占用入口 |
| 河湖 | 连贯水面，水色有克制变化，岸边自然；桥下仍可辨水体延续 | 检查水体真实footprint、桥面与渲染图，不只看颜色 |
| 植被/细碎装饰 | 按地貌成簇、疏密有别，保留开放战场与视线 | 检查基地盘、资源点、路径、桥头和坡口是否被视觉遮住 |
| 色彩/光照 | 同一场景色调一致，适度阴影帮助读出高差，资源和单位易辨 | 使用固定曝光与镜头比较，不以过暗、重雾、景深掩盖问题 |
| 随机变化 | 多张地图都达到同一品质，变化有约束 | 至少三张不同布局，不能只手摆一张展示图 |

自然不等于增加障碍、把整图铺满草石、改变水域大小或把平顶台地噪声化。视觉模块不得侵占实际通路；装饰不带碰撞也不能在视觉上形成假墙。

“岩土偏暖、低多边形风格”是对当前工程资产的可用基线，不是对未播放视频的色彩结论。优先维持现有游戏风格，再通过实际参考细化；不强行将视频假定成荒漠、森林或雪地。

## 素材使用规则

- 原始素材包只读，不改FBX、图集、Unity文件和原始预览；派生材质、索引、渲染缓存与生成成果放在本项目或隔离验证项目。
- 先筛选少量风格一致、用途明确的素材。每条记录来源完整相对路径、图集、尺寸/原点、允许用途、允许缩放、是否适合地表贴附及预览路径。
- 模型从Unity包而来，`.mat`不能直接当Godot材质；按真实图集绑定，防止白模。跨包图集不能全套用4006默认贴图。
- 以源相对路径作为唯一身份，不能只用basename，避免不同包同名资源冲突。
- 浮空岩、角色合集、碰撞专用FBX、武器、建筑围墙不要混入自然崖壁资产池；普通小道具也不能替代主地形。
- Synty散件负责视觉，连续台地/坡面/碰撞由Qwen的程序地形负责。素材库没有可直接替代全部地图逻辑的现成地形系统。
