本文件中的“公共接口”分为两层：

1. `AI_RTS.Core` 公共契约：Domain 值对象以及 Application 的命令、查询、服务、端口和结果类型；
2. Godot Adapter 门面：供可信 GDScript、场景节点和传统 AI 调用的 `Node`/`Dictionary` 边界。

Godot Adapter 的公开方法不自动等于可向外部 Python 或大模型进程开放的网络协议。未来跨语言入口必须另建 Gateway，并只能依赖经过本次确认的 Core 契约。

## 3. 跨接口统一语义

### 3.1 同步回执不是任务完成

`CommandResult`、`ProductionCommandResult`、`ConstructionSiteCommandResult` 等同步结果只回答本次请求是否被权威层接受或应用。以下情况在接收后仍可能发生：

- 单位中途死亡、失去移动或攻击能力；
- 目标死亡、失效或改变归属；
- 桥梁、路径或地形在途中变化；
- 不同速度单位在不同时间抵达；
- 生产完成但出口被堵，进入等待部署；
- 施工过程中受伤、被取消或被摧毁。

长期结果必须读取订单/任务快照或订阅状态事件，不能把一次 `Accepted` 解释为“已经到达”“已经命中”或“已经建造完成”。

### 3.2 部分成功

批量命令逐单位独立验证：至少一个单位接收、至少一个单位拒绝时返回 `PartiallyAccepted`。中途死亡、不可移动、非己方、能力不足等不会导致已合法成员一起失败。需要原子性的经济交易、建筑放置和单个生产入队不使用该语义。

### 3.3 身份与权限

- Core 只接受稳定 ID，不接受 Godot Node 或场景路径；
- 玩家 UI 的 `UnitCommandGateway` 属于本地可信适配器，可以把当前选中 Node 翻译为 ID；
- `RuleAiCommandGateway` 在组合根中一次性绑定玩家身份，调用者不能更换 issuer；
- 规则 AI 攻击目标必须是固定查询会话当前可见的敌人；不可见与不存在统一为 `TargetUnavailable`；
- 查询会话由 Match 组合根签发，调用方不能自行选择观察者、字段权限或全知标记；
- 外部大模型不能直接持有 `WorldQueryRuntime`、标准会话或 `IWorldQueryService`，只能访问未来的 `IBudgetedWorldQueryService` 实现及跨语言 Gateway。

### 3.4 数值和时间

- 离散资源余额、费用、生产/施工工作量使用 `int`；
- 账户版本、观察版本和模拟 Tick 使用 `long`，用于单调版本和长时间累计，不代表玩家可见经济数值；
- 世界位置在 Core 使用 `WorldPosition`；Godot Adapter 才转换 `Vector3`；
- 运行时移动、HP、射程、伤害等连续量当前使用 `float`。

## 5. Godot Adapter 门面评审

| 门面 | 调用方 | 是否可作为外部协议 | 结论 |
|---|---|---|---|
| `UnitCommandGateway` | Human GDScript/HUD | 否，参数含 Node、Vector3 | 保留为可信本地适配器 |

| `EconomyRuntime` | 玩家、Worker、生产/施工 Adapter | 否，参数含 Node | 保留 |
| `StructurePlacementRuntime` | 玩家放置与规则 AI | 否，参数含 Node、PackedScene、Transform3D | 保留 |
| `ProductionRuntime` | HUD、规则 AI、Match Tick | 否，参数含 Node/PackedScene | 保留 |
| `RallyPointRuntime` | Human 输入/HUD | 否，参数含 Node/Vector3 | 保留 |

## 6. 最终审计发现

### 6.1 已确认在 QA-008 内修正：测试会话入口的发布版硬关闭

`WorldQueryRuntime.GetStandardSessionForTests()` 和 `GetOwnEntityReferenceForTests()` 名称及注释明确为测试用途，但目前在非调试构建仍可调用。外部进程不能直接调用 Godot Node，因此这不是当前可利用的远程漏洞；不过测试边界不应依赖调用者自律。

项目负责人已接受以下修改：

- 非 Debug 构建的 `GetStandardSessionForTests()` 返回空字符串；
- 非 Debug 构建的 `GetOwnEntityReferenceForTests()` 返回空字典；
- `GetDebugSessionForTests()` 已具有只在 Debug 生成授权的限制，保持现状；
- 正式规则 AI 继续由组合根直接绑定会话，不依赖任何 `ForTests` 方法。

这项修改不改变已验收玩法，只把测试能力限制在调试构建。

### 6.2 接受但不冻结为外部协议

- `Godot.Collections.Dictionary` 的字段集合尚无独立协议版本；
- `IBudgetedWorldQueryService` 尚无操作点账户、扣费表或实现；
- Python 通信方式、超时、取消、重试和限流尚未选型；
- 规则 AI 的阵营、指挥官、地图和玩法配置尚未外置。

上述能力继续延期，不能在大模型或 AI 专项中绕过当前稳定 Core 服务直接操纵场景树。

### 6.3 明确不属于本次接口缺口

以下旧项目不存在或策划尚未确认的机制不阻塞本次重构接口验收：

- 散开、计划模式、列队；
- 目标类型过滤与优先级策略；
- 碾压等级与驱逐/阻挡细化；
- CMD-014、CMD-015；
- 海上/空中/特殊地形建筑；
- 生产暂停与队列重排；
- Worker 自动恢复采矿及右键矿场交付；
- 多 Worker 加速规则、维修规则；
- 复杂导航、多单位共享路径、Flow Field；
- 战役、任务和大模型实际接入。

这些项目必须在重构完成后分别进入需求或缺陷分支评审，不能通过修改当前公共接口的既有语义顺带实现。
