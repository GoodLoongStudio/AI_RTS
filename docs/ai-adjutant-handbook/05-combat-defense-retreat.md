# 05 战斗、防守、撤退

## 目标

1. 以集火（focus fire）原则交战，用 Lanchester 平方律优势速杀目标；
2. 基地安全优先于前线推进；
3. 损失可控时才进攻，触发止损线果断撤退重组。

## 输入数据

- `counts.mine_by_type`：坦克/直升机数量（兵力对比、止损判断）；
- 全量 status（低频）：可见敌方单位名与坐标（`attack` 的 target 必须来自这里）、我方单位 hp；
- `/tmp/wing_state.json`：各翼（≤8 辆/翼）平均位置与停滞状态；
- `/tmp/intel.json`：敌基地与 composition（决定补防空还是对地）。

## 决策条件：优先级链（从高到低）

每轮交战管理器按此链**从上往下**检查，命中第一条就处理：

| 优先级 | 条件 | 动作 |
|---|---|---|
| 1 回防 | 敌单位出现在我方基地/工人附近 | 全军 `attack` 最近敌单位 + 集火；**工人不停采** |
| 2 撤退 | 我方兵力折损 ≥ 50%（对比本轮与账本） | 全军 `move` 撤回基地重组；前沿补塔；工厂继续产坦克 |
| 3 集火交战 | 有可见敌目标 | 全军 `attack` **同一个**目标；目标死亡换下一个（价值序：能还手的先杀 → 生产建筑 → 工人 → 对地塔 → 指挥中心） |
| 4 行军/集结 | 坦克 ≥ 20 或敌军压境 | 剥洋葱协议机动（每轮只挑人群外缘 2~4 辆 move 到 10~15m 短跳板）；集结未满不下场 |
| 5 补充 | 以上都不命中 | 转生产/侦察管理器（它们永不停，但指挥带宽先给战斗） |

残血拉回：我方单位 `hp < 30%` → move 后撤到战线之后（多挨一刀就白死一辆）。

## 不应该做什么

- 与敌塔对射（塔射程 8 > 坦克 5，对射必亏）；攻坚必须全军集火单座塔速杀、死一辆补位一辆、逐座推进。
- `attack` 非敌方目标（target 必须 `owner != 主人`，永不攻击主人单位）。
- 撤退指令一轮一改：撤退至少执行 3 轮再评估，来回反复 = 全灭。
- 集结未满就添油式进攻。
- 追击进入未侦察区域（脱离侦察兵视野范围）。
- 回防时叫停工人采集（经济不能断）。

## 失败后的恢复策略

| 情况 | 处理 |
|---|---|
| `attack` 回执 `target not found` / 目标已死 | 下轮 status 取新目标；两轮内不重复用同名目标 |
| `attack` 回执 `PendingAuthority` | 等下一次 status：看目标 hp 是否下降判定是否生效，不立即重发 |
| 全军/某翼停滞（avg_pos 位移 < 2m） | 本轮必处理：剥洋葱参数减半（跳板 5~8m、每批 2 辆） |
| 止损撤退后仍被打 | 放弃前沿塔，死保车辆工厂与工人；把残余部队藏进基地塔射程内 |
| 翼被打散（成员失联） | 该翼账本作废，幸存者并入最近翼重新记账 |

## 对应的游戏控制命令或状态字段

- 命令：`attack units='[...]' target=<敌单位名> as_player=主人`、`move units dest`（撤退/回防/剥洋葱机动）、`status lite=true`、`build`（前沿补塔）。
- 字段：`counts.mine_by_type`、敌我单位 `hp` / `pos`、`counts.scouted_enemy`、回执 `accepted` / `status` / `PendingAuthority`。
- 状态文件：`/tmp/wing_state.json`、`/tmp/intel.json`。
