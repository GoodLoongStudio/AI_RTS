## 二、实施优先级

### P1 — 低成本高价值（复用现有数据源）
1. **情报流面板**：右栏小地图下方加滚动列表，订阅 `BattlefieldEventRuntime` 事件（生产完成/单位阵亡/基地受袭），每条带时间戳，最多保留 8 条。#4
2. **顶栏资源条**：资金 chip 从侧栏移到全宽顶栏 + 显示游戏内时钟（Match 计时）；侧栏腾出的空间给情报流。#1 部分
3. **生产卡片买不起态强化**：资金不足时价格文字变红色（现有置灰样式保留）。#2 收尾

### P2 — 中等工作量
4. **单位名牌**：单位头顶 `Label3D`（名称 + 聚合 ×N），同格多单位聚合显示，仅可见时渲染；建筑常显、单位受击/选中时显示。#7
5. **作战部队汇总**：SelectionPortraitPanel 顶部加人口行（X/Y，接生产人口统计）；肖像行已有血条。#6

### P3 — 大件（需新系统，先立玩法设计再动工）
6. **电力系统**：新资源类型 + 建筑提供上限 + 产能惩罚机制 → 需要单独 plan（balance/Core/联机同步都要动）。#10
7. **天气/时段**：环境光照 + 材质变化系统。#9
8. **占领点玩法**：需玩法设计。#8

### 立即可做小项
- 缩放百分比指示挂到侧栏底部状态行。#11
- 事件通知横幅与 #1 情报流共用数据源，一并做。#12

## 三、验收基线
每项完成需通过对应 Godot 自动场景测试 + 真实联机双端验证（规范要求）。
