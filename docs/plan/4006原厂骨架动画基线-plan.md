# 4006 原厂骨架动画基线

2026-09-06，用户授权重建一个标准士兵的动画管线。当前 yyp_test 比 main 领先 400 个提交，工作区已有 v2 动画与地图的未提交修改；本任务保留这些修改，以新增 v3 资产接入当前测试分支，不合并或推送 main。

问题：原始 Characters.fbx 已含 50 骨骼与身体蒙皮；旧管线重绑为 23 骨、丢失手指、缺少真正的步枪附件，Crawl 取样周期错误，导出检查不能判断实际姿态。

方案：保留原始身体网格、骨架与权重；按源参考姿态计算每骨全局旋转增量，统一角色朝向后求解目标局部旋转。非根骨不写平移。Idle/Run 来自现有 Soldier，Crawl/Death 来自现有 UAL；Fire/Hit/HitHeavy 是本次编制的步枪姿势、后坐和站立受击层。武器为原包 Assault_01，完整合并子部件，全部顶点刚性绑定 Hand_R。

交付范围：一个士兵、七段剪辑、Blender 可重建脚本、最终 GLB、逐段 GIF、独立 Godot 审核工程；接入现有步兵场景并更新骨架/真实姿态冒烟检查。Crawl 玩法命令、死亡延迟销毁和其他角色批量化不在本次范围。

验收：原始权重逐顶点一致；最终 GLB 重新导入的关节/变形包围盒与 Blend 一致；身体及完整武器不穿过地面；循环所有关节首尾一致，Crawl 内部无旧的 0.177m 根跳变；枪相对右手保持刚体；Godot 4.7.1 Mono 实際导入及各剪辑骨骼旋转变化；游戏内现有动画驱动测试。

限制：这是一套可审核的单角色技术基线。受击为保持持枪的站立反应，HitHeavy 不含击飞/倒地/起身。匍匐采用单手携枪。地面纠正解决穿透，不等同脚掌 IK 或任意导航速度下完全无滑步。近景握持、动作力度、RTS 实际移动速度匹配仍需美术/玩法目检；不要把技术测试通过当作最终美术定版。
