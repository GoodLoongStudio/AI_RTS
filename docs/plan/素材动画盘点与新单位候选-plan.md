# 素材动画盘点与新单位候选-plan.md

> 2026-09-11 盘点：初选素材包（五套 Synty 解包）+ 绑骨管线产物 + 现有 assets。
> 结论先行：**动画成品只有步兵一套（7 段）**；载具/建筑类单位不需要骨骼动画即可入库。

| 资产 | 位置 | 动画段 | 状态 |
|---|---|---|---|
| **Infantry_native_v3.glb**（4006 科幻士兵，50 骨骼+步枪） | `绑骨管线/4006/原厂骨架_v3/` | Idle-loop / Run-loop / **Fire** / **Hit** / **HitHeavy(爆炸击飞)** / Crawl / Death 共 7 段 | ✅ 已在游戏使用；审核 GIF/胶片条齐全 |

| 4019 一战军人 / 4041 西部人物 / 4017 幻想怪物（Characters.fbx 各 1 个合集文件） | `提炼_科幻战争与角色/人物角色/` | 未绑骨 | 需完整绑骨管线 |

> 关键结论：**步兵级新单位**若要走动画，目前只有"复用 Infantry 骨架"一条成熟路（同骨架换武器/贴图 → 火箭兵、狙击手等变体）。
> **载具/建筑类新单位不需要骨骼动画**——现有坦克/直升机/炮塔就是静态 FBX，可直接入库。

## 四、建议顺序

1. **APC 装甲车**（P1：静态模型、丰富载具线）
2. **火箭炮车**（P1：远程火力补全，弹道系统现成）
3. **重坦变体 HoverTank_02**（P2：成本最低的"新单位"）
4. **步兵武器变体**（P2：复用现有动画）
5. DropShip 运载 / 463 僵尸（P3：需新逻辑/动画管线）
