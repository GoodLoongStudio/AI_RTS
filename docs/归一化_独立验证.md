## 6. 额外发现 B：人类放置的建筑被放大 3 倍（真实链路缺陷）

1. `StructurePlacementHandler.gd:226-246`：ghost 被乘上原型 `Geometry.scale`（建筑=3.0）——这是"蓝图显示尺寸"修复本身。

## 7. 归因专项 1：local-avoidance 的红**不是**根缩放引起的

**问题（lead）**：是否由"单位根缩放 2→1"改变了避让有效几何？

### 7.1 引擎层实测（`_IndepVerifyAvoidanceScale.gd` 的 Q1 段）

```
[IVR4-Q1] NavigationAgent3D is Node3D=false class=NavigationAgent3D | NavigationObstacle3D is Node3D=true
[IVR4-Q1] 父链 scale=1.0（agent 无 transform）→ 服务器侧 radius=2.0 neighbor_distance=3.0 max_speed=5.0
          height=1.0 max_neighbors=8 time_horizon_agents=4.5 position=(0,0,0)
[IVR4-Q1] 父链 scale=2.0 → radius=2.0 neighbor_distance=3.0 max_speed=5.0 height=1.0 max_neighbors=8 …
[IVR4-Q1] 父链 scale=4.0 → radius=2.0 neighbor_distance=3.0 max_speed=5.0 height=1.0 max_neighbors=8 …
```
