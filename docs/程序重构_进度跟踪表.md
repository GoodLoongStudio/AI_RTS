## 状态规则

| 状态 | 表示方式 | 判定条件 |
|---|---|---|
| 已完成 | ~~工作项文本~~ | 代码、文档和必要测试均完成；需要人工验收的功能已获得验收结果 |
| 进行中 | 正常文本；状态写“进行中” | 已开始实现，但尚未满足全部验收条件 |
| 未开始 | 正常文本；状态写“未开始” | 尚未进入实现 |
| 延期 | 正常文本；状态写“延期” | 已确认不属于当前重构关键路径，转入后续独立分支 |
| 冻结 | 正常文本；状态写“冻结” | 保留接口或原型，不继续扩展，等待解冻评审 |

> 删除线只表示该行定义的工作已经完成，不表示相关子系统已经全部完成。部分完成的功能必须拆成多行，禁止把整组任务提前划掉。
