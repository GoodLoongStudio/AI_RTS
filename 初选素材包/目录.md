**FBX 命名前缀 → 类别**：

| 前缀 | 含义 |
|---|---|
| `SM_Bld_` | 建筑（房屋、塔楼、桥梁） |
| `SM_Env_` | 环境（地形件、悬崖、植被、战壕、弹坑） |
| `SM_Prop_` | 道具（桶、箱、杂物、家具） |
| `SM_Veh_` | 载具（车、坦克、直升机、船） |
| `SM_Chr_` | 角色（人物本体 + `SM_Chr_Attach_` 附件：帽盔、背包、面具） |
| `SM_Dec_` / `FX_` | 贴花 / 特效 |
| `SM_Til_` | 地块瓦片（可平铺） |
| `_Collision` 后缀 / `Col_` 前缀 | 碰撞体网格（**不要拿来渲染**） |

**贴图规律**：每包少量图集（atlas）供全部模型共用。`_A`=albedo、`_B`/`_C`=emissive/metallic；
`Textures\Alts\` 下是整包换色变体。

## 五、接入 Godot 项目的注意事项（重要）

1. **FBX 直接可用**：Godot 4.7 内置 ufbx 导入，`Models\` 下的 FBX 拖进工程即可。
2. **材质需要重做**：包内 `.mat` 是 Unity YAML，Godot 读不了，FBX 自带材质是白模。
   解法：用 **GUID 链**（prefab → .mat 的 `_MainTex` guid → 贴图 .meta 的 guid）算出模型对应图集，
   运行时挂 albedo_texture。现成实现：`工程\工具\map_fbx_textures.py` + `工程\预览渲染工程\texture_map.json`。
3. **没有真正的地形系统**：宣传图的地面 = Unity Terrain 组件（不可导出）+ Env 散件拼装。
   大地形仍走 AI_RTS 程序化地形，这些包提供**地表装饰散件**（瓦片/悬崖/弹坑/植被）。
4. **demo 场景布局**：4041/463 的官方摆位已解析为 `工程\预览渲染工程\scenes.json`
   （每实例 pos/quat/scale + 使用的 mesh）；4006 两个、4050 全部场景被 Unity 剥离无法解析。
5. **碰撞体**：`*_Collision.fbx` 是 Unity 碰撞网格，接入时排除（Godot 自己生成碰撞）。
6. **尺度**：Synty 1 单位 = 1 米，与 Godot 一致；单模型 0.5–5m，建筑 10–30m。
