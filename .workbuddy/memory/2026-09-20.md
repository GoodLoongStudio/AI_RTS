
## 首次 Windows 打包（2026-09-20）
- 导出失败根因：本机从未装导出模板。清华/TuxFamily 镜像无 4.7.1 mono 模板；官方归档页真实直链经 downloads.godotengine.org 查询式 URL 302 到 Hetzner 对象存储（godot-releases.nbg1.your-objectstorage.com），直连 200 可下载 1.2GB。
- 安装：tpz 解压 templates/ → %APPDATA%\Godot\export_templates\4.7.1.stable.mono\（解压耗时 1.5h，文件极多）。
- 导出：godot --headless --export-release "Windows Desktop" "build/Open RTS.exe"（embed_pck 单文件 505MB），--headless --quit-after 200 试运行无 .NET 报错。
- 模板直链公式：https://downloads.godotengine.org/?version=X&flavor=stable&slug=mono_export_templates.tpz（-I 看 Location 拿真链）。
