## 协作者拉取后无 BGM 的诊断（2026-09-08）
- 结论：音乐文件已正常推送——仓库用 Git LFS 管理 *.ogg/*.wav（.gitattributes），GitHub 上是 LFS 指针+LFS 对象；`git lfs fetch -I "assets/music/*" origin` 验证远端对象存在。
- 协作者没声音的原因必然在拉取端：①未装 Git LFS（拿到的是 130 字节指针文本，Godot 读不出）；②用网页 ZIP 下载（ZIP 里也是指针）；③GitHub LFS 免费额度（1GB 存储/1GB 月带宽）耗尽导致 lfs pull 报 quota 错。
- 修复口诀给协作者：装 Git LFS → git lfs install → git pull → git lfs pull；验证法：文本编辑器打开 assets/music/menu_theme.ogg，若开头是 "version https://git-lfs" 即指针未下载。
