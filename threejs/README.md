# AI_RTS Three.js 宇宙规模 RTS 视觉垂直切片

这是 `AI_RTS` 的 Three.js 路线原型：目标不是复刻任何现有商业游戏资产，而是建立“家园式三维舰队指挥 + 宇宙宏大尺度 + 高密度程序化舰船”的技术与视觉基线。

## 当前内容

- 7 类程序化舰船：母舰、战列巡洋舰、驱逐舰、护卫舰、轻型舰、攻击机、采集舰。
- 舰船由几何模块、程序化装甲板纹理、粗糙度纹理、发光引擎、炮塔、舰桥和灯带构成，无外部模型依赖。
- 多层星空、程序化星云、程序化行星大气、行星环、950 颗实例化小行星、空间尘埃。
- ACES Filmic 色调映射、Bloom、轻颗粒/暗角后处理、动态分辨率。
- 框选、点击选择、双击同类选择、编队移动、攻击、自动防御、敌方 AI、舰体生命、激光/曳光弹、爆炸、战术暂停。
- HUD：资源、舰队强度、舰种列表、选择信息、战术星图、命令按钮。

## 运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
npm run preview
```

## 控制

- 左键：选择 / 框选 / 点击敌舰攻击
- 右键：移动到目标空域；右键敌舰直接攻击
- Shift/Alt + 右键空域：提高/降低移动目标高度
- 点击空域：对已选择编队下达移动
- 双击己方舰船：选择全部同类型舰船
- WASD：镜头平移
- Q / E：镜头目标升降
- 鼠标中键拖动：环绕镜头
- 滚轮：缩放
- M：移动模式
- X：攻击模式
- F：聚焦首个选中单位
- Space：战术暂停

## 技术基线

- Three.js r184
- `InstancedMesh` 用于小行星场以降低 draw calls。
- `CanvasTexture` 在运行时生成舰体面板/粗糙度纹理。
- 自定义 ShaderMaterial 生成星云、行星表面和大气层。
- 近距离英雄舰采用较高几何复杂度；大量小型单位保持模块化低成本结构。
- WebGLRenderer 路线优先覆盖面；后续可单独建立 WebGPU + TSL 渲染分支。
